# 规范仓库风险登记

本表记录规范仓库的风险、触发条件与控制措施。维护职责按[职责表](ROLES.md)，所有状态都应绑定准确对象及证据；风险存在不等于已发生事故，已有失败也不能改写为从未发生。

| ID / 风险 | 触发与可观察后果 | 控制及核验 | 职责 / 剩余边界 |
| --- | --- | --- | --- |
| RS-01 / 解析遗漏或歧义 | 新条款格式未识别，章节数被误作义务数，正文附加后仍“全覆盖” | 逐文档配置、原标签清单、所有非空块绑定；先更新整文摘要再做删改/重复/截断/附加变异；计数独立标注身份/结构口径 | 工具维护与技术审查；自然语言是否包含多项义务仍须实读 |
| RS-02 / 过期或越界来源 | 动态文档更版、草案误称正式标准、单厂商保证被推广 | 有限命题、版本/章节/读取范围及不支持推论分列；维护时核上游差异及实际消费条款 | 领域维护；网络失败保留待核，旧读取不冒称新鲜度 |
| RS-03 / 测试替代真实效果 | 有限模型或SQLite示例被称为云/浏览器/硬件/交易通过 | 分开document-check、finite-model、isolated-runtime和真实目标；给齐not-run目标合同；跳过不是通过 | 验收职责；实际未运行目标不能升级 |
| RS-04 / 隐式生效与旧结论漂移 | 一份批准被推广至其他文档，变更摘要后沿用旧独审 | 固定规范状态、项目采用决定及实现结果的准确对象；审查与执行绑定准确hash；变更做实际影响分析和补验 | 采用决定与审查职责；记录一致性不能认证现实权限 |
| RS-05 / 失败或来源证据污染 | 改写失败、误把可移植视图当原始日志、发布无权再分发的长文本 | 保留原始结果与摘要；导出记录说明对象及转换过程；来源记录具体命题、版本和权利条件 | 证据与权利职责；摘要不能证明来源命题为真 |
| RS-06 / 并发及未知外部结果 | 迟到执行、重复效果或恢复时开启新意图 | 跨域接口分别固定意图/attempt/epoch/权威状态、拒旧与恢复；案例含合法并发和“查询暂缺后旧执行提交” | 领域维护与采用项目；按实际目标验证并发与恢复结果 |
| RS-07 / 兼容和依赖断裂 | 路径或版本迁移后消费者仍读旧保证，引用环被当必要闭包 | 条款级条件消费边、固定提供版本/hash、源块保全/修订理由、兼容和回退合同 | 架构与采用职责；链接存在不等于必要依赖成立 |
| RS-08 / 检查入口假通过 | `-O/-OO`删除assert、优化导入绕检查、字段存在替代语义 | 有断言入口明确拒绝优化；直接解析与主段语义变异；审查自动/人工边界 | 工具维护；工具不能证明所有自然语言命题 |
| RS-09 / 验证改写被审对象 | 测试在仓内写固定日志/数据库，重跑覆盖旧证据或改变候选 | 隔离临时输出、唯一运行目录、前后文件身份；原始失败另存不覆盖 | 验证职责；目标运行结果仅对其输入/环境成立 |
| RS-10 / 权利、角色和保护未落实 | 未定许可证被称开源、虚构维护者、方案被称平台已启用 | 根 [LICENSE](../LICENSE) 的路径规则、[第三方通知](../NOTICE.md)、发行许可核对、可验证职责决定及配置回读 | 项目所有者与管理员；接收和处理入口见职责表 |

## 处置与复审

发现具体问题时建立准确Issue/私密报告，列受影响条款、来源/依赖、直接失败、严重性与兼容影响。先保存失败，修复后对精确新对象运行受影响与完整门禁；必要时重新独审。风险接受需记录真实决定主体、对象、范围、期限与复审条件，不能仅将表中状态改为“已接受”。退役按相应模板核消费者、保留、处置与不可逆效果。

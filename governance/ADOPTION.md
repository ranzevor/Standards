# 规范采用

## 当前规范集合

Standards v0.1.2 包含 162 份已采用规范，生效日期为 2026-10-30。正式正文位于 `standards/`；[规范登记](../registry/standards.json)列出稳定 ID、标题、路径、领域、版本、状态、语言、生效日期和 SHA-256。

[规范目录](../INDEX.md)提供导航，[条款索引](../registry/requirements.json)提供条款 ID 和准确正文位置。规范 ID 不包含版本；选择特定内容时同时固定 ID、版本与摘要。

## 项目采用

项目按实际功能和约束选择适用条款，记录必要依赖、参数、例外及验收条件。既有有效采用决定覆盖当前项目范围时，直接引用该决定及其适用范围。

[采用指南](../guides/ADOPTION.md)说明选择和升级步骤，[项目记录模板](../templates/project-governance/project-record.template.json)提供机器接口。项目实施结果由该项目的实际检查与验收记录确定。

## 维护与变更

修订正文时同步其版本、摘要、条款和依赖索引。版本变更按[发行政策](RELEASE.md)处理；项目升级按[迁移指南](../guides/MIGRATION.md)核对受影响义务、消费者及恢复方案。

# Standards 0.1.2

版本日期：2026-10-31。

## 软件开发与质量门禁

- 增加质量门禁设计指南，说明独立验收预期、制品自述清单、来源字段关系与检查器自身的正反例和合法邻例。
- 提供缺少承诺包成员后重算清单、合法依赖组重排、等价 JSON 排版及配置读取后被替换的合成案例。
- 补充物理路径归属案例，分别检查 Windows junction 与 POSIX 目录链接导向根外的情况。

## 制品、安装与仓库流程

- 增加制品验证与安装恢复指南，区分当前源码检查、发行构建、新版安装及旧版备份、卸载和恢复的职责。
- 合成文件映射示例覆盖新装、文件增删和改名升级、恢复旧版及未知目标保护；实际安装器按自己的目录、锁、事务和数据迁移合同验收。
- 增加日常软件变更指南与完整案例，连接需求、基线、候选、检查选择、独立审查、修后复核、合并确认及发行维护。
- 同步贡献、仓库采用、模板、验证及中英文 README 导航；新增指南为中文。

## 发行恢复

- 标签对象或引用创建后暂时不可读时，最多执行四次只读确认，间隔为 1、2、4 秒。
- 对短暂不可见和暂时性读取故障进行确认；权限错误或可见身份冲突直接拒绝。
- 确认耗尽后停止后续发布，保留准确对象供同一发行恢复；确认过程不重复创建或移动标签。

## 兼容性与制品

- 发行集合由 0.1.1 升至 0.1.2；162 份规范正文保留原版本、稳定 ID、条款 ID 与内容身份。
- 新增指南和案例按项目需要使用，既有采用项目的义务与工具入口保持兼容。
- 正式发行提供 Source、Agent Skill、`BUILD-REPORT.json` 和 `SHA256SUMS.txt` 四项附件，并为附件生成 GitHub artifact provenance。
- 规范、文档与数据采用 CC BY 4.0；软件、校验器与可执行脚本采用 Apache-2.0，具体分配与第三方条件见根 `LICENSE`。

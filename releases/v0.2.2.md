# Standards 0.2.2

## 离线条款检索

- 支持在同一条款内重复指定最多八个 `--text-query`，所有条件必须同时命中；匹配文本可以位于不同规范正文行。
- 多条件结果新增 `term_matches`，提供每个查询词的原文行号和匹配片段；既有 `matched_line`、`matched_excerpt` 对应第一个条件。
- 保留单次正文查询、元数据查询、既有函数位置参数、结果字段和 `--offset` 分页语义；正文零命中仍返回成功的空结果，不等于规范不适用。

## 结构化错误反馈与恢复

- 新增可选 `--error-json`：检索失败时向 stderr 输出 `code`、`message`、`next_action`，区分 `INVALID_QUERY`、`SOURCE_MISSING`、`INTEGRITY_ERROR` 和 `IO_ERROR`。
- 在结构化模式下，`--limit` 和 `--offset` 的已解析越界值返回 `INVALID_QUERY`（退出码 1）；不启用该选项时保持原有 argparse 错误文本与退出码 2。
- 无效根目录归为输入错误并提示更正 `--root`；参数语法错误继续由 argparse 处理。增加对应回归以覆盖标准错误流及退出码。

## Agent 评测与交付行为

- 行为评测对比处于 `INCOMPLETE` 时，`success_fraction_delta` 为 `null`，不输出可能误导的部分成功率差值。
- 新增六个合成行为案例，覆盖检索零命中的适用边界、分页完整性、未执行检索、遇到反证的结论更新、远端副作用未知时的恢复，以及实际可运行产物的交付；关联测试与指南同步更新。

## 兼容与升级

- 发行集合版本由 0.2.1 升至 0.2.2；162 份现行规范正文的独立身份、内容和版本保持不变。
- 继续使用 Python 3.12，保留既有 Source 和 Agent Skill 消费入口、许可分配与完整性校验格式。上述新参数均为可选；已安装的 Skill 不因新发行而自动升级或改变项目采用决定。
- 新版安装前先确认完整性与目标 Agent 的安装路径；升级时将旧 Skill 目录移出发现范围，验证新版本后切换。需要恢复时，移出新目录并恢复旧目录。

## 获取与验证

- 发行附件为 `Standards-v0.2.2-source.zip`、`Standards-v0.2.2-agent-skill.zip`、`BUILD-REPORT.json` 和 `SHA256SUMS.txt`。
- 从同一正式发行获取文件并核对完整性清单；解包后执行包内验证和条款查询。完整步骤见[离线使用指南](https://github.com/ranzevor/Standards/blob/v0.2.2/guides/OFFLINE.md)与[Skill 安装指南](https://github.com/ranzevor/Standards/blob/v0.2.2/guides/SKILL-INSTALLATION.md)。

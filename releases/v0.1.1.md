# Standards 0.1.1

版本日期：2026-10-31。

## 软件仓库治理与采用

- 增加软件仓库采用指南，连接仓库状态、协作入口、质量门禁、发布与归档要求。
- 提供通用 Pull Request、缺陷 Issue、提案 Issue 和平台控制模板，以及公开发行、私有开发和归档仓库的合成示例。
- 增加可选的软件仓库 profile、JSON Schema 与离线校验器，检查状态和文件关系、工作流 Action 固定、证据目录边界及公开协作入口。

## 首次使用、跨平台与安全入口

- 补全从 GitHub Release 下载、核对 SHA-256、解压 Source 包、执行包级校验和最小条款查询的首次使用流程。
- Windows 与 Ubuntu 命令显式启用 Python UTF-8 模式；CLI 运行协议固定使用 UTF-8/LF 输出。
- 下载、摘要或校验失败时停止后续解压与执行；安全报告增加 GitHub 私密漏洞报告入口，并保留邮件备用渠道。

## 校验与自动化维护

- GitHub Actions 依赖更新到固定提交，并保持最小工作流权限。
- 离线校验覆盖软件仓库 profile、Action 固定、有效忽略规则及实施证据跟踪边界。
- 发行候选继续执行登记与索引一致性、全仓合同、回归测试、四个本地制品及解包后 Agent Skill 校验。

## 兼容性

- 发行集合版本由 0.1.0 升至 0.1.1；162 份规范正文的版本、稳定 ID、条款 ID 与内容身份不变。
- 软件仓库 profile 是可选采用接口，不为既有采用项目增加默认强制义务。
- 现有 Source 与 Agent Skill 消费流程保持兼容；采用项目仍按已固定的单份规范身份决定是否升级发行集合。

## 发行制品与许可

- 正式发行提供 Source、Agent Skill、`BUILD-REPORT.json` 和 `SHA256SUMS.txt` 四个附件，并为附件生成 GitHub artifact provenance。
- 规范、文档与数据采用 CC BY 4.0；软件、校验器与可执行脚本采用 Apache-2.0，具体分配与第三方条件见根 `LICENSE`。

# Standards 0.1.0

版本日期：2026-10-30。

## 规范与采用

- 提供 162 份已采用的中文规范，覆盖 L0–L6、十六技术领域和项目治理。
- 使用稳定文档 ID、准确版本、路径、SHA-256 和条款 ID 定位规范；提供条款、引用、依赖与跨领域接口索引。
- 提供 20 份项目治理英文译文，以及项目采用、升级、反馈和维护指南。
- README 徽章统一使用标准 Shields.io，并核对展示对象、状态、跳转与实际依据。

## 行为指南与工程工具

- 提供表达质量、授权内推进、产物用途、完成状态、按需加载和行为评测六组指南及 36 个场景。
- 提供行为评测、有限合同检查、规范检索、内容完整性验证与跨平台离线消费者工具。
- 工具使用 Python 3.12 标准库；规范与索引采用 UTF-8/LF。

- 提供 Source、Agent Skill、BUILD-REPORT 和 SHA256SUMS 四个发行附件。
- 构建绑定准确 Git 提交及文件集合；发布核验标签身份、附件集合和下载字节，重复执行复用相同发行。

# Standards 0.2.1

## 安装与首次使用

- 中文和英文入口提供可直接交给 Agent 的安装提示词，从正式 Release 获取完整 Skill，按当前 Agent 的发现机制选择项目级安装位置。
- 补充首次查询、升级、恢复和移除流程，保持业务源码、既有采用决定及其他 Skill 不变。
- Windows 与 Linux 本地安装工具检查所选作用域，在发现目录外暂存并校验完整内容，再以不可覆盖的目录移动完成安装。
- 目录保护覆盖创建、复制、复验、移动和清理，修复父目录重定向与替换竞态；复制失败不留下可发现的残缺安装，重试不覆盖既有目标。

## 检索与命令修复

- 离线检索新增可选 `--offset`，可连续读取全部过滤结果；默认偏移为零，保留原有参数、JSON 字段和登记顺序。
- 使用示例先限定文档或领域再检索正文；脚本和返回路径按实际 Skill 根目录解析，不要求切换项目工作目录。
- 修复 PowerShell 首次使用流程的失败传播，下载、解压或 Python 命令失败后停止后续操作，并恢复工作目录和调用方错误偏好。

## 任务案例与兼容性

- 新增差异审查、最小缺陷修复和发行判断三个任务案例，复用现有行为评测入口，按实际 Agent 实现分别检查显式和自然调用。
- 明确 0.2.x 的兼容修订范围；集合版本从 0.2.0 升至 0.2.1，162 份现行规范正文及各自版本保持不变。
- 保留 Source 与 Agent Skill 两种发行包、现有许可分配及原工具入口。

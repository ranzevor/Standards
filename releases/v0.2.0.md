# Standards 0.2.0

版本日期：2026-11-01。

## Agent Skill 消费

- 完善 `ranzevor-standards` 的触发描述、任务流程与渐进式加载；按项目真实任务和既有采用决定选择相关规范。
- 新增 Skill 任务选读指南，提供工程、Agent、项目治理、安全及验收任务的准确检索入口。
- `lookup.py` 增加 `--text-query`，对已校验规范条款做精确文本检索，输出命中行、条款 ID、各自版本和来源摘要，原查询选项保持兼容。
- 保留 Agent Skills 标准目录结构；由已有 `SKILL.md`、`scripts/` 和 `references/` 承载全部能力，不增加服务或宿主级拦截组件。

## 验证与采用

- 新增四个 Skill 消费合成行为场景，覆盖候选与采用区分、零命中、规范与发行版本区分、包校验与真实行为验证的差别。
- 扩充 Source 与 Agent Skill 的独立离线消费者测试，核对正文精确检索及原有条款定位。
- 在质量检查中接入固定来源提交的官方 `skills-ref validate`。实际 Agent 的行为验收仍基于真实宿主执行记录、产物和独立判据。
- 沿用现有采用、升级和问题反馈记录，不增加外部状态服务。

## 兼容性与制品

- 集合版本从 0.1.2 升至 0.2.0；162 份现行规范的稳定 ID、各自版本和 SHA-256 保持不变。
- 分离规范正文版本与发行集合版本的校验，支持准确跨次发行；Tag 名称校验与发行集合版本规则一致，并通过从已发布 v0.1.2 到 v0.2.0 的完整发布回归。
- 正式发行仍提供 Source、Agent Skill、`BUILD-REPORT.json` 和 `SHA256SUMS.txt` 四项制品，维持原权利分配和完整性机制。

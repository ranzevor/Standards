# Standards v0.1.0

本目录包含 **162 份已采用规范**，版本统一为 **0.1.0**，生效日期为 **2026-10-30**。每份规范使用稳定文档标识，正文与[规范登记](../registry/standards.json)一一对应。

从[完整规范目录](../INDEX.md)按领域选择文档，再按[项目采用指南](../guides/ADOPTION.md)确定适用条款、必要依赖和具体配置。条款的定位、输入输出和检查范围见[条款索引](../registry/requirements.json)。

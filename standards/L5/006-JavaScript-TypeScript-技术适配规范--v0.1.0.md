**文档ID：** STD-L5-006　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 定位、适用与非目标

本画像提供本体系对 JavaScript / TypeScript 的技术适配合同：将L3/L4的状态、数据、权限、兼容与验收要求落实到真实语言/运行时/工具入口。它不是重写完整语言标准或某框架教程，也不要求全部项目采用此栈。列出的固定资料版本用于可复核技术命题和示例，不构成全组织版本推荐、所有版本支持承诺或当前安全状态保证。项目L6必须选择实际受支持版本、发行/维护政策和具体平台，不得用画像存在替代该决定。

“必须/不得”为采用且触发时必要要求；“应/建议”偏离需理由与等价保障；“可/示例”不增加功能或权限。运行时是实际执行对象，工具链包括编译/解析/构建工具，宿主/target是提供API、ABI与系统能力的环境。类型/静态检查、有限样例、隔离目标与真实业务验收分别报告。

通用依赖：[L3通用工程](../L3/001-通用工程规范--v0.1.0.md)、[L6采用接口](../L6/001-项目采用与实现验收接口规范--v0.1.0.md)。具体领域按真实组成组合采用；技术参考不自动生效。逐命题来源见[十类适配来源](../../sources/stack-adapters.md)，本画像中组织工程动作由其反例及不变量说明理由，不冒称官方规范逐字规定。

## STK-01 宿主、模块与构建身份

- **适用条件与主体：** 浏览器脚本、Node程序或发布包的构建/维护者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须固定ECMAScript目标、TypeScript编译器/选项、宿主版本、模块格式和入口。Node包明确type、.mjs/.cjs及exports；浏览器打包结果与Node解析分开验。锁文件、实际解析树、构建脚本及转译输入构成制品身份，不能只登记package.json。
- **失败、并发、未知与恢复：** 条件导出或loader变化可使同源码加载不同对象；错宿主/模块格式应受控失败，不能静默落入开发源码。跨版本消费先查实际入口而不是latest标签。
- **产物与可观察验收：** 在干净支持环境解析同一包入口，比较构建清单、exports路径与实际加载对象；CJS/ESM各自按承诺测试。
- **正确案例：** 明确type=module的.mjs入口被Node加载为所声明API。
- **直接失败反例：** 测试src入口成功却发布缺dist的包。
- **合法邻例：** 仅浏览器静态脚本无需支持Node CJS，但须声明该范围。
- **来源与消费接口：** JS-01,JS-02；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

## STK-02 运行时输入、数值与序列化

- **适用条件与主体：** 接收JSON、DOM、IPC、网络或插件数据的边界实现者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须在运行时按业务合同验证类型/范围/单位；TypeScript断言和类型擦除不能验证外部数据。区分undefined、null、缺字段、NaN、负零和整数精度；金额采用所选精确表示，BigInt到JSON另定编码，不静默截断。
- **失败、并发、未知与恢复：** 坏字段不得通过as声明变合法；合法等价编码先按合同归一化。新字段或未知枚举保留/拒绝策略须与消费者兼容，不能把所有falsy值当空。
- **产物与可观察验收：** 输入0/false/空串/缺失/超安全整数、未知字段与合法非ASCII值，核精确输出及拒绝分类。
- **正确案例：** 对象count=0保持合法且不被默认值覆盖。
- **直接失败反例：** 把远端unknown强转为业务类型后直接执行扣减。
- **合法邻例：** 只处理展示浮点且无精确金额义务时可按已声明容差。

## STK-03 Promise、事件与取消后的权威

- **适用条件与主体：** 异步UI、Node任务和远程SDK的实现者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须观察Promise拒绝、资源所有权与任务终态；await不是取消或事务。AbortSignal只消费具体API承诺，导航/账号/对象变化后按身份/世代过滤旧结果，外部写入超时按L4核原意图。
- **失败、并发、未知与恢复：** 取消旧请求不保证服务器未提交；旧回调不能覆盖新状态。重复事件和重挂载不得无依据重复业务效果；关闭流和订阅后按API释放，不用unhandled rejection吞失败。
- **产物与可观察验收：** 注入A/B反序完成、取消后迟到、流中断和提交丢响应，比较当前权威状态、效果数与未决记录。
- **正确案例：** 较旧搜索回包不覆盖新查询。
- **直接失败反例：** 用户关弹窗便显示远端交易已撤销。
- **合法邻例：** 只读幂等查询可按预算重复，不一律禁止重试。
- **来源与消费接口：** JS-01,JS-04；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

## STK-04 共享状态、能力与依赖执行

- **适用条件与主体：** 使用Worker、共享缓冲、插件、构建脚本或第三方包时的维护者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须区分单事件循环任务交错、Worker消息与共享内存；共享可变状态按实际Atomics/消息/锁契约处理。第三方脚本、install脚本、动态import与模板插值属于执行边界，类型系统不授予能力；路径/命令/HTML按目的验证。
- **失败、并发、未知与恢复：** 依赖解析失败不能回退不明同名包；构建权限不交给不可信输入。超时后仍活动的Worker须明确终止/协作停止与在途效果边界。
- **产物与可观察验收：** 锁定树变化有差异，错来源依赖拒绝；两个异步保存和跨Worker写不会破坏所选不变量。
- **正确案例：** 不可共享状态通过结构化消息和版本前提传递。
- **直接失败反例：** 以“JavaScript单线程”否认await间竞态或Worker共享写。
- **合法邻例：** 没有共享内存的纯函数库不必引入Atomics。
- **来源与消费接口：** JS-01,JS-02；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

# L5 C# / .NET 技术适配规范

**文档ID：** STD-L5-002　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 定位、适用与非目标

本画像提供本体系对 C# / .NET 的技术适配合同：将L3/L4的状态、数据、权限、兼容与验收要求落实到真实语言/运行时/工具入口。它不是重写完整语言标准或某框架教程，也不要求全部项目采用此栈。列出的固定资料版本用于可复核技术命题和示例，不构成全组织版本推荐、所有版本支持承诺或当前安全状态保证。项目L6必须选择实际受支持版本、发行/维护政策和具体平台，不得用画像存在替代该决定。

“必须/不得”为采用且触发时必要要求；“应/建议”偏离需理由与等价保障；“可/示例”不增加功能或权限。运行时是实际执行对象，工具链包括编译/解析/构建工具，宿主/target是提供API、ABI与系统能力的环境。类型/静态检查、有限样例、隔离目标与真实业务验收分别报告。

通用依赖：[L3通用工程](../L3/001-通用工程规范--v0.1.0.md)、[L6采用接口](../L6/001-项目采用与实现验收接口规范--v0.1.0.md)。具体领域按真实组成组合采用；技术参考不自动生效。逐命题来源见[十类适配来源](../../sources/stack-adapters.md)，本画像中组织工程动作由其反例及不变量说明理由，不冒称官方规范逐字规定。

## STK-03 Task、取消与资源

- **适用条件与主体：** 异步/流/连接生命周期实现者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须观察Task失败/完成并按API传CancellationToken；取消是合作通知，不强制停止或撤销外部效果。IDisposable/IAsyncDisposable按拥有者完成后释放，CancellationTokenSource.Dispose与发出Cancel不同。
- **失败、并发、未知与恢复：** 取消、超时或Task失败后核仍活动操作和权威写入结果；异步清理失败保留影响。不能fire-and-forget后把请求返回当已完成。
- **产物与可观察验收：** 注入取消前后/清理失败/迟到结果，观察Task终态、句柄和原意图状态。
- **正确案例：** 等待实际任务清理并保持远端未知。
- **直接失败反例：** Cancel返回就宣称付款回滚并释放仍在用资源。
- **合法邻例：** 不支持取消的API可明确合同，不伪造可强停能力。
- **来源与消费接口：** NET-01；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

## STK-04 共享状态、反射与原生能力

- **适用条件与主体：** 并发/插件/PInvoke/AOT实现者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须按锁/Interlocked/消息等实际机制保护复合不变量，线程安全集合不保护跨步骤业务。反射、动态加载、PInvoke及构建任务是信任边界；裁剪/AOT影响反射和序列化时显式验证。
- **失败、并发、未知与恢复：** 锁竞争、取消、回调或旧世代不可越过目标控制；内存安全不证明对象授权或native调用安全。
- **产物与可观察验收：** 并发和旧回调夹具核状态，实际AOT/裁剪产物运行反射/序列化路径，原生库按RID验。
- **正确案例：** 复合扣减在明确事务或同步范围完成。
- **直接失败反例：** ConcurrentDictionary被当跨条目业务事务。
- **合法邻例：** 不使用动态加载的纯库不强制创建插件系统。

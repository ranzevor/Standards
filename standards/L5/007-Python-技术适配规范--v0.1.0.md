## 定位、适用与非目标

本画像提供本体系对 Python 的技术适配合同：将L3/L4的状态、数据、权限、兼容与验收要求落实到真实语言/运行时/工具入口。它不是重写完整语言标准或某框架教程，也不要求全部项目采用此栈。列出的固定资料版本用于可复核技术命题和示例，不构成全组织版本推荐、所有版本支持承诺或当前安全状态保证。项目L6必须选择实际受支持版本、发行/维护政策和具体平台，不得用画像存在替代该决定。

“必须/不得”为采用且触发时必要要求；“应/建议”偏离需理由与等价保障；“可/示例”不增加功能或权限。运行时是实际执行对象，工具链包括编译/解析/构建工具，宿主/target是提供API、ABI与系统能力的环境。类型/静态检查、有限样例、隔离目标与真实业务验收分别报告。

通用依赖：[L3通用工程](../L3/001-通用工程规范--v0.1.0.md)、[L6采用接口](../L6/001-项目采用与实现验收接口规范--v0.1.0.md)。具体领域按真实组成组合采用；技术参考不自动生效。逐命题来源见[十类适配来源](../../sources/stack-adapters.md)，本画像中组织工程动作由其反例及不变量说明理由，不冒称官方规范逐字规定。

- **产物与可观察验收：** 干净环境按固定输入获得同一受支持依赖集合；实际导入来自预定发行物而非工作目录旁的同名文件。

- **合法邻例：** 纯标准库脚本无需虚构第三方锁文件，但须固定解释器和源码。

## STK-03 上下文管理与资源终态

- **适用条件与主体：** 文件/连接/生成器/任务等资源拥有者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须定义所有权及close/with/async with/finally路径；异常和取消也释放本地资源。关闭文件不等于已按目标持久化，释放连接不撤销已提交事务，垃圾回收时机不是业务完成点。
- **失败、并发、未知与恢复：** 清理自身失败保留原异常与清理影响；子任务仍使用资源时不可先关闭并宣称停止。外部写入超时保留原操作身份。
- **产物与可观察验收：** 正常/异常/取消三路径观察句柄、锁和任务终态；文件持久承诺按实际文件系统另验。
- **正确案例：** with退出后本地文件句柄关闭，事务结果另核。
- **直接失败反例：** 删除对象引用便认为远程请求和后台线程已结束。
- **合法邻例：** 无需外部资源的纯函数不强制使用上下文管理器。
- **来源与消费接口：** PY-01,PY-03；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

## STK-04 asyncio、线程与共享可变状态

- **适用条件与主体：** 异步任务或线程/进程并发的实现者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须按所选运行时同步共享状态、观察子任务失败和取消完成。asyncio取消是协作异常注入；不得通常吞CancelledError后伪报成功。线程中的外部调用不因等待方超时自动停止；GIL不构成跨步骤业务互斥或持久事务。
- **失败、并发、未知与恢复：** 超时与取消后检查仍活动任务和旧回调，按目标幂等/栅栏恢复；TaskGroup等采用按版本和异常组合同处理。
- **产物与可观察验收：** 用受控事件而非只sleep注入旧世代回调、部分失败、取消清理和并发计数，核任务集合和权威状态。
- **正确案例：** finally记录本地清理，CancelledError仍向调用方传播。
- **直接失败反例：** wait_for超时就认定线程里的付款没有执行。
- **合法邻例：** 无共享状态且仅只读的协程可并发，不强制全局锁。
- **来源与消费接口：** PY-01；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

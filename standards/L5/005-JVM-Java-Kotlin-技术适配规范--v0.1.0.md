# L5 JVM（Java / Kotlin） 技术适配规范

**文档ID：** STD-L5-005　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 定位、适用与非目标

本画像提供本体系对 JVM（Java / Kotlin） 的技术适配合同：将L3/L4的状态、数据、权限、兼容与验收要求落实到真实语言/运行时/工具入口。它不是重写完整语言标准或某框架教程，也不要求全部项目采用此栈。列出的固定资料版本用于可复核技术命题和示例，不构成全组织版本推荐、所有版本支持承诺或当前安全状态保证。项目L6必须选择实际受支持版本、发行/维护政策和具体平台，不得用画像存在替代该决定。

“必须/不得”为采用且触发时必要要求；“应/建议”偏离需理由与等价保障；“可/示例”不增加功能或权限。运行时是实际执行对象，工具链包括编译/解析/构建工具，宿主/target是提供API、ABI与系统能力的环境。类型/静态检查、有限样例、隔离目标与真实业务验收分别报告。

通用依赖：[L3通用工程](../L3/001-通用工程规范--v0.1.0.md)、[L6采用接口](../L6/001-项目采用与实现验收接口规范--v0.1.0.md)。具体领域按真实组成组合采用；技术参考不自动生效。逐命题来源见[十类适配来源](../../sources/stack-adapters.md)，本画像中组织工程动作由其反例及不变量说明理由，不冒称官方规范逐字规定。

## STK-01 编译、运行与目标字节码

- **适用条件与主体：** Java/Kotlin工程的构建维护者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须分别锁定JDK编译器、运行时、Java语言级别/--release、Kotlin编译器/jvmTarget和依赖解析。JRE存在不证明javac可用，Gradle/Maven wrapper及插件亦为执行输入；同名JAR与类路径顺序影响实际类身份。
- **失败、并发、未知与恢复：** 目标类版本、模块/类路径或依赖冲突时受控失败；不得默认采用运行机器最新JDK特性而仍声称支持旧JVM。
- **产物与可观察验收：** 读取java/javac/kotlinc版本及产物class目标，按支持JVM消费同一发行包。
- **正确案例：** 编译明确--release并在承诺JVM运行。
- **直接失败反例：** 只装JRE便宣称已编译Java/Kotlin全部例。
- **合法邻例：** 纯Java库不必引入Kotlin；含Kotlin才核其编译/运行依赖。
- **来源与消费接口：** JVM-01；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

## STK-02 空值、相等性与协议数值

- **适用条件与主体：** 跨Java/Kotlin/JSON/数据库边界的实现者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。

- **必要机制：** 必须约定null、缺字段、平台类型、装箱/拆箱、数组/集合相等、字符编码和精确金额。Kotlin非空声明不能替代Java或反序列化边界验证；BigDecimal的数值比较与scale相关表示/equals按实际合同选用。
- **失败、并发、未知与恢复：** 空值解箱、溢出或未知枚举不得静默转默认业务值；兼容新旧字段时保留必要信息和可查询错误。
- **产物与可观察验收：** 合法0/false、null、非ASCII、同数异scale及未知字段输入逐个核返回/异常与持久结果。
- **正确案例：** 明确金额单位与舍入，而非经double构造后期望十进制精确。
- **直接失败反例：** 把Java平台类型当已验证的Kotlin非空值。
- **合法邻例：** 无金额业务不要求引入BigDecimal，但仍保持数值范围。
- **来源与消费接口：** JVM-01,JVM-02；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

## STK-03 Java内存模型与共享状态

- **适用条件与主体：** 线程、执行器、并发集合或共享状态的拥有者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须按JMM建立所需happens-before与原子边界；volatile可提供特定可见/排序关系，不使复合++或多字段业务不变量原子。使用锁/原子类/不可变消息时声明实际范围，不把线程安全容器等同整体事务。
- **失败、并发、未知与恢复：** 可见性、竞争和死锁按目标实际观察；线程超时或Future取消不证明在途副作用未发生，恢复消费L4权威状态。
- **产物与可观察验收：** 受控交错检查计数及多字段约束，核真正同步位置；不能以一次未复现竞争证明无竞争。
- **正确案例：** 复合更新在同一锁或已核CAS协议下完成。
- **直接失败反例：** volatile余额上进行无事务扣减并声称无竞争。
- **合法邻例：** 线程封闭不可变对象无需为形式新增全局锁。
- **来源与消费接口：** JVM-01；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

## STK-04 取消、异常与资源所有权

- **适用条件与主体：** 线程/协程/流/连接生命周期实现者。 仅实际具备该对象或已承诺能力时适用，不为满足文档新增不存在的功能。
- **输入、输出与权威：** 输入是准确源码/制品、有效项目合同、实际运行版本/配置及具体数据；输出为本条所列可检查工件和结果。权威由目标实现与原始输入证明，不能由类型标签、测试名或缓存摘要自证。
- **必要机制：** 必须处理interrupt、任务完成、异常传播和清理；AutoCloseable用适用try-with-resources，关闭合同不自动幂等。Kotlin协程取消是合作机制，需挂起点/主动检查并保留清理；不把Job.cancel或Future.cancel当远端事务撤回。
- **失败、并发、未知与恢复：** 旧任务可能继续使用资源，须等明确终态或由目标栅栏拒绝；清理异常和原失败分开保留。
- **产物与可观察验收：** 注入取消前/中/后及清理失败，观察本地资源释放、异常链、仍活动任务和外部状态。
- **正确案例：** 取消后核目标结果并按原意图恢复。
- **直接失败反例：** 取消Job便删除唯一状态并宣称旧线程不可能写。
- **合法邻例：** 短纯计算可正常完成而无需外部撤销；仍不能错报其终态。
- **来源与消费接口：** JVM-03,JVM-04；本条消费L3相应工程机制和实际L4合同，提供具体工具/API与失败边界给L6。真实检查按本条命令/观察点记录版本、输入、退出与日志；本仓文档结构检查不认证实现。

- **必要机制：** 必须核JAR实际类/资源、模块/服务发现、公开签名和运行行为；Kotlin元数据、默认参数及Java互操作影响消费者。JNI/本地库按目标OS/架构/调用约定/线程与所有权另验，不把字节码跨平台推广给原生依赖。
- **失败、并发、未知与恢复：** 缺服务资源或ABI不兼容时受控失败，回退程序不恢复已迁移数据；依赖重定位/打包需核许可和资源发现。

- **直接失败反例：** 只比较源码方法名就宣称二进制兼容。

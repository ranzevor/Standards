# L4 移动应用领域通用基线

**文档ID：** STD-L4-MOBILE-005　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

**领域：08 移动应用。** 领域序号表示分类，不表示优先级。

> 项目采用范围与实现验收分别记录；符合性由相应条款的实际执行证据判定。

本规范规定手机、平板移动应用共有的工程契约：应用可能被系统挂起或回收，设备能力和权限会变化，网络与后台运行机会不连续，已安装客户端也不会随服务端发布立即更新。因此，关键用户状态、操作结果、账号归属与恢复路径必须在这些变化中仍可辨认。本规范规定应验证的机制和结果，不指定语言、框架、SDK、商店或统一性能数值。

下表列出组合技术接口。项目按准确版本记录采用范围，并分别取得工程验收结果及发行授权。

## 目标与非目标

目标是在可回收进程、动态能力、间歇网络和旧安装端条件下保持用户工作/结果/主体可辨；非目标是强制双平台、账号/推送/离线架构或统一后台/性能数值。

## 术语、角色与共同验收规则

“必须/应/不得”为适用条件成立时的规范要求，“建议”为可有依据替代，“例如/示例”为非穷尽说明。每条由其适用对象的组件实现者负责，产品维护者固定支持合同，L5 固定平台/API/工具版本，验证者留准确环境与原始结果。每条输入/输出与权威细化附于条内；本地/OS/渠道/远端各只对其管辖事实确认，日志字段不认证真实权限或效果。

继承所引用的 [L3 通用工程规范 v0.1.0](../../L3/001-通用工程规范--v0.1.0.md) 的工程与证据接口，不由此推定正式采用。

所有适用条款的前置为支持组合、准确运行构建、相关账号/资源/操作身份及必要预算已可定位。并发或异步状态绑定实例、账号/工作区、文档/场景和操作代际；互不相关对象允许并行。超时/断连/取消请求不是效果未发生；有界重试及恢复应先核未知结果，已确认未提交或无副作用路径可按合同重试。时钟、预算和兼容版本由采用合同固定，不从统一毫秒阈值或 latest 页面推断。完成以条内目标与判据回读，正常/直接失败/合法邻例共同验证。

## 一 适用范围与分层边界

### 1 适用对象

适用于以手机或平板操作系统应用包交付的原生应用、跨平台应用，以及具有原生权限、生命周期或系统入口的混合宿主。嵌入 Web 内容同时采用适用的 Web 规范；仅在浏览器内运行的移动网页不因屏幕较小而自动适用全部移动宿主条款。可穿戴、车载、电视、专用工业终端等不同运行环境不得仅凭共享代码宣称已覆盖，实际纳入时由 L6 明确对象和差异。

项目按已批准的真实功能选择条款。单平台、离线单机、无账号、无推送、无后台任务、无商店分发均可能是合法形态。不强制同时支持 Android 与 iOS，必要验证缺少目标环境时保留“未验证”，不能改称“不适用”或删减已承诺能力。

下文“应”“不得”均为**拟议条文**，只在获批并被项目适用时产生相应义务。

## 二 应保持可区分的状态

下列区分用于实现和验收，不要求所有项目照抄一套枚举或另建台账。

- **运行状态：** 界面或 scene 可见、可交互、后台、挂起、系统回收、用户主动终止及设备重启不是同一个事件。后台入口可能没有可见界面，多窗口也可能有各自生命周期。[DM26](../../../sources/desktop-mobile-claims.md#dm26)[DM28](../../../sources/desktop-mobile-claims.md#dm28)
- **用户工作：** 尚未提交的输入、可恢复界面状态、满足本地持久承诺的数据、可丢缓存分开保存。内存对象、恢复快照和持久存储的恢复能力不同。[DM27](../../../sources/desktop-mobile-claims.md#dm27)
- **操作结果：** 未提交、已持久排队、已交给系统或服务、权威方已确认、失败、取消与结果未知分开。调度成功不等于实际执行，客户端超时不等于远端未发生。[DM29](../../../sources/desktop-mobile-claims.md#dm29)[DM30](../../../sources/desktop-mobile-claims.md#dm30)
- **访问条件：** 账号会话、设备解锁状态、OS 权限、限定资源授权、硬件能力、管理策略和服务端对象授权分别校验。任何一个条件不能代替其他条件。
- **交付身份：** 产品与渠道、包标识、发布签名、构建身份、扩展或组件、当前安装版本、本地数据格式及远端契约能够关联。渠道接收构建、可供下载、设备已安装与核心任务可用分别举证。[DM39](../../../sources/desktop-mobile-claims.md#dm39)[DM41](../../../sources/desktop-mobile-claims.md#dm41)

## 三 共同机制与验收契约

### M01 支持范围与设备能力

- **适用触发：** 声称支持某类手机、平板或移动 OS 的交付。
- **机制：** 在现有项目文档固定受支持 OS 版本区间、设备形态、必要架构与能力、渠道和关键任务。识别屏幕尺寸、折叠或分屏、输入方式、设备管理以及运行时组件差异中真正影响功能的部分；能力可用性应在使用时核实，不只以品牌、OS 名称或编译成功推断。
- **失败与恢复：** 必要能力不可用时展示可理解的限制或已约定替代路径，不伪造设备结果。扩大或缩小支持合同由有权主体决定，不由测试失败自动改写。
- **验收入口：** 将支持声明映射到产物、代表设备及核心路径；检查一个必要能力缺失的目标和一个正常目标。抽样说明风险依据及未覆盖边界，不机械遍历所有设备组合。

**输入、输出与权威补充：** 产品维护者输入支持画像，输出代表设备/能力任务矩阵；真实设备能力而非品牌为权威。

**正例：** 只承诺单平台手机范围可完整验收。

**具体目标入口与完成判据：** 最终包在正常/缺必要能力目标启动并完成核心任务，核画像。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM26](../../../sources/desktop-mobile-claims.md#dm26)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M02 界面生命周期与状态恢复

- **适用触发：** 存在导航、用户输入、多窗口或跨启动恢复承诺。
- **机制：** 将界面短暂状态、可恢复任务标识和业务持久数据分层，按目标系统生命周期恢复；恢复引用的对象前重验其存在、版本和当前账号权限。不可依赖退出回调或内存存活保证保存；多 scene 或窗口恢复不得抢占另一任务或重复提交业务。系统任务切换的显示快照另按 M20 控制，不与本条恢复状态混同。[DM26](../../../sources/desktop-mobile-claims.md#dm26)[DM27](../../../sources/desktop-mobile-claims.md#dm27)[DM28](../../../sources/desktop-mobile-claims.md#dm28)
- **失败与恢复：** 恢复快照过期、对象已删除或身份不匹配时，回到可解释的安全入口，并保留仍有权恢复的草稿。用户主动结束是否恢复按平台与产品契约处理，不承诺平台不保证的自动重启。
- **验收入口：** 在输入、导航和返回结果等待点触发旋转或尺寸变化、后台回收及冷启动，核对焦点、数据与提交次数；分别记录系统回收、手动强停和设备重启，不能互作全部故障证明。

**输入、输出与权威补充：** 场景维护者输入 scene/Activity/恢复引用，输出原上下文恢复；持久对象与当前权限为权威。

**正例：** 原账号有权对象恢复且不重复提交。

**具体目标入口与完成判据：** 系统配置变化、后台 am kill 实证和冷启动分别记录；Xcode 多场景入口核路由。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM26](../../../sources/desktop-mobile-claims.md#dm26)、[DM27](../../../sources/desktop-mobile-claims.md#dm27)、[DM28](../../../sources/desktop-mobile-claims.md#dm28)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M03 本地确认与可恢复操作

- **适用触发：** 用户编辑、下载、导入或其他需要跨进程死亡保留结果的操作。
- **机制：** 明确“保存”“完成”“已加入队列”的确认点；必要数据及操作身份在相应持久边界后才确认。采用实际存储引擎的事务、原子替换或恢复机制，不另写一套与数据库规范冲突的持久性保证。长任务保存可重入阶段，并处理重复进入和多个移动入口同时写入。
- **失败与恢复：** 低存储、写入中断或结果未知时，不显示假成功；保留原有效数据、可恢复输入或有据的部分进度。恢复时识别已完成阶段，防止重复扣减、上传、导入或覆盖；无法恢复的范围明确告知。
- **验收入口：** 在确认点前后及阶段边界注入存储失败或终止，重开回读内容、操作身份和副作用次数；以合法取消、重新提交和独立对象并行为对照。

**输入、输出与权威补充：** 操作维护者输入代次/操作ID/事务阶段，输出持久或未知结果；数据库提交/真实目标为权威。

**正例：** 确认点后重开仍读原数据且重入不重效果。

**具体目标入口与完成判据：** 目标持久引擎/应用导出，在确认前后注入失败或进程终止回读。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM27](../../../sources/desktop-mobile-claims.md#dm27)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M04 后台执行与调度机会

- **适用触发：** 功能要求应用离开前台后继续、延后或周期执行。
- **机制：** 说明任务是否必须即时、可延后、可中断、用户可感知，并使用所选平台允许的机制。调度请求、系统授予执行机会和最终完成分别记录；到期、取消、重入和资源条件改变时及时释放资源，保留必要检查点，并按平台契约报告完成或失败。[DM29](../../../sources/desktop-mobile-claims.md#dm29)[DM30](../../../sources/desktop-mobile-claims.md#dm30)
- **失败与恢复：** 系统未调度、强停后不运行、网络条件不足或执行窗口结束时维持真实的待办状态；前台可提供查看、继续或取消入口。不得用忙循环、虚假用途或不必要持续唤醒绕过后台限制，也不得承诺所有任务固定时刻必达。
- **验收入口：** 检查任务适用类型、有效配置和取消处理，在目标平台验证延迟、到期、重入及前后台交接。测试工具主动触发的任务只证明其触发路径，不证明自然调度时间保证。

**输入、输出与权威补充：** 后台者输入任务需求/条件，输出排队/机会/结果；OS 调度与业务权威分别观察。

**正例：** 实际完成后才显示成功。

**具体目标入口与完成判据：** dumpsys jobscheduler/WorkManager 或目标 Xcode BGTask 调试与自然运行分列。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM29](../../../sources/desktop-mobile-claims.md#dm29)、[DM30](../../../sources/desktop-mobile-claims.md#dm30)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M05 动态权限与最小设备访问

- **适用触发：** 访问照片、相机、麦克风、位置、通知、附近设备或其他受控能力。
- **机制：** 按具体功能解释访问目的，在合适上下文请求所需范围；每次使用前以及异步返回后核实有效授权。区分未询问、拒绝、受策略限制、一次或限定授权、精度受限和后续撤销；选择器或系统代理能满足需要时评估其更窄访问面。[DM31](../../../sources/desktop-mobile-claims.md#dm31)[DM32](../../../sources/desktop-mobile-claims.md#dm32)
- **失败与恢复：** 拒绝或撤销只影响相关功能；提供无需该能力的合法路径或准确限制。不得循环骚扰请求、将拒绝变成空白假成功，或以扩大权限掩盖实现错误。重新授权入口遵守平台限制，不能伪造系统设置已改变。
- **验收入口：** 从首次请求、拒绝、限定选择、授权后撤销到再次使用完整操作；核对真实清单与运行提示、使用对象和数据输出，而不只测试应用内开关。

**输入、输出与权威补充：** 能力者输入用途/实际许可范围，输出当前可访问对象；OS 有效授权非 toggle 为权威。

**正例：** 窄选择器满足功能时只用选定资源。

**具体目标入口与完成判据：** 真实权限 UI 首次/拒绝/限定/撤销后使用链，加清单与实际资源检查。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM31](../../../sources/desktop-mobile-claims.md#dm31)、[DM32](../../../sources/desktop-mobile-claims.md#dm32)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M06 设备会话与中断恢复

- **适用触发：** 使用采集、播放、定位、蓝牙、传感器或其他设备会话。
- **机制：** 设备会话绑定当前用途、生命周期和授权；处理锁屏、来电或其他会话竞争、路由变化、设备断开、精度或采样变化及 OS 中断。异步回调返回时核对会话仍有效，并以适用时间与质量标识区分新测量和缓存值。
- **失败与恢复：** 中断后停止无权采集或播放，释放占用；自动恢复仅在原意图和权限仍有效时进行，否则由可见入口重新开始。不得把无信号、旧坐标或空录音解释成真实测量，也不得因重连重复发送不可逆设备命令。
- **验收入口：** 在采集或播放中制造一项相关中断和权限变化，核对指示、资源释放、输出完整性与恢复后的会话归属；没有使用某类设备的应用无需虚构相应测试。

**输入、输出与权威补充：** 设备者输入用途/路由/采样时间与权限，输出当前会话数据；缓存不是当前测量。

**正例：** 用户明确选择新路由后合法继续。

**具体目标入口与完成判据：** 真机来电/拔耳机/设备断接与撤权，核 OS 指示、输出和资源释放。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM31](../../../sources/desktop-mobile-claims.md#dm31)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M07 应用数据与系统备份恢复

- **适用触发：** 保存用户内容、缓存、应用设置、待同步数据或提供导入导出。
- **机制：** 区分业务数据、可丢缓存、临时对象、日志与秘密，明确容器、保留和导出边界；系统选择器返回的资源按实际授权和对象语义使用，不假定永久稳定的普通文件路径。系统备份、设备迁移或应用重装可能带回的数据，与账号会话、密钥及权限能否恢复分别设计；按平台和渠道核实备份规则。恢复后在重新提供访问前核实有效删除或保留约束，避免旧备份恢复已应删除的数据；不许诺不可实现的永久保存。[DM42](../../../sources/desktop-mobile-claims.md#dm42)
- **失败与恢复：** 缓存驱逐不应删除未同步的唯一用户内容；资源授权失效时重新选择或恢复合法副本，不扩权搜盘。恢复的数据缺少可用密钥或账号时隔离待处理并说明路径，不把解密失败当空数据库覆盖，也不把旧令牌视为新设备自动获权。
- **验收入口：** 检查实际备份和排除配置，按采用方式执行缓存清理、所选资源失效、导出再读及有风险的备份恢复或设备迁移；未进行真实迁移不得以配置截图代替。

**输入、输出与权威补充：** 数据者输入业务/缓存/秘密与备份规则，输出可恢复闭包；恢复数据、账号和密钥分开。

**正例：** 可重建缩略图驱逐后重建。

**具体目标入口与完成判据：** 目标 backup/data extraction rules 与选定真实恢复/迁移入口、内容和引用回读。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM42](../../../sources/desktop-mobile-claims.md#dm42)、[DM34](../../../sources/desktop-mobile-claims.md#dm34)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M08 秘密与锁屏状态

- **适用触发：** 本地存储凭据、密钥、敏感材料，或使用设备解锁与生物识别。
- **机制：** 采用符合平台与威胁模型的秘密存储及访问属性，明确设备锁定、重启后首次解锁、身份变化和备份迁移时的可用性。硬件保护须按实际设备、算法及配置确认；生物识别或设备认证结果不替代服务端业务授权。[DM34](../../../sources/desktop-mobile-claims.md#dm34)[DM35](../../../sources/desktop-mobile-claims.md#dm35)
- **失败与恢复：** 秘密暂不可用或失效时延期、重新认证或走已批准恢复流程，不降级为明文、另存无保护副本或删除待恢复数据。不能把“密钥不可导出”扩大为“受控应用进程无法调用密钥”。
- **验收入口：** 在目标设备验证锁屏、重新解锁、选定失效条件及另一账号访问；检查日志、备份和导出不携带秘密，记录实际硬件能力而非模拟器推断。

**输入、输出与权威补充：** 秘密者输入保护属性/设备/算法，输出可用/失效/恢复；Keychain/KeyInfo 实际状态为权威。

**正例：** 锁定时延期而不明文降级。

**具体目标入口与完成判据：** 真机锁屏/首次解锁/选定失效，核真实 security level、日志/备份。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM34](../../../sources/desktop-mobile-claims.md#dm34)、[DM35](../../../sources/desktop-mobile-claims.md#dm35)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M09 离线网络与结果确认

- **适用触发：** 访问远端数据，或承诺离线读写与后续同步。
- **机制：** 固定可离线任务、数据新鲜度和用户可见状态；区分网络连接与服务实际可达。待同步项关联稳定操作身份、账号或租户、对象版本和必要权限，重连时重新核实；冲突、重复、乱序及远端未知结果按后端契约处理，不由 UI 自行发明覆盖规则。[DM33](../../../sources/desktop-mobile-claims.md#dm33)
- **失败与恢复：** 弱网、切网、受限流量或服务失联时实行有界重试和可见待办；敏感副作用的未知结果按既定后端契约，通过已验证的权威查询或可靠幂等／去重回执恢复；幂等路径须保持原账号、原操作身份及相同参数，并在已验证的去重与结果保留边界内执行，不能只凭设置一个 key 宣称恰好一次。缺少可靠结果确认或防重保证时保留未知，不因超时盲目重放。在线专用功能可明确暂不可用，合法本地工作不应被无关联网检查阻断。
- **验收入口：** 在请求发送前、远端已接收但响应丢失、离线编辑及重连冲突处断网，核对本地与远端状态、账号和提交次数；普通断网模拟不能替代全部真实无线网络特性测试。

**输入、输出与权威补充：** 同步者输入原主体/操作ID/参数/版本，输出本地和远端各状态；原操作权威回执为结果。

**正例：** 可靠防重窗内同请求取回原结果。

**具体目标入口与完成判据：** 隔离服务提交后丢响应，重启重连并核效果次数/回执身份及去重窗口。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M10 账号切换与异步身份归属

- **适用触发：** 有登录、多账号、租户、工作资料或共享设备场景。
- **机制：** 缓存、离线队列、草稿、后台任务、下载、通知路由和回调都保留其身份归属。切换或退出时隔离旧会话，失效旧异步操作对当前界面的写入权；待同步项按数据保留与用户选择处理，不自动改投新账号。服务端撤权与本地退出分别确认。
- **失败与恢复：** 旧账号结果迟到不得进入新账号视图或使用新令牌重发。保留有权恢复的未提交工作，但不得在退出后继续向原账号执行不再获准的敏感操作；无法撤回的已提交操作保留真实结果查询路径；按已批准事务条件仍须完成的操作遵守其撤销边界，不把本地退出一概当作撤销既有权益。
- **验收入口：** 账号 A 离线产生任务，切到 B 后让 A 的网络、后台或通知回调到达，再重启；核对缓存、通知内容、队列和远端写入均无串号，并验证切回 A 的合法恢复。

**输入、输出与权威补充：** 会话者输入原主体/代际，输出隔离缓存/队列/回调；OS 用户不是应用账号。

**正例：** 切回 A 并重获权可恢复其工作。

**具体目标入口与完成判据：** A 离线→B 登录→迟到 worker/通知/网络→重启，检查实际 UI/存储/远端。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M11 深链与外部系统入口

- **适用触发：** URL 链接、登录回调、分享导入、文件打开或其他外部激活应用的入口。
- **机制：** 将入口参数视为不可信数据，限定允许的路由、参数和资源；验证域名关联、调用来源或会话绑定等适用条件，但不把链接验证当作对象授权。路由在冷启动、已运行和多窗口情形下均须确认当前身份及目标；敏感或破坏性动作按已有业务授权与确认合同执行。[DM36](../../../sources/desktop-mobile-claims.md#dm36)[DM37](../../../sources/desktop-mobile-claims.md#dm37)
- **失败与恢复：** 关联失败、过期回调、恶意参数或目标无权访问时拒绝相应操作，保留安全返回路径，不自动切换账号、泄漏对象内容或转向任意外部地址。合法但需登录的链接可保存最小必要上下文，在认证后重新校验；已批准的匿名访问和合法共享不应被无关登录要求阻断。
- **验收入口：** 从系统真实入口测试合法链接、伪造或重复回调、错误账号、缺失对象及恶意参数；同时验证冷启动和已有任务不会造成重复操作或丢草稿。

**输入、输出与权威补充：** 入口者输入域/路由/原会话绑定，输出当前有权目标；关联验证不作对象授权。

**正例：** 合法匿名/共享链接按其权利打开。

**具体目标入口与完成判据：** pm get-app-links 与真实 VIEW/Universal Link；冷/热/多场景错账号和重复回调。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM36](../../../sources/desktop-mobile-claims.md#dm36)、[DM37](../../../sources/desktop-mobile-claims.md#dm37)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M12 通知与独立系统组件

- **适用触发：** 推送、本地通知、组件、扩展、快捷入口或其他独立于主界面的运行单元。
- **机制：** 组件与主应用使用明确的权限、共享数据和版本契约；通知负载最小化，打开后再查当前有权访问的数据。通知许可、设备注册信息、服务端接收、系统展示和用户完成动作分别记录；重装、账号切换或注册变化时维护对应关系，不把投递信息当持久身份。
- **失败与恢复：** 通知被拒、延迟、重复或丢失时仍有与产品合同相符的应用内查询路径，不声称已读或业务必达。锁屏、旧账号或过期组件不得泄漏敏感内容；共享数据不兼容时受限读取或提示更新，不破坏数据。
- **验收入口：** 真实目标系统上验证通知拒绝、重复或迟到、账号切换后点击、设备重装后的注册变化，以及所选组件独立启动；无通知功能的应用不需补建推送基础设施。

**输入、输出与权威补充：** 通知者输入许可/注册/负载/主体，输出投递阶段和获权路由；token 非持久身份。

**正例：** 公开最小摘要可展示后重查对象。

**具体目标入口与完成判据：** 真机真实通知拒绝/重复/迟到/换账号/重装，核应用内查询和组件独立启动。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM30](../../../sources/desktop-mobile-claims.md#dm30)、[DM31](../../../sources/desktop-mobile-claims.md#dm31)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M13 混合宿主与原生能力桥

- **适用触发：** WebView、远端页面、脚本或跨信任组件能够调用宿主能力。
- **机制：** 明确信任来源与导航边界，桥接口限定操作、参数、身份及权限；将原生能力与网页可见性、当前来源和会话绑定。外部内容、子框架或导航变化不能继承先前可信页面的广泛访问。Web 内容本身继续执行适用 Web 安全、状态和发行规范。
- **失败与恢复：** 来源变化、桥版本错配、应用进入受限生命周期或权限撤销时拒绝失效调用并释放资源；保留可恢复用户工作，不为修复页面失效而开放任意文件、通用命令或不受限原生接口。
- **验收入口：** 注入外域导航、过期桥回调、账号切换及权限撤销，验证只能执行仍获准的动作；同时验证可信内容的合法限定能力不会被一概禁用。

**输入、输出与权威补充：** 桥者输入可信内容/帧文档与权限，输出最小原生能力；不能信任消息 URL。

**正例：** 受控可信内容限定能力正常使用。

**具体目标入口与完成判据：** 目标 WebView 外域 iframe/导航/旧回包；addJavascriptInterface 无帧 origin 认证时隔离或不暴露敏感桥。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM38](../../../sources/desktop-mobile-claims.md#dm38)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M14 触控显示与多输入适配

- **适用触发：** 提供移动交互界面。
- **机制：** 核对安全显示区域、屏幕尺寸与姿态变化、系统栏、软键盘遮挡和实际支持的分屏或折叠模式。触控目标、手势冲突、系统返回和焦点保持应让核心任务可完成；涉及手势、外接键盘、指针或输入法时保留其真实语义，不把组合输入或滚动误作提交。
- **失败与恢复：** 布局变化不能丢弃已输入内容、把确认按钮遮至不可达或将系统返回等同不可撤销提交。非必要方向或形态可明确不支持，但不以锁定布局掩盖已承诺设备上的不可操作状态。
- **验收入口：** 在实际支持的代表显示条件下完成输入、校验错误、确认、取消和返回；覆盖大字体或缩放、键盘出现及相关旋转或窗口变化，记录操作过程而不只交付静态截图。

**输入、输出与权威补充：** 交互者输入窗口/键盘/姿态/文本事件，输出可达布局/提交；组合确认不是业务提交。

**正例：** 大字/键盘下确认和取消仍可达。

**具体目标入口与完成判据：** 代表设备旋转/分屏/键盘/系统 Back 与真实 IME，核草稿/效果次数。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM27](../../../sources/desktop-mobile-claims.md#dm27)、[DM43](../../../sources/desktop-mobile-claims.md#dm43)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### M15 可访问任务与辅助技术

- **适用触发：** 面向用户的界面及项目已选可访问性要求。
- **机制：** 依据目标平台和 L6 选定的标准范围提供名称、角色、状态、顺序和可操作语义；动态状态与错误可被感知，焦点不被无端夺走，关键操作有适用的非复杂手势路径。原生、Web 内容及系统弹层之间的辅助技术体验作为一条任务链核对，不将 DOM 检查直接当作原生语义证明。[DM44](../../../sources/desktop-mobile-claims.md#dm44)[DM43](../../../sources/desktop-mobile-claims.md#dm43)
- **失败与恢复：** 读屏或其他已选辅助技术无法识别关键状态、完成操作或恢复错误时，按实际影响修复或提交明确例外；不能以自动 audit 通过覆盖人工任务失败，也不凭无障碍标签宣称全应用符合某等级。
- **验收入口：** 在目标设备用所选辅助技术与系统设置完成至少各类关键任务及其错误恢复，并附相应自动检测结果；具体等级、输入技术和场景依项目适用性确定，不强制所有设备、辅助技术两两全测。

**输入、输出与权威补充：** AT 适配者输入真实语义/系统设置，输出可完成任务；真实 AT 不被 audit 替代。

**正例：** 读屏能感知保存失败并修正。

### M16 能耗热状态与资源压力

- **适用触发：** 有持续计算、渲染、网络、采集或面向用户的资源预算。
- **机制：** 对启动到可操作、交互响应、长时内存、存储、流量、后台唤醒、能耗与热影响选择实际预算和代表负载；在资源或热状态受限时调整并发、质量或调度，保留用户任务与安全边界。应用回到前台、取消操作或切换任务后正确释放不再需要的设备与资源。

**输入、输出与权威补充：** 资源者输入设备/电源/温度/负载/预算，输出分布和长时趋势；物理结果须真机观察。

**正例：** 有界退让并保留用户数据。

### M17 包身份与渠道实际制品

### M18 更新迁移与安装状态恢复

- **适用触发：** 支持已有安装升级、数据格式演进、恢复备份或渠道迁移。

**输入、输出与权威补充：** 迁移者输入旧/新格式和全部写者，输出可重入阶段/恢复；安装成功非数据健康。

**具体目标入口与完成判据：** 真实支持旧包升级、首启中断/重入、数据与账号回读；备份恢复另列。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

### M19 旧客户端与远端变更

### M20 隐私声明与可控诊断

- **适用触发：** 处理个人或敏感数据、敏感界面或向系统复制／共享内容，接入第三方 SDK、采集遥测、崩溃材料或生成支持包。
- **机制：** 将实际数据流、SDK 行为、系统权限和所选渠道触发的隐私声明对应；平台清单、用途声明、渠道数据披露与运行流量是不同证据。[DM46](../../../sources/desktop-mobile-claims.md#dm46)[DM46](../../../sources/desktop-mobile-claims.md#dm46)[DM47](../../../sources/desktop-mobile-claims.md#dm47) 诊断关联构建、系统、必要设备条件和错误阶段，收集范围、保留与接收方符合授权，默认不包含凭据、完整用户内容或无必要的精确设备轨迹。处理敏感界面或主动向系统复制／共享内容时，应识别任务切换快照、屏幕采集与非安全显示、系统剪贴板及其预览的传播边界；按敏感度、真实用户任务和所选平台能力采用相称的快照遮蔽、采集保护、最小复制或敏感预览标记等控制，记录生效条件及剩余限制。预览遮蔽不等于阻止全部读取，不要求各平台具有相同 API，也不一律禁止公开内容截图或获准的复制／共享。[DM48](../../../sources/desktop-mobile-claims.md#dm48)[DM49](../../../sources/desktop-mobile-claims.md#dm49)[DM50](../../../sources/desktop-mobile-claims.md#dm50)

**正例：** 公开内容截图和获准复制可用。

**具体目标入口与完成判据：** 最终包数据流/导出检查、系统任务快照/剪贴板预览/屏幕采集合成样本，对照渠道材料和符号。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

## 四 验收组织与证据粒度

项目应复用现有仓库、CI、测试记录和发行系统，不为本基线另建竞争台账。条款适用决定必须能解释“不适用”的真实原因；验收入口中的账号、限定授权、组件和检测工具仅按真实功能及所选平台能力适用，应做而缺设备、缺授权、暂缺工具、尚未实现或测试失败的检查不得改标“不适用”。

| 验证层 | 入口与主要证据 | 能证明的范围及边界 |
| --- | --- | --- |
| 静态与可复现构建 | 固定源码、锁定依赖、清单与能力、包身份、桥接口、数据和任务契约 | 可检查结构及产物对应；不能证明系统真的授予权限或执行后台任务 |
| 局部自动化与契约 | 状态转换、账号作用域、操作身份、冲突、迁移、输入校验、错误注入 | 可验证可控条件下的逻辑；Mock 成功不代表服务端或设备真实结果 |
| 模拟器或等价虚拟目标 | 界面、启动、路由、可自动化生命周期、部分故障与设备配置 | 对其实际支持能力给出结果；不默认等同真机签名、传感器、调度、无线电与能耗 |
| 真机与系统交互 | 最终分发物安装、权限与撤销、锁屏、系统入口、所用能力、辅助技术、资源压力 | 记录实际设备型号、OS build、渠道及有效设置；单台成功不自动覆盖全部支持设备 |
| 演进与用户结果 | 支持期内升级与恢复、账号切换、旧新服务组合、核心任务及异常恢复 | 验证完整用户契约和数据归属；渠道“已接受”或 CI 绿色不能替代 |

每个结论至少可关联：被测构建或分发物身份、相关配置及渠道、设备或替代环境、数据与账号类型、适用条款、真实步骤或命令、实际输出、预期和偏差、恢复结果及未覆盖条件。服务端、系统或渠道还未确认的结果单列为未知，不推定成功或失败。

核心用户链路由 L6 按真实需求选择，例如创建并恢复一项本地工作、完成一次账号隔离的同步、从系统入口打开获权对象，或在中断后恢复一次合法设备会话；这些是选择示例，不是所有应用必须具备的功能清单。性能、无障碍等级、安全控制集与支持矩阵也由已有需求与风险决定，不从本文自动派生统一数量门槛。

## 五 直接失败场景与合法邻例

下表为待项目实现的检查契约，**不表示任何项目已经运行这些测试**。每项失败场景与同条合法邻例应一起审查，防止实现通过过度拒绝制造表面安全。

| 场景与条款 | 失败输入和检查入口 | 应观察的失败处理或恢复 | 合法邻例 |
| --- | --- | --- | --- |
| F01 M01 | 只测手机却宣称平板分屏可用；对照支持声明与真机任务 | 声明所需证据缺失准确列出，界面失败不能算通过 | 仅承诺指定手机形态且如实验收 |
| F02 M02 | 输入后退后台并被回收；恢复代码只读内存 | 按约定恢复已保存草稿，未恢复部分不伪装完成 | 用户主动取消后不恢复已明确丢弃的临时输入 |
| F03 M03 | 提示已保存后进程终止；回读无数据或重入重复导入 | 确认点与真实持久一致，重复阶段不重复副作用 | 暂存中明确显示尚未完成 |
| F04 M04 | 调度请求返回成功便通知同步完成；到期后仍忙循环 | 待执行与已完成分开，到期释放并可继续 | 用户可见合法持续任务采用适用平台机制 |
| F05 M05 | 选择少量照片后仍遍历全部图库；操作中撤权 | 限定范围生效，撤权不扩权且无隐蔽读取 | 需要全量媒体且真实获准的功能按范围使用 |
| F06 M06 | 耳机断开或来电后继续向外放敏感音频；重放回调 | 中断按约定处理，恢复前确认当前会话与路由 | 用户明确选择新输出设备后继续播放 |
| F07 M07 | 未同步的唯一作品放缓存；清理或恢复后变空 | 唯一用户内容不被当缓存丢弃，恢复缺失可辨认 | 可重建缩略图被系统回收后重建 |
| F08 M08 | 锁屏时密钥不可用便保存明文凭据；检查存储 | 不明文降级，解锁或重新认证后有据恢复 | 无秘密的离线工具不必创建密钥系统 |
| F09 M09 | 远端已执行但回包丢失，重连后盲目重复交易 | 经已验证的权威查询或可靠幂等回执恢复；无结果确认或防重保证则保留未知，不盲目重放 | 无独立查询端点，但原账号、操作身份及相同参数在有效去重和结果保留边界内返回原结果 |
| F10 M10 | A 离线写入，切到 B 后队列自动用 B 令牌上传 | 队列归属仍为 A，不泄漏、不串写 | 切回 A 并重新获权后继续原工作 |
| F11 M11 | 验证过的域名链接引用无权对象，或重放旧登录回调 | 对象与会话重新校验，不能自动获权或重复动作 | 合法匿名链接或当前账号有权的链接正常打开 |
| F12 M12 | 旧账号通知在新账号点击后展示旧内容；模拟迟到 | 路由先鉴权，锁屏负载最小化，投递不冒称完成 | 公开非敏感通知可按合同展示 |
| F13 M13 | 可信页跳转外域仍持有相机或本地数据桥 | 原来源能力失效，异步回调不越权 | 当前可信页面调用获准的限定能力 |
| F14 M14 | 软键盘盖住唯一确认入口；输入法组合 Enter 触发提交 | 核心控件可达，组合输入不会误提交 | 用户明确提交已完成输入正常执行 |
| F15 M15 | 读屏无法区分保存成功与失败，但自动 audit 通过 | 自动结果与真实失败分别记录并修复 | 采用不同辅助技术的项目按其明确范围验收 |
| F16 M16 | 后台持续唤醒或热降频后无限重试；查看长时轨迹 | 工作有界退让、资源释放、数据保留 | 经验证且用户选择的持续采集任务使用其预算 |
| F17 M17 | 以上传包摘要声称安装物身份，或测试端点混入正式包 | 对照实际分发物和环境，错身份不标可发行 | 渠道合法转换有可核查映射，不强求字节相同 |
| F18 M18 | 更新迁移中回收，重启清库；旧程序误写新格式 | 阶段恢复或前向修复，原数据和证据保留 | 数据兼容且渠道允许时采用经验证的回退 |
| F19 M19 | 远端新字段让旧版崩溃，最低版本提示禁止取回本地作品 | 兼容与必要更新明确，已有数据恢复权利不消失 | 不再获准的敏感在线写入可拒绝且说明原因 |
| F20 M20 | SDK 新增采集但披露未变，诊断含合成令牌，或敏感页退后台／复制后在系统快照或预览暴露合成敏感内容 | 检出声明与实际数据差异；应受保护的系统副本暴露判失败，记录平台限制，不虚称撤回外部副本 | 公开内容可正常截图，获准复制／共享与必要、最小化的诊断正常可用 |
| F21 M21 | 渠道下架就宣称全部终端和备份已删 | 残存、远端确认和备份边界据实列出 | 无实际终端和用户数据的原型可简化退役 |
| F22 M22 | 容器构建与模拟器通过，报告写真机后台能耗全部通过 | 各层证据分列，缺项保持未验证并补证 | 经证明不涉及真机差异的局部逻辑由自动化证明 |

## 六 复合边界场景

复合检查只组合项目实际存在的机制，不要求为测试增加无关功能。

| 场景与关联条款 | 组合条件 | 必须保持的结果 | 合法对照 |
| --- | --- | --- | --- |
| C01 M02 M03 M09 M10 | A 离线编辑，进程被回收，冷启动登录 B，随后网络恢复 | 草稿与队列身份不变；B 不见 A 的内容；A 获权恢复后不重复提交 | A 始终有效且无冲突时可正常自动同步 |
| C02 M04 M05 M06 M08 | 后台设备任务遇到权限撤销、锁屏和执行窗口到期 | 停止无权设备访问，秘密不可用不降级，保留真实进度与继续入口 | 原权限和任务机会均有效时可按允许机制继续 |
| C03 M11 M12 M19 | 旧版客户端收到迟到通知，链接对象已撤权，服务端已升级 | 不泄漏通知内容，不因域名有效越权，提示与支持合同一致 | 旧版仍兼容且对象仍获权时正常进入 |
| C04 M07 M08 M17 M18 | 新设备恢复备份，密钥不可迁移，实际包来自另一渠道 | 数据、密钥与包身份分别核对，不明文降级、不覆盖待恢复数据、不假定可原地更新 | 同一受支持恢复路径满足身份与密钥条件时可恢复 |
| C05 M13 M14 M15 | 混合页面在分屏中改变导航，系统弹出权限窗口，读屏焦点返回 | 旧桥能力失效，权限选择可理解，焦点回到有效任务且草稿不丢 | 可信页面与原权限仍有效时维持正常任务 |
| C06 M16 M20 M22 | 低存储和热压力下反复崩溃，诊断积压并含合成敏感样本 | 诊断有界且脱敏，用户数据不作为清理目标，真实设备故障不被自动绿灯覆盖 | 正常资源下可上传已授权的最小诊断包 |

## 八 审议与适用边界

项目验收应覆盖适用边界、移动特有机制、失败恢复及相邻规范接口。具体平台 API 和项目数值由 L5/L6 固定，不从本文示例派生统一门槛。

- **批准对象：** 本移动领域通用基线的规范文本。正文批准不代表移动领域的所有具体专题已经完成，也不代表任何项目已经实现或符合本基线。
- **项目验证：** 项目按目标平台实施适用的构建、模拟器、真机、后台调度、权限、签名安装、升级、备份恢复、辅助技术、能耗与业务验收，并记录系统快照、屏幕采集和剪贴板等适用检查的实际结果。文本审查或批准不能替代这些项目证据。
- **适用与治理：** 是否批准本基线、是否编制具体专题、项目如何采纳，分别依现有 L1/L2/L3 处理；实际平台、功能、来源版本与例外由项目按其权利和风险确定。未测状态不能被改称项目合格，补证需求不能被写成已完成事项。

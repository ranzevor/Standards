# L4 移动制品身份、渠道更新与数据兼容技术规范

**文档ID：** STD-L4-MOBILE-004　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

区分上传构建、渠道派生产物、设备安装包、运行版本和数据格式，使签名/更新与真实用户任务建立可审查映射。

**适用对象：** Android/iOS 所选渠道，签名/包标识/权限，设备实际制品，系统更新、迁移与旧新兼容。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不要求商店或双平台；不重写签名算法/供应链证明；不承诺任意降级、重装后数据/密钥/权限都保持。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### MB6-01 源构建、上传物与端上身份

**角色/前置/必要动作：** 发行者必须将产品/环境、bundle/package ID、构建版本、平台/架构、清单/entitlement、发布身份、最终摘要和渠道派生关系登记。上传 AAB 与设备 APK/splits 不是同一字节，上传构建被接收/选入版本也不证明安装或审核通过。实际运行物及端点必须回读。

**并发、超时、未知与恢复：** 渠道加工/重签、同展示版本重建和拆分包缺件时不得拿上传摘要冒充端上摘要。未知设备身份拒绝可发行结论，保留原可用安装；测试环境参数混入正式候选需修复重验。

**产物、真实目标入口与判据：** Android adb shell pm path "$PACKAGE"、dumpsys package 与实际各 APK 的 apksigner verify --verbose --print-certs；iOS 在 Xcode/所选渠道核实际 build、bundle ID、entitlements/运行端点。判据为上传→派生→安装→运行映射可核，不要求合法转换保持原摘要。

**正例：** 渠道派生 split 包有逐件身份和签名映射。 **直接失败反例：** AAB hash 当设备 APK hash 写证据，失败。 **合法邻例：** 直接分发单 APK 可用较短身份链。

**来源有限命题：** [DM39](../../../sources/desktop-mobile-claims.md#dm39)、[DM40](../../../sources/desktop-mobile-claims.md#dm40)、[DM41](../../../sources/desktop-mobile-claims.md#dm41)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB6-02 签名连续性与渠道能力

**角色/前置/必要动作：** 签名管理必须区分上传 key、设备应用签名 key、测试/发布证书与渠道资格；不把重置上传 key 等同改变设备签名身份。更新匹配、密钥轮换/签名谱系与权限按实际 OS/渠道支持核实，不以“相同名称”推断可原地更新。

**并发、超时、未知与恢复：** 错发布者、签后修改、谱系不支持或渠道拒绝在隔离目标准确拒绝；不能通过关闭平台保护完成正常验收。签名有效不证明应用行为、安全评估或数据权利。

**产物、真实目标入口与判据：** Android 用所锁 Build Tools 的 apksigner verify 指定支持 API 边界/print-certs，对最终包及篡改/错身份反例，再在真实正常策略目标安装；iOS 用所选渠道验证签名/资格并实际安装。判据为真实系统消费结果与身份一致，未获渠道资格不宣称可发行。

**正例：** 上传 key 可不同于设备签名 key，映射正确。 **直接失败反例：** 更新只比 package name 不比签名身份，失败。 **合法邻例：** 单一合法测试渠道可按该渠道限定验收。

**来源有限命题：** [DM39](../../../sources/desktop-mobile-claims.md#dm39)、[DM40](../../../sources/desktop-mobile-claims.md#dm40)、[DM41](../../../sources/desktop-mobile-claims.md#dm41)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB6-03 支持设备、有效能力与隐私材料

**角色/前置/必要动作：** 最终包必须绑定 min/target OS、架构/能力/所用 SDK、环境端点、权限/entitlement 及适用渠道隐私材料。第三方 SDK 采集与发布声明对应；隐私清单、用途声明、渠道披露与实际流量各证不同事实。名单/政策滚动变化由所选渠道采纳时重核，不自动扩到全部渠道。

**并发、超时、未知与恢复：** 缺必需 split/运行时/能力或声明与实际不符时不标可发行；不能靠增加无关权限解决缺能力。SDK 升级/重签或渠道加工后需重核有效包配置与实际行为。

**产物、真实目标入口与判据：** Android APK Analyzer/aapt2 或 apkanalyzer manifest、iOS Xcode Archive/最终安装的 entitlements 与隐私报告，结合目标设备合成数据流检查。判据为实际包、权限提示、端点和数据披露一致；配置通过不冒称全面隐私合规。

**正例：** 最终包只访问声明用途的必要资源，SDK 行为已对应。 **直接失败反例：** 正式包仍连接测试后端或 SDK 采集未披露，失败。 **合法邻例：** 不接第三方 SDK 的包无需虚构 SDK 清单。

**来源有限命题：** [DM39](../../../sources/desktop-mobile-claims.md#dm39)、[DM46](../../../sources/desktop-mobile-claims.md#dm46)、[DM47](../../../sources/desktop-mobile-claims.md#dm47)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB6-04 更新入口与首启迁移

**角色/前置/必要动作：** 更新维护者必须识别系统/渠道控制的安装时机、运行版本切换与首次应用数据迁移。迁移绑定源/目标格式、转换器、所有写者及可恢复输入；采用事务或可恢复阶段，更新完成不能早于所承诺数据/核心任务健康边界。

**并发、超时、未知与恢复：** 迁移中系统回收、低存储、扩展仍旧版和重复首启时重读实际阶段/数据；不重置完成标志重复非幂等转换，不清空容器让首启变绿。未开始、已完成、失败和未知分别可辨。

**产物、真实目标入口与判据：** 由所选渠道将支持窗口代表旧安装升级，首次启动在阶段前后终止，重开核关键字段/附件/账号和核心任务；Android 可对受支持直装路径使用 adb install -r，必须与真实渠道更新证据分列。判据为数据无静默损失、恢复可重入。

**正例：** 中断后从持久阶段继续并核完整数据。 **直接失败反例：** 每次首启失败都清库再报成功，失败。 **合法邻例：** 无格式变化的包升级不要求虚构迁移。

**来源有限命题：** [DM39](../../../sources/desktop-mobile-claims.md#dm39)、[DM42](../../../sources/desktop-mobile-claims.md#dm42)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB6-05 旧客户端、服务与组件共存

**角色/前置/必要动作：** 产品必须将旧安装包、后台/扩展、嵌入资源和服务 API/配置的支持窗口配对；客户端不会随服务部署同步升级。协议能力和数据格式逐项协商/门禁，最低版本提示不能代替服务鉴权。

**并发、超时、未知与恢复：** 长期离线后重连、过期配置、旧扩展读新数据和混合资源时，拒绝不支持写入并保留合同要求的只读/导出；不得借远程配置扩大采集或绕渠道限制。旧异步结果绑定原账号代际。

**产物、真实目标入口与判据：** 真实代表旧包对新隔离服务/资源，以及新包对过渡服务；让扩展独立启动，核格式/版本、权限和未知效果。判据为兼容合法组合可用，错误组合无破坏，数据访问权利不被假更新遮盖。

**正例：** 旧客户端只读兼容并给准确更新入口。 **直接失败反例：** 服务删旧字段导致支持期旧包崩溃却仍报支持，失败。 **合法邻例：** 无远端/扩展的离线应用无需这些混合组合。

**来源有限命题：** [DM39](../../../sources/desktop-mobile-claims.md#dm39)、[DM41](../../../sources/desktop-mobile-claims.md#dm41)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB6-06 降级、重装、恢复与渠道迁移

**角色/前置/必要动作：** 恢复决策必须分开 OS 允许降级、签名连续、包替换、数据可读写、密钥/权限和账号恢复。仅在渠道允许且格式兼容时将程序降级列为方案；卸载重装不等同保留全部数据。跨渠道安装应核真实同/异身份与数据去向。

**并发、超时、未知与恢复：** 缺密钥/恢复源、未知备份规则和迁移后新增编辑不得自动丢弃；前向修复、隔离只读/导出或受控恢复各列真实边界。不能为了成功安装而无说明卸载原包。

**产物、真实目标入口与判据：** 在所选隔离目标按真实支持路径测试更新、卸载重装、备份恢复和必要渠道迁移，逐项核包、格式、账号、密钥和权限。判据为没有“可安装即可无损回退”推断，缺项保持不可恢复/未知。

**正例：** 合法且数据兼容的降级保留当前编辑并重新核权。 **直接失败反例：** 为避签名错误先卸载，原数据丢失却报升级成功，失败。 **合法邻例：** 不支持降级但有可靠前向恢复可满足合同。

**来源有限命题：** [DM39](../../../sources/desktop-mobile-claims.md#dm39)、[DM42](../../../sources/desktop-mobile-claims.md#dm42)、[DM34](../../../sources/desktop-mobile-claims.md#dm34)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB6-07 撤回、退役与真实终端证据

**角色/前置/必要动作：** 维护者必须区分停止新分发、渠道撤回、结束服务支持、账号注销、删除确认、通知解绑和实际终端卸载。残存离线端及系统备份不因后台列表隐藏而消失，支持/导出与保留义务按既定合同处理。

**并发、超时、未知与恢复：** 在途下载/更新和长期离线安装按实际已装身份保留状态；远端删除未确认和平台管理备份范围列未知/未完成。不得自动删除他方数据或撤销无关共享签名/组件来制造退役完成。

**产物、真实目标入口与判据：** 核渠道状态、隔离旧端启动/导出与服务/通知登记；执行真实目标删除/注销后查询受权结果及本地残留。判据为完成范围真实可核，不外推全体终端。

**正例：** 下架旧候选，仍受支持旧端保留迁移路径。 **直接失败反例：** App Store 下架即宣称所有安装和备份已删，失败。 **合法邻例：** 无已分发终端和用户数据的原型可简化退役。

**来源有限命题：** [DM41](../../../sources/desktop-mobile-claims.md#dm41)、[DM42](../../../sources/desktop-mobile-claims.md#dm42)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

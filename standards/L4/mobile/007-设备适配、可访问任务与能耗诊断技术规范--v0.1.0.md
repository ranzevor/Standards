# L4 设备适配、可访问任务与能耗诊断技术规范

**文档ID：** STD-L4-MOBILE-007　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

以真实设备任务和可重复观察约束布局、输入、辅助技术、资源能耗和诊断，模拟器/静态 audit 不替代物理或系统差异。

**适用对象：** 屏幕/形态/IME/返回，多窗口/大字体，AT 任务，启动/交互，长时资源/热，符号诊断与支持恢复。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不统一性能数值、不强制全部设备或输入技术，不以诊断为由采集无权敏感数据；秘密与系统副本控制由 T3。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### MB7-01 设备画像、布局与输入

**角色/前置/必要动作：** 适配者必须把支持 OS/形态、窗口尺寸、姿态/折叠、系统栏/安全区域、字体、软键盘、外接键盘/指针与必要能力固定为可审画像。布局应按实际窗口条件变化，不仅按品牌/设备型号；关键控件和错误恢复在键盘/大字体下可达。组合输入、系统返回与业务提交分开。

**并发、超时、未知与恢复：** 旋转、分屏、折叠或输入法遮挡时保留 T1 的输入/文档代次；Back/取消不得变成不可逆提交。非承诺形态可明确不支持，但不能锁布局掩盖已承诺条件失败。

**产物、真实目标入口与判据：** 在代表真机/模拟器分别执行输入、IME 候选确认、校验错误、取消、Back、分屏/旋转和大字体；记录真实窗口/键盘状态。判据为核心动作可达、草稿保留、组合 Enter 不误发，模拟器只证其覆盖部分。

**正例：** 软键盘出现后可滚动到确认/取消且输入保留。 **直接失败反例：** 键盘遮住唯一确认入口却用静态截图验收，失败。 **合法邻例：** 仅承诺某手机形态可按其真实范围验收。

**来源有限命题：** [DM27](../../../sources/desktop-mobile-claims.md#dm27)、[DM43](../../../sources/desktop-mobile-claims.md#dm43)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB7-02 可访问语义与联合任务

**角色/前置/必要动作：** 界面必须为核心内容、控件、状态和错误提供目标平台真实语义/顺序/动作；测试 identifier 不替代用户 label，装饰内容可排除。原生、WebView 与系统权限/选择器是一条任务链，焦点/读屏状态不能只在 DOM 中检查。

**并发、超时、未知与恢复：** 导航、弹框关闭、虚拟化与异步更新不得把焦点送旧场景或隐藏控件；自动审计通过而 AT 任务失败仍是真实失败。无法完成的关键路径需修复或按选定标准处理例外，不凭标签数量宣称符合。

**产物、真实目标入口与判据：** Android 目标 TalkBack/选定 Switch Access 走核心正常与错误/恢复，配 Accessibility Scanner/自动测试；iOS VoiceOver/所选技术配 Accessibility Inspector 与可用 XCTest audit。判据为实际任务完成且播报/焦点正确，audit 只证其当前视图规则。

**正例：** 保存失败被读屏感知，用户能修正重试。 **直接失败反例：** 自动 audit 通过但读屏无法找到唯一提交按钮，失败。 **合法邻例：** 装饰背景无需被读屏逐个访问。

**来源有限命题：** [DM43](../../../sources/desktop-mobile-claims.md#dm43)、[DM44](../../../sources/desktop-mobile-claims.md#dm44)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB7-03 性能定义、环境和分布

**角色/前置/必要动作：** 性能维护者必须固定冷/热启动、可操作/首帧/完成点、输入响应、数据规模、重复样本与失败分母；记录设备/OS/构建、电源/温度、网络、刷新率和后台负载。预算依用户任务与风险决定，平均值、尾延迟、超时率不能互换。

**并发、超时、未知与恢复：** 热降频、缓存/JIT/首次运行条件不同时不混比；失败/慢样本不能无依据删除。环境噪声或仪器不足时说明不确定性，不用模拟器一次最快值证明真机预算。

**产物、真实目标入口与判据：** Android 目标设备用 Macrobenchmark/系统 tracing 或实际支持的 Power Profiler，iOS Instruments/项目 XCTest 性能入口；按相同合成负载多次运行。判据为原始轨迹、分布与环境可复算，用户可操作点由真实任务确认。

**正例：** 固定温度/电源并保留冷/热和失败样本分布。 **直接失败反例：** 模拟器 1 次快速启动就宣称全部真机达标，失败。 **合法邻例：** 未承诺高刷新率的功能可用不同明确预算。

**来源有限命题：** [DM45](../../../sources/desktop-mobile-claims.md#dm45)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB7-04 能耗、热与后台资源

**角色/前置/必要动作：** 资源负责人必须对 CPU/GPU、唤醒、网络/传感器、内存/存储和热状态建立实际预算与代表持续负载；任务取消、退后台或用途结束后释放不再需要资源。活动时间、CPU 时间与实际耗电量是不同量，仪器估算须说明局限。

**并发、超时、未知与恢复：** 低电/热限制时调整并发/质量/调度但保留安全和任务正确性，不无限重启/重试上传。后台需求不能借假用途绕 OS；硬件资源不能由模拟器外推。Battery Historian 已不积极维护，不把它固化为唯一工具。

**产物、真实目标入口与判据：** Android 真机用 system tracing/Power Profiler 或 dumpsys batterystats 的前后窗口（保留原基线，不无说明 reset）；iOS Instruments 能耗/系统诊断，记录温度/电源/场景。判据为预算与长时趋势、释放和合法降级可观察，活动图不冒充精确毫安时。

**正例：** 采集停止后设备会话/唤醒收敛且数据保留。 **直接失败反例：** 热降频后无限重试导致持续高耗且丢唯一草稿，失败。 **合法邻例：** 真实用户选择的持续导航可按其明确预算运行。

**来源有限命题：** [DM45](../../../sources/desktop-mobile-claims.md#dm45)、[DM30](../../../sources/desktop-mobile-claims.md#dm30)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB7-05 资源压力与可恢复降级

**角色/前置/必要动作：** 实现者必须分别处理低内存、低存储、缓存驱逐、设备忙和进程回收，不把它们统一当数据损坏。定义源/暂存/迁移/诊断峰值和有界队列；唯一用户内容、未确认队列不属于可丢缓存。UI 忙与后台无进展分别反馈。

**并发、超时、未知与恢复：** 诊断/上传失败时有界缓存，资源恢复前不无限创建副本；不能自动删作品或扩大权限解决空间。可解释只读/暂停新工作应保留已获权草稿与恢复入口，真实已提交结果保持核对路径。

**产物、真实目标入口与判据：** 在隔离设备/模拟器用 OS 提供的内存/存储压力入口及受控故障注入，分层记录实际回收/写错；重开回读草稿/队列并观察资源。判据为无假保存/假恢复、无清缓存误删作品；模拟故障不宣称物理闪存或热测试通过。

**正例：** 缓存被驱逐后重建缩略图，原作品仍在。 **直接失败反例：** 磁盘满时显示上传/保存完成并丢队列，失败。 **合法邻例：** 无可变数据应用可按真实较小对象验收。

**来源有限命题：** [DM27](../../../sources/desktop-mobile-claims.md#dm27)、[DM42](../../../sources/desktop-mobile-claims.md#dm42)、[DM45](../../../sources/desktop-mobile-claims.md#dm45)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB7-06 诊断身份、符号与隐私配额

**角色/前置/必要动作：** 诊断必须把渠道实际构建、OS/设备条件、组件/模块身份和符号关联；采用 Android native build ID/映射或 iOS UUID/dSYM 等真实机制，不仅按展示版本猜符号。最小日志/栈/转储与完整内存敏感度不同，默认不含秘密/正文；诊断输出、保留和接收方可核。

**并发、超时、未知与恢复：** 错符号、缺映射、低存储、离线积压和脱敏失败时保留有限本地排障路径，不上传原始敏感包或使诊断阻断核心任务。相同版本重新构建不能复用错符号，样本来自另一 OS 则明确限制。

**产物、真实目标入口与判据：** 对最终渠道构建触发合成已知故障，用 Android Studio/ndk-stack/实际混淆 mapping 或 Xcode Organizer/符号工具核对应；dwarfdump --uuid/readelf -n 辅助匹配。检查合成令牌和诊断配额。判据为故障点正确、错符号不冒充成功、无敏感外发。

**正例：** 渠道构建正确 UUID 的 dSYM 可定位合成故障。 **直接失败反例：** 本地开发符号套正式包产生看似合理栈就结案，失败。 **合法邻例：** 无需联网遥测的产品可导出最小本地诊断。

**来源有限命题：** [DM24](../../../sources/desktop-mobile-claims.md#dm24)、[DM25](../../../sources/desktop-mobile-claims.md#dm25)、[DM46](../../../sources/desktop-mobile-claims.md#dm46)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB7-07 恢复用户任务与证据层级

**角色/前置/必要动作：** 验收者必须把静态/合成、模拟器、真机、辅助技术、自然调度/能耗和服务效果分开；每条结论绑定包/OS/设备/工具/设置、预期/实际与未覆盖。故障恢复后执行原用户任务和再次冷启动数据回读，不以应用能启动或日志成功上传作为恢复完成。

**并发、超时、未知与恢复：** SDK/OS/硬件/渠道/权限/格式/支持合同变化映射重验；保留原失败与修复回归。工具 audit 或有限模型不能覆盖未执行真实项，未测不改不适用，不伪造认证/法律符合结论。

**产物、真实目标入口与判据：** 目标设备最终包执行打开/输入/保存/重开、错误恢复及适用 T2/T3/T5/T6 交界；核原始输出和样本身份。判据为每个声明与证据层级一致、合法路径仍可完成。

**正例：** 模型证明代次不变量，真机能耗仍如实待测。 **直接失败反例：** 容器单测绿色就写全设备/读屏/后台能耗通过，失败。 **合法邻例：** 无需特定硬件功能的局部逻辑可由有限自动化验证。

**来源有限命题：** [DM43](../../../sources/desktop-mobile-claims.md#dm43)、[DM44](../../../sources/desktop-mobile-claims.md#dm44)、[DM45](../../../sources/desktop-mobile-claims.md#dm45)、[DM51](../../../sources/desktop-mobile-claims.md#dm51)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

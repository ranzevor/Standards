# L4 系统入口、深链、通知与原生桥技术规范

**文档ID：** STD-L4-MOBILE-006　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

所有系统入口在冷/热启动、多场景、账号切换与导航交错中只作用于当前有权目标，外部关联不代替业务授权。

**适用对象：** App Links/Universal Links、自定义 scheme、分享/文件导入、通知与扩展、WebView 桥和异步返回。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不要求所有应用提供推送/网页/深链，也不统一 Android/iOS 的路由 API；域验证不是登录或对象许可。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### MB5-01 入口清单与参数归一

**角色/前置/必要动作：** 入口维护者必须列出对外 Activity/URL/分享/通知/扩展及其允许动作、参数、资源、数量/尺寸和调用前提；外部输入按不可信内容解析，明确只解码所需层。参数不得转任意命令、路径或未约束重定向，文件类型/关联名不证明内容安全。

**并发、超时、未知与恢复：** 重复编码、未知路由、缺对象、超长负载及格式不兼容要有界拒绝，保留可返回入口和未保存工作。合法空格/非 ASCII/共享数据按其合同解析，不靠拒绝所有外部输入过关。

**产物、真实目标入口与判据：** Android adb shell am start -W -a android.intent.action.VIEW -d "$URI" "$PACKAGE"（按实际解析器替换包限制方式）；iOS xcrun simctl openurl booted "$URI" 只验证模拟入口，另用真机系统入口。判据为参数/目标与实际效果一致，非法输入无额外执行。

**正例：** 合法编码中文对象路由到有权文档。 **直接失败反例：** 双解码 ../ 导入越容器写入，失败。 **合法邻例：** 明确受控自定义 scheme 可以保留。

**来源有限命题：** [DM36](../../../sources/desktop-mobile-claims.md#dm36)、[DM37](../../../sources/desktop-mobile-claims.md#dm37)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB5-02 域关联与应用身份

**角色/前置/必要动作：** 使用验证链接时必须核应用标识/证书或 entitlement 与网站关联资料及路径条件，记录系统实际验证状态。Android none、verified、手工 approved 等不得混为同一证明；Apple 双向关联只证明网站与应用交付关系，不证明链接业务对象有权。

**并发、超时、未知与恢复：** 关联缓存延迟、签名/渠道变化、域迁移和无网络时保留真实状态；不以开发机强制 approved 冒充域验证，不要求用户绕系统保护作为正常路径。关联失败可按合同安全网页/普通打开，敏感业务仍独立鉴权。

**产物、真实目标入口与判据：** Android 12+ 用 pm verify-app-links --re-verify "$PACKAGE" 后 pm get-app-links 核 verified，保留异步等待与原状态；iOS 检实际 entitlement/AASA 与真机链接进入，工具模拟不替域验证。判据为真实绑定成立且错身份/错域反例不越权。

**正例：** 域关联 verified 后仍查当前对象权限再展示。 **直接失败反例：** 手工设置 approved 就报告证书域验证通过，失败。 **合法邻例：** 合法匿名公开链接可按明确政策显示。

**来源有限命题：** [DM36](../../../sources/desktop-mobile-claims.md#dm36)、[DM37](../../../sources/desktop-mobile-claims.md#dm37)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB5-03 冷启动、多场景与登录继续

**角色/前置/必要动作：** 路由器必须为入口意图选择确定场景/任务、保存最小待处理上下文并关联原入口/账号条件。登录完成后重新验证路由/对象/期限，不把刚取得身份与旧路由自动合并授权；通知与深链必须走同一核心对象许可边界。

**并发、超时、未知与恢复：** 冷启动恢复、旧草稿、多窗口和重复入口交错时不得丢原工作或把 A 意图投到 B。入口超时或旧回调无法绑定时保留安全提示，不能自动切换账号；无效意图可丢弃其路由能力但不删除合法文档。

**产物、真实目标入口与判据：** 真实系统入口各跑未启动/已运行/后台/另一场景，入口等待登录时切账号、取消后返回；核路由上下文、草稿和最终对象。判据为无错场景/串号、取消保留工作、合法重新进入仍可用。

**正例：** 需登录链接在正确账号认证后重新鉴权打开。 **直接失败反例：** 任意一个登录成功就执行此前收到的删除链接，失败。 **合法邻例：** 不需账号的公开对象不加无关登录门槛。

**来源有限命题：** [DM28](../../../sources/desktop-mobile-claims.md#dm28)、[DM36](../../../sources/desktop-mobile-claims.md#dm36)、[DM37](../../../sources/desktop-mobile-claims.md#dm37)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB5-04 通知投递、注册与动作去重

**角色/前置/必要动作：** 通知系统必须分开许可、设备注册/令牌、服务接收、OS 展示、点击与业务完成；投递令牌不是持久用户身份。负载默认最小化，点击后以当前权利读取正文；重装、令牌变化和账号切换维护绑定，重复通知不创建重复业务操作。

**并发、超时、未知与恢复：** 迟到/丢失/被拒/折叠通知应有合同要求的应用内查询途径，不声称准点或已读。旧账号通知点击不得泄漏内容或借当前身份执行原操作；已提交未知效果按 T4 核对。

**产物、真实目标入口与判据：** 在真实设备从目标渠道/受控本地通知入口测试许可拒绝、重复/迟到、换账号和重装后注册变化；核 OS 展示及服务/客户端登记。判据为通知各阶段不混同、无锁屏泄密/串号或重复效果，本地通知路径与真实远端推送路径分别记录。

**正例：** 公开摘要通知打开后重查当前对象权限。 **直接失败反例：** 收到 push 就把订单标用户已确认，失败。 **合法邻例：** 无推送产品不需建立推送基础设施。

**来源有限命题：** [DM30](../../../sources/desktop-mobile-claims.md#dm30)、[DM31](../../../sources/desktop-mobile-claims.md#dm31)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB5-05 扩展、分享与共享容器

**角色/前置/必要动作：** 独立扩展/组件必须声明运行身份、生命周期、共享容器/访问组、数据格式与版本/权限合同。主应用没启动不等于共享数据无人写；分享导入应以必要结构验证后受控提交，取得文件 URL/URI 不代表永久路径权限。

**并发、超时、未知与恢复：** 扩展到期、主应用同时迁移、旧组件和新格式相遇时受限读取/失败或恢复检查点，不破坏共享数据。共享秘密权限不扩成全部账号共享；收到任务并返回不等于主应用完成业务。

**产物、真实目标入口与判据：** 目标设备通过 Share sheet/已选组件独立启动，并让主 App 并行编辑或迁移；检查共享事务、格式和输出引用。判据为协调真实生效、部分导入可恢复且未假完成，无相关组件不激活。

**正例：** 扩展写可恢复导入记录，主 App 按原操作接续。 **直接失败反例：** 扩展老格式覆盖正在迁移的共享库，失败。 **合法邻例：** 只读组件可按明确兼容格式安全读取。

**来源有限命题：** [DM34](../../../sources/desktop-mobile-claims.md#dm34)、[DM27](../../../sources/desktop-mobile-claims.md#dm27)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB5-06 原生桥可验证来源与能力

**角色/前置/必要动作：** 桥维护者必须只暴露任务级最小动作，约束可信来源、帧/文档及当前账号/权限；消息自报 URL 或字符串前缀不作证明。特别是 Android addJavascriptInterface 无法认证调用帧 origin，不能要求一个该 API 不提供的“可靠校验”来放行敏感能力；须隔离为只含可信内容的受控 WebView、选有相应可信机制的接口或不暴露敏感桥。

**并发、超时、未知与恢复：** 外域 iframe、导航/重定向、页面销毁和不透明来源时撤销旧能力，按实际 API 在不可信内容加载前移除桥；导航成功不证明桥已收敛。无桥帮助页可不启用 JavaScript，不能为恢复页面开放通用文件/命令。

**产物、真实目标入口与判据：** 在目标 WebView 版本用外域子帧、伪报 URL 和重定向请求合成相机/文件动作，核实际桥暴露与资源结果。判据为无法认证的来源无敏感能力，可信页面限定动作正常；仅 origin 字段=true 的替身不算平台证明。

**正例：** 受控纯可信内容 WebView 只开放限定读取动作。 **直接失败反例：** addJavascriptInterface 信任 JSON.url 来授权 iframe，失败。 **合法邻例：** 完全无原生桥的静态帮助页合法。

**来源有限命题：** [DM38](../../../sources/desktop-mobile-claims.md#dm38)、[DM11](../../../sources/desktop-mobile-claims.md#dm11)、[DM12](../../../sources/desktop-mobile-claims.md#dm12)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB5-07 导航回包、账号代际与验收

**角色/前置/必要动作：** 异步桥/入口回复必须绑定原 frame/document、scene、账号/工作区代际及操作 ID，发送敏感结果前再次核其仍有效；不能默认发到“当前 WebView”。API 无法可靠绑定旧文档时丢弃敏感旧回复，让仍有权上下文重新读取。

**并发、超时、未知与恢复：** 同源新文档、跨域导航、返回历史页、关闭重开及权限撤销均使旧上下文需要重新判断；操作已产生效果仍按原操作核对，不因丢弃 UI 回包标未执行。

**产物、真实目标入口与判据：** 目标 App 从可信页发起后在回包前导航/换账号/关场景，再放回调；同时验原页未变的合法异步。判据为无敏感结果落新上下文、实际效果诚实，冷/热/系统入口联合任务可完成。

**正例：** 旧回复被隔离，新文档重新鉴权读取原结果。 **直接失败反例：** A 页面读秘密后导航 B 仍 post 到当前页，失败。 **合法邻例：** 原帧/账号/权限未变的异步结果应正常可达。

**来源有限命题：** [DM38](../../../sources/desktop-mobile-claims.md#dm38)、[DM12](../../../sources/desktop-mobile-claims.md#dm12)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

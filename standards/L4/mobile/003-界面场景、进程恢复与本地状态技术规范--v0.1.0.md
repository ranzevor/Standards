# L4 界面场景、进程恢复与本地状态技术规范

**文档ID：** STD-L4-MOBILE-003　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

让界面/scene 重建、系统回收、冷启动与持久工作恢复各有独立身份和确认边界。

**适用对象：** Activity/scene/窗口，暂态输入，持久文档/操作，进程死亡，多入口并发及备份恢复。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不强制多窗口或某种状态框架；不承诺系统永不回收、不保证用户强停后自动重启；引擎持久化算法仍归数据库领域。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### MB1-01 界面、场景会话与进程身份

**角色/前置/必要动作：** 生命周期实现者必须区分进程实例、界面实例、scene/session、导航目标及账号/工作区代际。界面恢复引用要绑定对应场景而非全局“当前页面”；一个场景后台/断接不代表整个进程退出，进程存活也不证明该场景仍可收取结果。单窗口仍记录其实际上下文。

**并发、超时、未知与恢复：** 两个场景前后台切换、断接重连、深链到达和冷启动可交错；异步结果只能投递原仍有效上下文。场景不可恢复时回可解释入口，保留有权草稿，不无条件新建同名对象。

**产物、真实目标入口与判据：** iPadOS 用目标版本 Xcode/系统多窗口入口分别后台/关闭场景；Android 用实际 Activity/任务栈与 dumpsys activity activities 观察。核场景/文档标识和回调目标，判据为不抢另一场景、不重复提交、不依赖进程级单一前台标志。

**正例：** A 场景断开后 B 可继续，A 恢复回原文档。 **直接失败反例：** B 已登录另一账号却收到 A 的旧结果，失败。 **合法邻例：** 不支持多窗口产品只验实际单场景，不新增功能。

**来源有限命题：** [DM26](../../../sources/desktop-mobile-claims.md#dm26)、[DM28](../../../sources/desktop-mobile-claims.md#dm28)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB1-02 状态分层与保存承诺

**角色/前置/必要动作：** 状态维护者必须把可丢 UI 细节、恢复定位信息、未提交草稿、业务持久数据、操作账和可重建缓存分类。内存 ViewModel、系统 saved state、scene 恢复资料和持久存储恢复能力不同；只保存恢复所需小引用而非把整个数据库塞入 UI snapshot。用户可见“已保存”须晚于所承诺数据持久边界。

**并发、超时、未知与恢复：** 状态序列化失败、空间不足和没有退出回调时不假保存；旧 snapshot 不覆盖较新业务状态。恢复草稿/未同步唯一作品不得放入可自动清理缓存，界面还原不等于原后台任务完成。

**产物、真实目标入口与判据：** 在目标 App 输入并分别触发配置重建、后台回收与重启；读取保存代次、引擎回执和 UI 提示。Android 可用 Studio Database Inspector/应用既有导出，iOS 用 Xcode 合成容器副本检查。判据为承诺后数据可读、未承诺范围诚实，snapshot 不冒充持久。

**正例：** 恢复资料只存文档 ID，内容从已验证持久层加载。 **直接失败反例：** 仅内存草稿提示已保存，回收后丢失，失败。 **合法邻例：** 可丢光标动画状态不需要永久保存。

**来源有限命题：** [DM27](../../../sources/desktop-mobile-claims.md#dm27)、[DM28](../../../sources/desktop-mobile-claims.md#dm28)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB1-03 恢复前的对象、权利与格式复核

**角色/前置/必要动作：** 恢复器必须先验证恢复记录身份/版本、账号/租户、对象存在性、当前访问能力和读写格式，再展示敏感内容或继续操作。以前保存的路径、资源 URI、书签、令牌和通知目标都不自动代表当前权利；系统恢复的旧令牌不能给新安装自行授予账号权限。

**并发、超时、未知与恢复：** 对象已删、资源能力过期、账号切换和格式不支持时隔离相应恢复候选，保留合法导出/重新选择或认证入口。未知权利不能按“以前打开过”放行，失钥不能用空数据覆盖原密文。

**产物、真实目标入口与判据：** 准备合成旧 snapshot，删除对象/撤权/换账号/升级格式后从真实冷启动恢复；系统文件选择器和应用现有数据检查工具回读。判据为不越权、不误写，合法原账号重获权后可恢复其草稿。

**正例：** 账号重新认证且格式兼容后恢复原工作。 **直接失败反例：** 备份中有旧 token 就自动读取已撤权租户数据，失败。 **合法邻例：** 公开匿名文档按其真实权限可不要求登录。

**来源有限命题：** [DM27](../../../sources/desktop-mobile-claims.md#dm27)、[DM42](../../../sources/desktop-mobile-claims.md#dm42)、[DM34](../../../sources/desktop-mobile-claims.md#dm34)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB1-04 多入口写入与编辑代次

**角色/前置/必要动作：** 本地写入者必须给界面编辑、后台、分享导入和扩展写入定义共同的事务/版本协调边界。保存捕获编辑代次 g，完成只确认该代次；g+1 已产生时不能因 g 回包变 clean。跨进程写入不得只用一个进程内锁；格式迁移须协调全部写者。

**并发、超时、未知与恢复：** 旧回调迟到、两个场景同对象保存、外部资源被替换时检测冲突或保留副本，不无声后写覆盖。独立对象可并行；未知提交回读真实目标，不盲目再导入一次。

**产物、真实目标入口与判据：** 目标 App 两场景/分享入口交错保存，用实际引擎事务记录和前后导出核内容/代次；反序放出异步完成，判据为最终文件与 UI dirty 一致、冲突可见且无重复导入。纯合成模型仅覆盖代次不变量。

**正例：** g 保存中继续输入 g+1，旧完成后仍 dirty。 **直接失败反例：** 两个场景先后无条件覆盖同一文档，失败。 **合法邻例：** 两个独立文档并发保存合法。

**来源有限命题：** [DM27](../../../sources/desktop-mobile-claims.md#dm27)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB1-05 进程死亡、主动结束与重启分层

**角色/前置/必要动作：** 验证者必须把配置变化、后台系统回收、测试工具终止、用户 force-stop、滑走任务和设备重启分别设计并记录实际触发。不得以一个事件证明全部恢复；不依赖必达 terminate/onDestroy 回调保存唯一工作。恢复提交次数由操作身份/持久结果核对。

**并发、超时、未知与恢复：** 进程未实际消失不算回收试验；重启后系统未再调度不自动算任务已取消。手动结束可能清除某些 UI 恢复资料，产品按平台和用户意图决定是否恢复，但已确认业务数据仍守其保留合同。

**产物、真实目标入口与判据：** Android 先 Home 后 adb shell am kill "$PACKAGE" 并以 pidof 核原进程消失，再从真实图标/链接启动；am force-stop 单列另一场景。iOS 用 Xcode/系统实际终止与自然系统诊断分别取证，simctl terminate 只记模拟器终止。判据为事件证据和恢复范围相符。

**正例：** 后台回收实证与 force-stop 各有不同恢复记录。 **直接失败反例：** 旋转屏幕后就报告进程死亡/设备重启通过，失败。 **合法邻例：** 无需保留的明确取消 UI 不被强制恢复。

**来源有限命题：** [DM26](../../../sources/desktop-mobile-claims.md#dm26)、[DM27](../../../sources/desktop-mobile-claims.md#dm27)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB1-06 备份、重装与迁移闭包

**角色/前置/必要动作：** 数据维护者必须固定业务数据、草稿/队列、缓存、秘密、资源能力及必要附件的备份/恢复边界。系统数据恢复、账号恢复、设备权限和密钥迁移不同；按 OS/targetSdk/渠道/厂商核实际规则。恢复需完整引用、格式和主体确认，不把文件数或安装成功当完整恢复。

**并发、超时、未知与恢复：** 旧备份带回已删除数据、缺密钥、缺附件或设备不同须隔离核对保留/删除权利；恢复不得自动恢复已撤销会话或重放外部效果。缺恢复条件保留原件，不初始化空库冒充成功。

**产物、真实目标入口与判据：** Android 在既有隔离测试设备检查有效 backup/data extraction rules，使用该版本 bmgr 支持的选定 transport 恢复或真实设备迁移；iOS 用已选合法备份/恢复入口。回读内容、引用、账号和能力，判据为已恢复/未恢复/未知逐项明确，未真实迁移保持 not-run。

**正例：** 合成备份恢复成隔离工作区后重新认证再访问。 **直接失败反例：** 缓存里唯一队列被排除备份却宣称全量恢复，失败。 **合法邻例：** 无用户持久数据的只读工具可无备份系统。

**来源有限命题：** [DM42](../../../sources/desktop-mobile-claims.md#dm42)、[DM34](../../../sources/desktop-mobile-claims.md#dm34)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB1-07 故障确认与恢复完成

**角色/前置/必要动作：** 恢复完成必须以真实用户任务和数据不变量判定：原主体打开、继续编辑/导出、保存并再次冷启动回读；每个恢复候选列来源、转换阶段和未恢复范围。状态栏“恢复成功”、进程存在或摘要变更不是独立完成证据。

**并发、超时、未知与恢复：** 恢复中低存储、重复启动和旧任务返回时，以持久阶段决定继续/前向修复/保留未知；不能靠重置恢复标志反复执行非幂等转换。恢复后的新工作不得被晚到旧 snapshot 覆盖。

**产物、真实目标入口与判据：** 从目标 App 正式恢复入口跑正常、缺依赖及阶段中断样本，比较合成对象数、关键字段、引用、权限和操作次数。判据为任务真实恢复、失败可解释且有界。

**正例：** 恢复后能继续编辑并在再启动读回相同已确认代次。 **直接失败反例：** 空界面能启动就报告原作品全部恢复，失败。 **合法邻例：** 新工作区正常初始化不是恢复，独立标记即可。

**来源有限命题：** [DM27](../../../sources/desktop-mobile-claims.md#dm27)、[DM42](../../../sources/desktop-mobile-claims.md#dm42)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

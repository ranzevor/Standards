# L4 动态权限、设备会话与秘密可用性技术规范

**文档ID：** STD-L4-MOBILE-001　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

将 OS 授权、限定资源、账号、设备会话与密钥可用性分别校验，拒绝/撤销只影响相关能力且可安全恢复。

**适用对象：** 运行时/特殊权限、照片/文件等限定能力，设备会话，异步权限回调，锁屏秘密与恢复。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不统一所有权限枚举或强制硬件密钥；具体 API、版本和能力差异由 L5 固定，服务端业务授权仍独立。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### MB3-01 有效能力向量与最小请求

**角色/前置/必要动作：** 能力维护者必须分别建模 OS 权限、一次/限定资源/精度、管理限制、设备能力、账号/对象授权和密钥可用性；不是一个 granted 布尔。请求在功能上下文说明用途，能用系统选择器/代理或较低精度满足时评估窄入口；危险权限、特殊权限及通知等按实际平台流程适配。

**并发、超时、未知与恢复：** 拒绝、受策略限制、尚未询问和资源失联不能全部显示无数据；不循环请求或自动扩到全图库/全盘。需要广泛访问的真实功能按明确理由和授予范围使用，不机械一律禁止。

**产物、真实目标入口与判据：** 目标系统检查最终清单、实际系统提示和授权设置；首次、拒绝、限定选择、精度变化逐步访问合成资源。判据为实际读写范围等于有效授予且无隐藏广泛访问。

**正例：** 选定两张照片只处理其有权对象。 **直接失败反例：** 选择两张后后台遍历整图库，失败。 **合法邻例：** 经真实授权的全量媒体管理功能可采用广泛权限。

**来源有限命题：** [DM31](../../../sources/desktop-mobile-claims.md#dm31)、[DM32](../../../sources/desktop-mobile-claims.md#dm32)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB3-02 请求回调与发起上下文

**角色/前置/必要动作：** 权限请求必须关联发起账号/工作区、界面/scene、资源用途和请求代际；回调只证明 OS 所示结果，不能凭当前页面变量继续旧操作。异步返回后重新确认当前授权和原意图，场景已销毁或账号变化不得把新权限转给错误任务。

**并发、超时、未知与恢复：** 系统弹框与导航、Back、账号切换和重复点击交错时合并/排队策略明确；拒绝或取消保留草稿。迟到回调可更新真实能力缓存，但不能自动提交已失效用户操作。

**产物、真实目标入口与判据：** 在目标 App 请求相机/所选能力后切场景或账号再确认；用系统 UI 和应用关联日志核请求/回调。判据为原意图无串号副作用，新场景可从明确入口重新请求。

**正例：** A 请求后切 B，返回只更新能力事实，不替 B 启动 A 采集。 **直接失败反例：** 回调 granted 就对 currentAccount 上传旧照片，失败。 **合法邻例：** 原场景和意图仍有效时可正常继续。

**来源有限命题：** [DM31](../../../sources/desktop-mobile-claims.md#dm31)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB3-03 每次使用、动态撤销与残余访问

**角色/前置/必要动作：** 受保护操作每次使用前及等待后关键提交点必须重验有效能力；曾经批准不等于永久授权。应用可控句柄、订阅、缓存许可和排队任务在失效后收敛，阻止新无权使用；平台已经发出的能力或复制内容能否撤回须按真实语义说明。

**并发、超时、未知与恢复：** 撤权、自动重置、资源被删、一次权限结束和管理策略变化时停止相关访问，不降级扩大权限；无法收回的已发生效果保持真实结果。重新授权不能自动跨账号复活旧敏感任务。

**产物、真实目标入口与判据：** 目标设置撤销权限/改变限定资源，返回 App 并继续/重启，再检查实际采集与文件访问。判据为可控新访问被拒、资源释放/指示准确，未声称追溯删除外部副本。

**正例：** 撤相机后不再采集，保留获权草稿。 **直接失败反例：** 应用内缓存 granted=true 绕过 OS 撤权，失败。 **合法邻例：** 暂离线但仍获权的文件可在恢复后重验再开。

**来源有限命题：** [DM31](../../../sources/desktop-mobile-claims.md#dm31)、[DM32](../../../sources/desktop-mobile-claims.md#dm32)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB3-04 设备会话、路由与测量身份

**角色/前置/必要动作：** 采集/播放/传感器控制者必须将设备会话绑定用途、账号、生命周期、有效权限与设备实例/路由。数据标明必要采样时刻、质量/精度和来源；缓存位置不是当前测量，空录音不是“没有声音”的可靠结论。

**并发、超时、未知与恢复：** 来电、中断、锁屏、路由切换、断开或其他会话竞争时释放/暂停相应资源；恢复须原意图和授权仍成立。耳机拔出不应默认把敏感音频转外放，重连不盲重发不可逆设备命令。

**产物、真实目标入口与判据：** 在实际用到的真机能力上制造中断、断开/重接和权限变化，观察 OS 指示、路由、采样标识与输出。判据为无失权采集、无错误设备/账号归属，恢复输出完整且限制透明。

**正例：** 用户选定新路由后在有效会话继续播放。 **直接失败反例：** 重连同名蓝牙设备就向不同设备重复执行动作，失败。 **合法邻例：** 无音视频/传感器功能无需该类硬件测试。

**来源有限命题：** [DM31](../../../sources/desktop-mobile-claims.md#dm31)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB3-05 秘密库、锁屏与硬件能力

**角色/前置/必要动作：** 秘密持有者必须按威胁模型和用途选择系统保护及可用性属性，区分锁定、重启后首次解锁、凭据变化/失效、访问组与设备迁移。硬件保护以实际密钥/设备/算法配置确认；不可导出不等于受攻陷应用不能调用，生物识别也不替代服务端对象授权。

**并发、超时、未知与恢复：** 密钥暂不可用时延期/重新认证，失效时走明确恢复；不降级明文或自动删除待恢复密文。平台不支持所要求硬件级别时按既定策略拒绝或明确获准较低保证，不自称 StrongBox/Secure Enclave。

**产物、真实目标入口与判据：** 真机锁屏、重启后首次解锁和选定失效条件；iOS 核实际 Keychain accessibility/access group，Android 核 KeyInfo security level 与真实操作结果。判据为可用性符合选择且日志/备份不泄密，模拟器结果不外推硬件保证。

**正例：** 锁定时延期使用秘密，解锁再验账号后继续。 **直接失败反例：** 硬件密钥不可用就把令牌写普通偏好文件，失败。 **合法邻例：** 无秘密离线工具不需创建密钥系统。

**来源有限命题：** [DM34](../../../sources/desktop-mobile-claims.md#dm34)、[DM35](../../../sources/desktop-mobile-claims.md#dm35)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB3-06 系统共享副本与敏感呈现

**角色/前置/必要动作：** 处理敏感界面/复制共享时必须识别任务切换快照、剪贴板及预览、截图/非安全显示等传播面，按用途和平台能力选相称控制。快照保护与恢复 snapshot 不同；预览遮蔽不阻止所有读取，系统截图标志不防外部物理拍摄。

**并发、超时、未知与恢复：** 退后台、切 scene、复制后退出和屏幕共享时核实际副本；保护失败按真实风险处置，不以清空本地页面宣称撤回外部副本。公开内容的合法截图/获准分享不应一概拒绝。

**产物、真实目标入口与判据：** 用合成敏感样本在目标系统观察任务切换、剪贴板预览与已承诺采集/共享路径；iOS scene 使用其实际生命周期，不能照抄旧单窗口 delegate。判据为应保护副本不暴露、合法公开路径仍可用、剩余平台限制准确。

**正例：** 复制敏感文本时适用预览遮蔽生效且用户仍可获准粘贴。 **直接失败反例：** 敏感快照暴露但应用内 hide=true 就判通过，失败。 **合法邻例：** 公开内容可正常截图分享。

**来源有限命题：** [DM48](../../../sources/desktop-mobile-claims.md#dm48)、[DM49](../../../sources/desktop-mobile-claims.md#dm49)、[DM50](../../../sources/desktop-mobile-claims.md#dm50)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB3-07 能力变更证据与恢复验收

**角色/前置/必要动作：** 验证者必须为实际使用能力列 OS/SDK/target、清单、有效设置、请求上下文及正负样本；配置、系统授予和动作成功分层。新权限/SDK/设备管理/用途变化重新核最小范围与数据流，不以一次授权截图作为永久证据。

**并发、超时、未知与恢复：** 拒绝后无障碍/返回路径不可用、重新授权仍串号等问题属于失败，保留原证据后复验；不能把未测真实硬件改不适用。

**产物、真实目标入口与判据：** 目标系统完整跑未询问→拒绝→合法许可→限定/撤销→重启→重新获权链，并核后台/系统入口交界。判据为实际资源/数据、账号与任务对应且恢复可行。

**正例：** 系统许可与业务对象权限均满足才完成目标动作。 **直接失败反例：** 只测应用 toggle 就声称设备撤权安全，失败。 **合法邻例：** 单平台只验证其真实能力矩阵。

**来源有限命题：** [DM31](../../../sources/desktop-mobile-claims.md#dm31)、[DM34](../../../sources/desktop-mobile-claims.md#dm34)、[DM35](../../../sources/desktop-mobile-claims.md#dm35)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

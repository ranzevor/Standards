# L4 账号隔离、离线队列与同步结果技术规范

**文档ID：** STD-L4-MOBILE-008　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

离线工作、账号切换和弱网未知效果下保持原主体、原操作与可验证权威结果，不虚构恰好一次。

**适用对象：** 离线可读写，持久操作账/队列，账号/租户，重试/去重边界，冲突/水位与旧客户端。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不强制 offline-first、联网或账号；不重写服务端幂等/事务算法，也不以客户端逻辑代替远端鉴权。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### MB4-01 离线任务与状态权威

**角色/前置/必要动作：** 产品必须明确哪些任务可离线、数据新鲜度和用户可见承诺；本地编辑已持久、待上传、同步中、远端确认、冲突、失败和未知结果分别呈现。网络连接只证明传输条件，不证明服务可达/已提交。UI 可从本地权威视图读，但远端副作用以相应服务确认。

**并发、超时、未知与恢复：** 断网/切网/门户登录和服务失联时提供真实状态与有界重试；在线专用功能可拒绝远端任务，不能阻断无关合法本地工作或显示假新鲜数据。

**产物、真实目标入口与判据：** 目标 App 通过系统网络切换和受控服务断连执行离线编辑、重开及重连；比较本地持久记录与隔离服务查询。判据为本地保存与远端确认不混同、数据新鲜度可辨认。

**正例：** 离线草稿可打开且标待同步。 **直接失败反例：** Wi-Fi connected 就显示远端提交成功，失败。 **合法邻例：** 在线专用查询可明确离线不可用。

**来源有限命题：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB4-02 队列身份与不可变请求

**角色/前置/必要动作：** 排队记录必须在对应持久边界关联 operation ID、主体/租户、对象及版本前置、动作、规范化参数摘要、端点契约版本和必要权限条件。凭据不作为长久主体 ID，不能将明文 token 放队列作无限期授权。相同操作 ID 重试须保持同一语义/参数；修改参数需明确新意图和关联关系。

**并发、超时、未知与恢复：** 恢复旧队列、重装/备份恢复和多入口入队须检测重复与过期契约；不能按当前登录用户重写旧记录主体。未成功持久的记录不确认已加入队列，单纯消息传输 ACK 不作业务完成。

**产物、真实目标入口与判据：** 让 A 离线入队，杀进程并切 B，再从真实存储重建 worker；检查 operation/主体/参数和实际出站身份。判据为无 B 凭据代发 A 操作、相同 ID 异参数明确拒绝，合法原操作仍可恢复。

**正例：** 原账号重获权后同 ID 同参数恢复提交。 **直接失败反例：** 切 B 后批量更新 queue.user=B 再发，失败。 **合法邻例：** 无账号应用用明确本地安装/工作区作用域即可。

**来源有限命题：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)、[DM29](../../../sources/desktop-mobile-claims.md#dm29)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB4-03 发送、未知与可靠防重边界

**角色/前置/必要动作：** 发送前重新鉴权并检查原操作身份/参数；区分明确未提交、发送在途、受权结果已确认和效果未知。敏感副作用未知后，只能通过绑定原主体/操作的权威查询，或在服务已验证的去重/结果保留边界内重用原请求恢复。客户端一个 key 不证明服务原子防重；保存期限应覆盖服务实际迟到接受/重试窗口。

**并发、超时、未知与恢复：** 服务结果未明、旧请求仍可能被接受或去重期已过时，不自动新建 ID 重做。新尝试未应用不证明旧尝试未应用；查询需对应原效果，错租户/对象/参数回执拒绝。合法只读请求可按其合同重试。

**产物、真实目标入口与判据：** 隔离服务在提交后丢响应，再重启客户端、重复同请求并越过去重边界；核服务效果账和回执身份。判据为有效期内可靠返回原结果、窗口外保留未知/人工核对，不因本地发出时间较早推断迟到请求已被服务拒绝。

**正例：** 有效防重期内原账号/同参数重试返回原回执且效果一次。 **直接失败反例：** 超时后换 key 再付款，失败。 **合法邻例：** 无独立查询端点但原幂等请求可靠返回原回执可合法恢复。

**来源有限命题：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB4-04 账号切换、撤权与在途

**角色/前置/必要动作：** 会话维护者必须让缓存/草稿/队列/下载/通知与原主体分区；退出/切换失效旧异步操作更新当前 UI 的权利，敏感新动作重新确认当前服务授权。已提交事务的完成/撤销边界按原业务合同，不能把本地退出一概当远端撤销。

**并发、超时、未知与恢复：** 排队后撤权、A 结果迟到 B 会话、后台持旧凭据和重启恢复时，阻止无权新提交并隔离有权保留的工作。无法撤回的在途效果保留原查询路径，不消失于列表就算取消。

**产物、真实目标入口与判据：** 目标 App A 离线工作→B 登录→A 的迟到网络/通知/worker 返回→重启，再切回 A；核缓存、通知、UI 和服务账。判据为无串号泄漏/写入，合法 A 重获权可恢复，不误删除其作品。

**正例：** 旧 A 回包只归 A 结果账，B 不展示。 **直接失败反例：** 后台自动用 B token 重放 A 队列，失败。 **合法邻例：** 明确共享工作区按独立授权可共享数据。

**来源有限命题：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)、[DM31](../../../sources/desktop-mobile-claims.md#dm31)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB4-05 冲突、版本前置与可恢复合并

**角色/前置/必要动作：** 同步层必须固定对象版本/修订比较、服务权威、删除语义和冲突决策；设备墙钟不自动决定全局先后。版本条件写入/合并/保留冲突副本按既定服务合同；离线编辑与远端删除、权限撤销不同，不自动用本地最新标签覆盖。

**并发、超时、未知与恢复：** 两个设备/场景并发、乱序回执和重复 delta 需避免旧回包倒退已确认版本；无法安全合并时保存双方差异供有权选择。取消上传不应丢本地草稿，用户确认覆盖须对应实际版本，过期确认重新判断。

**产物、真实目标入口与判据：** 两个隔离客户端基于同版离线改同对象，先后联网并交换回包顺序，再测试远端删/撤权；以服务版本和前后内容核对。判据为无静默丢编辑、冲突透明，独立对象可正常并行。

**正例：** 版本冲突保留本地副本和服务当前内容供选择。 **直接失败反例：** mtime 更大便覆盖所有远端内容，失败。 **合法邻例：** 已验证可交换的独立字段合并可自动完成。

**来源有限命题：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB4-06 增量同步、游标与清理

**角色/前置/必要动作：** 同步提交点必须绑定主体/数据集、服务游标/版本及本地已应用效果，分页获取、接收和持久应用不是同一水位。只有相关页/事件在实际事务或可恢复阶段完成后才推进消费游标；token 过期应走服务定义的重扫/快照，不伪造连续。

**并发、超时、未知与恢复：** 应用中断、重复/乱序页和部分水位不得漏数据；删除墓碑、队列或缓存之前核仍有未确认引用/保留义务。新快照不能将已应删除数据无判断复活，也不能清掉唯一待同步作品。

**产物、真实目标入口与判据：** 用固定隔离分页数据在持久应用前后杀进程，再重复页、换账号或过期 token；检查服务记录集与本地效果/游标。判据为无提前推进、可重入不重效果、合法重扫可恢复且不越主体。

**正例：** 页完整提交后原子推进该数据集游标。 **直接失败反例：** 收到第 3 页就保存最终水位，页内容未写即死亡，失败。 **合法邻例：** 无增量协议的小数据可按明确全量快照合同同步。

**来源有限命题：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### MB4-07 旧客户端、退役与验收分层

**角色/前置/必要动作：** 旧安装端不会跟随服务即时更新，产品必须固定支持窗口内 API/配置能力与最低版本行为。受限提交、只读/导出和数据去向分别约定；服务鉴权不依赖客户端隐藏按钮。退出、删除、通知解绑与终端卸载各确认其实际范围。

**并发、超时、未知与恢复：** 长期离线后恢复、协议不兼容、远端删未确认和残存终端需保留真实失败/未知，不以渠道下架或卸载测试宣称全端清除。兼容证据只复用其原协议/权限前提。

**产物、真实目标入口与判据：** 实际代表旧包对新隔离服务，含长离线、过期配置和撤权；回读本地导出/服务结果/队列与数据删除状态。判据为核心离线权利与安全边界同守，真实网络/设备未验保持 not-run。

**正例：** 旧端安全拒在线写，仍可取回有权本地作品。 **直接失败反例：** 最低版本门禁把用户唯一草稿锁死，失败。 **合法邻例：** 从不联网且无账号产品不激活服务兼容条款。

**来源有限命题：** [DM33](../../../sources/desktop-mobile-claims.md#dm33)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

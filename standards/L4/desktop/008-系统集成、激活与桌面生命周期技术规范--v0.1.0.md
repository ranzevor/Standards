# L4 系统集成、激活与桌面生命周期技术规范

**文档ID：** STD-L4-DESKTOP-008　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

让外部系统入口、窗口和后台工作的状态可辨认；系统已派发、应用已接纳与业务已完成不得混同。

**适用对象：** 文件/URI/Shell 激活，实例选择，多窗口，通知/托盘/登录项，睡眠/注销与设备任务。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不要求新增单实例、通知或常驻服务；IPC 身份由 P1 管理，文件保存由 P2 管理，焦点与显示由 P4 管理；不规定统一 Linux 会话行为。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### DT3-01 注册对象、有效状态与用户选择

**角色/前置/必要动作：** 集成维护者必须把每种注册关联到产品/渠道、安装范围、键或包扩展点、所有者和撤销条件。注册清单是意图，OS/桌面环境的有效关联才是当前入口权威。应用只能请求它确实处理的类型，不得把注册为候选解释成用户已选择默认；恢复/修复不得无条件恢复用户关闭的登录项。

**并发、超时、未知与恢复：** 两个版本或他方更改关联时，先比较当前拥有者和目标再修改；超时或安装中断后读取有效状态，不覆盖较新用户选择。某项注册失败应局部报告，不能伪造整个应用不可用。

**产物、真实目标入口与判据：** 产物为注册对象清单及前后有效值。Windows 用 Settings > Default apps、Get-AppxPackage 与实际 Explorer 打开；Linux 用 desktop-file-validate 和 xdg-mime query default；macOS 用 Finder 的 Open With。判据为所选 handler 与实际运行构建对应，改默认后应用不抢回。

**正例：** 用户选本应用处理一种已支持文档后正常打开。 **直接失败反例：** 修复安装把用户新选 handler 改回本应用，检查失败。 **合法邻例：** 仅内部使用格式不注册为默认候选仍合法。

**来源有限命题：** [DM15](../../../sources/desktop-mobile-claims.md#dm15)、[DM16](../../../sources/desktop-mobile-claims.md#dm16)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT3-02 激活参数与目标对象

**角色/前置/必要动作：** 激活接收者必须把文件列表、URI 和文本参数作为不可信输入，按平台入口取得结构化对象；定义解码层、允许 scheme/路由、数量、大小和必要资源授权。不得把拼接字符串转给 shell，也不得把文件选择或可信域名当成内容/对象授权。Desktop Entry 的 Exec 必须遵守 1.5 §7 的字段码与 quoting，而非发明 shell 展开。

**并发、超时、未知与恢复：** 重复编码、截断参数和对象已移动分别拒绝或重新选择；入队后对象/账号变化须在使用点复核。批量打开只报告实际成功项，无法解析参数不触发默认破坏动作。

**产物、真实目标入口与判据：** 从真实文件管理器多选“草稿 一.txt”和含非 ASCII 的第二文件；再以实际 URI 入口送重复编码、额外选项及超长值。跟踪接收的 argv/平台激活对象（不留正文），判据为边界完整、无额外程序和越权对象访问。

**正例：** 两个合法文件分别作为两个对象打开。 **直接失败反例：** 含空格路径被拆成选项并触发删除，直接失败。 **合法邻例：** 受控自定义 scheme 可按明确产品合同使用，不一律要求 HTTPS。

**来源有限命题：** [DM15](../../../sources/desktop-mobile-claims.md#dm15)、[DM16](../../../sources/desktop-mobile-claims.md#dm16)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT3-03 实例选举与转交接纳

**角色/前置/必要动作：** 需要单实例时，实例协调者必须以 OS 支持的排他原语或等效安全协议决定当前实例，绑定 OS 用户/登录会话及应用范围；PID 文件仅为线索。第二实例转交应经 P1 认证并返回关联激活 ID 的接纳结果。发送成功不证明目标窗口已打开或任务完成；多实例产品可按文档/工作区选择不同实例。

**并发、超时、未知与恢复：** 两个首启竞争、旧实例崩溃和假端点占位均不得产生双重无约束写者。超时保留“转交未知”，先核实例和原激活结果，不能启动第二个敏感提交。接管仅在有效原语证明可接管时实施。

**产物、真实目标入口与判据：** 在目标 OS 同时从 Shell 打开两个文档，并在接纳前后终止承接进程；以进程树、端点 owner、应用激活账和文档数核对。判据为符合实例合同、无假服务接收秘密、无永久陈旧锁；合法多实例各写独立对象可并行。

**正例：** 两次首启只产生合同规定的一个写者和两个被接纳文档。 **直接失败反例：** 超时便强删仍活跃实例的锁并重复提交，失败。 **合法邻例：** 多文档应用采用独立实例不是缺陷。

**来源有限命题：** [DM10](../../../sources/desktop-mobile-claims.md#dm10)、[DM13](../../../sources/desktop-mobile-claims.md#dm13)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT3-04 重复激活、窗口选择与业务效果

**角色/前置/必要动作：** 路由器必须区分系统事件 ID、打开/聚焦意图和有副作用业务操作 ID。重复“打开”可聚焦现有窗口或按合同新开，不应因去重永久阻止用户再次打开。外部回调需关联原发起会话、账号和有效期；敏感动作必须重验对象权限并取得适用确认，不由点击通知直接视为已批准。

**并发、超时、未知与恢复：** 冷/热启动与多窗口并发采用确定的上下文选择；旧回调不得写入当前任意窗口。业务效果未知时按权威结果核对，不因另一次 OS 事件 ID 重做相同效果；过期路由保留安全返回和草稿。

**产物、真实目标入口与判据：** Windows 用真实文件/URI 关联，macOS 用 open -a 指定应用与文件，Linux 用 gio open/xdg-open 在选定会话派发；交错两窗口、重复回调及账号切换。判据为目标、任务次数和持久结果一致，不只看进程启动退出码。

**正例：** 重复打开聚焦同一文档，新的明确打开意图仍可工作。 **直接失败反例：** A 的登录回调到达 B 窗口后切换 B 身份，失败。 **合法邻例：** 纯无副作用帮助 URI 允许重复显示。

**来源有限命题：** [DM15](../../../sources/desktop-mobile-claims.md#dm15)、[DM16](../../../sources/desktop-mobile-claims.md#dm16)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT3-05 关闭、退出、登录项与通知生命周期

**角色/前置/必要动作：** 生命周期控制者必须区分关窗口、最后窗口关闭、退出进程、后台驻留、通知许可和登录启动。后台仍有工作时应有与产品合同相符的可见查询/退出入口；托盘图标消失不是工作已结束。通知负载最小化并在点击后重新鉴权；禁用自启动的有效选择不得被每次启动覆盖。

**并发、超时、未知与恢复：** 退出与新激活交错时明确定义接纳界线：已接纳工作安全完成、持久移交或准确失败；退出超时保留未完成/未知清单，不以 UI 消失充当取消确认。系统不承诺退出回调时，不依赖该回调保存唯一工作。

**产物、真实目标入口与判据：** 用系统 Task Manager/Activity Monitor/ps、通知设置与登录项界面，执行 Close/Exit、再激活、拒绝通知和用户禁用登录项后重开。判据为进程/任务及 UI 记录一致，唯一草稿可重开，禁用选择保持。

**正例：** 按合同关闭窗口后托盘仍能显示和取消下载。 **直接失败反例：** 窗口关闭后无入口的 helper 无限上传，失败。 **合法邻例：** 无后台职责的应用最后窗口关闭即退出合法。

**来源有限命题：** [DM15](../../../sources/desktop-mobile-claims.md#dm15)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT3-06 休眠、会话切换与时间坐标

**角色/前置/必要动作：** 系统事件接收者必须在唤醒/会话恢复后重读资源、网络、账号、锁和有效权限；睡眠前缓存不作当前权威。超时使用合适的单调时间度量并说明睡眠是否计入，凭据/业务期限用其权威时间；两种时间不得随意相减。不得把系统事件到达视为所有子组件已恢复。

**并发、超时、未知与恢复：** 唤醒事件重复、显示设备改变和会话退出可交错；恢复每项关键动作前重验条件，过期写入拒绝且保留草稿。无法确认远端副作用时先查询，不将睡眠当网络请求取消。

**产物、真实目标入口与判据：** 在目标 OS 通过系统菜单 Sleep/Resume、锁屏解锁或用户切换；跨测试凭据期限，核 app 事件、运行时钟与受权查询结果。判据为未越权重放、窗口可达、用户状态与实际结果相符；仅模拟时间单测不代替 OS 实验。

**正例：** 唤醒后重新认证再同步原账号队列。 **直接失败反例：** 休眠后复用过期权限并显示旧请求已取消，失败。 **合法邻例：** 不联网的只读文档恢复无需新增登录。

**来源有限命题：** [DM13](../../../sources/desktop-mobile-claims.md#dm13)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT3-07 设备接管、任务未知与注销收敛

**角色/前置/必要动作：** 使用打印、音视频、外接盘等能力时，资源控制者必须关联设备实例、提交 ID、权限和接管阶段。系统队列已接收、设备完成与用户实际获得输出分别观察。设备重连同名不证明同一设备；注销或关机只给有限清理机会，关键检查点应先由 P2 达到承诺。

**并发、超时、未知与恢复：** 拔出、设备忙、会话结束及回包丢失时保留已提交/未提交/未知状态。重试先核队列或设备可提供的权威结果；缺乏查询的不可逆动作不得盲重放。已确认未提交或无副作用读取按合同恢复。

**产物、真实目标入口与判据：** 目标系统通过打印队列界面、所用设备官方状态工具及实际拔插/注销路径核对；以合成文档和模拟输出设备优先，记录设备无法确认的物理结果。判据为次数不虚报、不重复打印、不因设备失联删源文档。

**正例：** 未提交打印在用户选择后送往当前获准打印机。 **直接失败反例：** 旧打印已被系统接纳但超时后自动再印一份，失败。 **合法邻例：** 无该类设备功能的产品不产生对应义务。

**来源有限命题：** [DM15](../../../sources/desktop-mobile-claims.md#dm15)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

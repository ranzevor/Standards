# L4 本地应用架构、进程通信与权限边界技术规范

**文档ID：** STD-L4-DESKTOP-005　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

> 项目采用范围与实现验收分别记录；符合性由相应条款的实际执行证据判定。

## 目标与非目标

目标是本地输入跨进程/权限/内容边界时仅获得当前有权的最小能力；非目标是强制多进程或自制认证协议，也不承诺普通用户态对抗已控制管理员/内核的主体。

## 术语、角色与共同验收规则

“必须/应/不得”为适用条件成立时的规范要求，“建议”为可有依据替代，“例如/示例”为非穷尽说明。每条由其适用对象的组件实现者负责，产品维护者固定支持合同，L5 固定平台/API/工具版本，验证者留准确环境与原始结果。每条输入/输出与权威细化附于条内；本地/OS/渠道/远端各只对其管辖事实确认，日志字段不认证真实权限或效果。

继承所引用的 [L3 通用工程规范 v0.1.0](../../L3/001-通用工程规范--v0.1.0.md) 的工程与证据接口，不由此推定正式采用。

所有适用条款的前置为支持组合、准确运行构建、相关账号/资源/操作身份及必要预算已可定位。并发或异步状态绑定实例、账号/工作区、文档/场景和操作代际；互不相关对象允许并行。超时/断连/取消请求不是效果未发生；有界重试及恢复应先核未知结果，已确认未提交或无副作用路径可按合同重试。时钟、预算和兼容版本由采用合同固定，不从统一毫秒阈值或 latest 页面推断。完成以条内目标与判据回读，正常/直接失败/合法邻例共同验证。

## 一、对象、适用与效力

本专题为第07领域规划 P1，管理 UI、后台、helper、渲染器、插件之间的本地执行与信任边界，以及 IPC 端点、消息、特权代理、沙箱、动态授权和 WebView 原生桥。进程拆分本身既不证明隔离，也不要求所有应用拆成多进程。纯原生单进程、无插件、无网络和无提权的编辑器可只采用实际存在的输入与资源权限条款；不存在的端点可以不适用，存在但未测不得标成不适用。

本文“应/不得”按项目选定的适用条款执行。

L6 固定实际平台、OS/SDK/运行时区间、发行模式、用户群、是否支持跨会话/跨用户调用及威胁模型。至少区分另一 OS 用户、同用户无关进程、被攻陷的低信任页面/插件与已控制管理员/内核的攻击者。不能承诺普通用户态边界抵御已控制所有进程的攻击者；也不能用这一局限免除可以实施的同用户端点保护。

## 二、继承与技术分工

- L0/L1/L2 保留分层、批准、例外、授权与唯一写入职责；L3 保留通用对象级授权、输入验证、密码材料、测试与副作用语义。P1 将这些落实到可变本地进程、连接及文档上下文，不另建通用身份协议或密码学标准。
- 桌面基线 D02–D04、D11–D12、D21 是范围依据；本专题新增端点创建/抢占、双向对端认证、连接代际、能力转交、异步回包和撤权时序等可检查机制，不以重述基线代替专项。
- 已有 Web《浏览器身份与应用安全》继续负责 Web 身份、同源/跨源、脚本注入与远端会话；P1 负责这些不可信内容跨入本地能力的入口。已有供应链专题负责制品来源与签名算法；P1 消费运行对端身份，不用“已签名”替代动作权限。存储专题保留持久化和崩溃恢复算法。
- P2 文件持久化、P3 系统激活、P5 安装、P6 版本切换和 P8 诊断分别提供下文所列技术接口；这些专题按职责提供接口，不形成循环采用前置。文件安全打开、Shell 注册、更新回退细则不在此重编。
- L5 选择 Electron/Tauri/Qt/.NET/AppKit 等实际 API、参数、权限清单和兼容版本。本文的 Windows/macOS/Linux 实例均按条件激活，不默认三平台或某个框架。

## 三、信任与执行状态模型

项目应能从现有架构及接口材料识别：组件的运行身份、有效权限、输入可信度、秘密/用户数据持有位置、可启动的子进程、实际端点、直接与间接能力、重启/退出责任。UI 进程不天然可信；后台进程不天然特权；签名同发布者的两个程序也不天然共享业务授权。

敏感操作至少区分：未接纳、已认证连接、已验证并授权请求、排队、执行中、已确认结果、拒绝、取消已确认、结果未知。传输成功不等于授权成功；连接断开、超时或发送取消并不证明执行未发生。身份和能力须绑定到实际连接/运行实例，并按需要再绑定 OS 登录会话、应用账号、工作区、文档和文档代际。字段由可信接收端建立或验证，不能信任消息自报的 `userId`、PID、来源 URL 或 `isAdmin`。

“能力”指允许某主体对特定资源执行特定动作的可验证授权，不强制采用自制令牌。操作系统句柄、受控连接或成熟平台能力机制均可；凭证的生成、保存和密码学沿用适用通用规范。

## 四、具体机制与验收契约

### I01 实际隔离与职责分离
**适用：** 多组件、加载外部输入或需要不同权限。应将高风险解析、网页/插件执行与秘密及特权动作隔离到与风险相称的边界。线程、模块命名、同进程 JavaScript context 不是 OS 进程隔离；进程拆分后若继承全部权限和秘密，仍须说明实际减少了什么风险。合法可信内置扩展可与主进程同权，但须明确这是可信计算基的一部分，不宣传可安全运行任意插件。

**检查与失败：** 对照实际进程树、用户/完整性或沙箱状态、文件/网络可达范围及加载模块；低信任组件直接访问受限资源应被平台或受控代理拒绝。确实需要同权组件时记录理由和输入边界，不为了形式增加后台服务。

**输入、输出与权威补充：** 架构者将不可信输入、秘密与执行权映射实际进程/沙箱；输出可达能力图。

**正例：** 同进程可信内置扩展明确为 TCB。

**具体目标入口与完成判据：** Process Explorer/ps 与实际受限资源读取；不把线程名当隔离。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM11](../../../sources/desktop-mobile-claims.md#dm11)、[DM12](../../../sources/desktop-mobile-claims.md#dm12)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I02 启动链与隐式继承
**适用：** 派生进程或加载可执行扩展。应控制可执行目标、工作目录、环境、动态加载搜索位置及可继承句柄/文件描述符；只传必需资源，不把长期令牌放入可公开诊断的命令行。应检查插件入口是否由低权限可写目录替换，以及服务启动是否误读用户可写配置。与发行物绑定的可执行身份不等于所有参数均可信。

**检查与失败：** 使用同名程序、替换工作目录、额外继承连接及污染环境的受控测试；不得启动替代程序或泄漏未授权资源，启动失败不能回退为 shell 任意执行。合法用户选择的工具需按明确产品合同处理，不一律禁止外部工具。

**输入、输出与权威补充：** 启动者输入可执行身份/参数/环境/继承集，输出最小子进程；实际映像/句柄为权威。

**正例：** 获准外部工具只取得其必需资源。

**具体目标入口与完成判据：** 目标进程工具核映像、工作目录、环境与继承 FD/handle；同名替代程序反例。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM11](../../../sources/desktop-mobile-claims.md#dm11)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I03 端点生命周期与服务端身份
**适用：** 命名管道、socket、本地 HTTP、总线或第二实例接收端。端点名称不是秘密也不是身份。应以平台安全创建和访问控制约束谁能创建/连接，避免先检查名称再无条件创建的竞态；已有端点须验证其实际所有者/对端，不能自动删除可能属于仍运行实例的端点。

客户端在向 helper 发送秘密或有权操作前，应确认连接的是期望服务，而不仅要求服务验证客户端。随机端口、loopback 和“仅本机”不能单独解决抢占或伪服务。TCP 端点还需限制监听接口，并考虑网页发起的跨站请求；CORS 响应可读限制不是敏感请求授权。

**检查与失败：** 先启动假服务占据名称/端口、重启与陈旧端点、另一用户连接；应拒绝或选择可验证的新连接，不向假服务发送秘密。平台支持的受保护私有通道可无需再叠加无意义的网络登录。

**输入、输出与权威补充：** 端点创建者输入名称/会话/安全描述符，输出受保护连接；实际 owner/凭证非端点名为权威。

**正例：** 私有受控继承通道经验证后可用。

**具体目标入口与完成判据：** 先起假服务占名/端口，再实际连接并看秘密是否发送。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM10](../../../sources/desktop-mobile-claims.md#dm10)、[DM13](../../../sources/desktop-mobile-claims.md#dm13)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I04 连接身份与请求授权分开
**适用：** 跨边界消息。应使用 OS/运行时可信对端资料或符合威胁模型的能力凭证，明确身份检查究竟证明用户、登录会话、应用还是特定实例。PID、路径、进程名及消息携带 UID 不足以独立授权；若用 PID 查询其他身份，须处理重用和检查到使用的竞态。认证后仍须逐项核对动作、资源、账号和工作区。

采用 Windows 命名管道时须检查实际 DACL，而非假定默认描述符私有；采用 D-Bus 时应绑定实际连接身份，服务名变更后旧身份缓存不得继续使用，缺失的凭证字段不能被当作匹配。[DM10](../../../sources/desktop-mobile-claims.md#dm10)[DM13](../../../sources/desktop-mobile-claims.md#dm13) 具体获取机制由 L5 固定。

**检查与失败：** 同 UID 的无关客户端、另一个登录会话、伪造账号字段、断线重连及服务所有权变化均有拒绝对照；合法跨用户服务按其显式策略授权，不机械要求所有调用同 UID。

**输入、输出与权威补充：** 接收者输入可信连接身份与动作对象，输出逐项授权；OS/总线凭证不是消息自报字段。

**正例：** 显式获权跨用户服务可合法调用。

**具体目标入口与完成判据：** GetSecurityInfo、真实 D-Bus GetConnectionCredentials/NameOwnerChanged 加动作拒绝。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM10](../../../sources/desktop-mobile-claims.md#dm10)、[DM13](../../../sources/desktop-mobile-claims.md#dm13)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I05 消息结构、版本与资源上限
**适用：** IPC 请求及回复。应定义有限的操作集合、类型、长度/嵌套/集合规模、允许未知字段的版本规则、错误码和超时。先验证帧与大小再分配资源或反序列化，避免不可信数据实例化任意类型/对象；校验语义组合而不只校验 JSON 可解析。协商不支持的版本或能力时拒绝相应动作，不降级为更宽松的旧通道。

**检查与失败：** 截断帧、过大长度、递归结构、未知操作、类型混淆、版本不兼容应产生有界拒绝，不让特权进程耗尽或执行默认命令。已定义的可忽略扩展字段及正常大文档流式传输可合法通过，额度由 L6 负载确定，不强制全领域字节值。

**输入、输出与权威补充：** 解析者输入有界帧/schema/能力版本，输出受限消息或错误；先验长度再分配/执行。

**正例：** 合法可忽略扩展字段保留兼容。

**具体目标入口与完成判据：** 实际协议 handler 送截断/大长度/未知操作并测资源与正确正常大文档。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM13](../../../sources/desktop-mobile-claims.md#dm13)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I06 能力、资源引用与转交
**适用：** IPC 带路径、句柄、共享内存、文件描述符或能力令牌。应绑定操作、资源、主体、有效期/生命周期及可转交范围。传递句柄可能直接传递读写权，不能只检查消息声明的权限；共享内存需处理验证后被发送方改写的竞态，以不可变快照、受控所有权或等价机制使用。接收端要验证实际对象和权限，不能仅凭路径前缀或客户端声明。

**检查与失败：** 读授权请求写入、把一个工作区能力用于另一个、扩大句柄权限、检查后篡改共享数据；越界动作被拒且多余资源关闭。合法只读句柄及限定资源的流式读取不应被一概禁止。路径解析与持久化方案在相应存储/L5 规范落实。

**输入、输出与权威补充：** 能力接收者输入实际句柄/共享对象及动作，输出限定使用；资源对象和当前授权为权威。

**正例：** 只读句柄可进行获权读取。

**具体目标入口与完成判据：** 目标平台句柄/FD 检查，加验证后共享数据替换交错，核最终对象权限。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM03](../../../sources/desktop-mobile-claims.md#dm03)、[DM10](../../../sources/desktop-mobile-claims.md#dm10)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I07 特权 helper 的受约束代理
**适用：** 需要机器级修改或特权资源。普通任务应以普通身份运行；把确需提权的最小操作放入明确入口，接收端重做调用者、参数、目标和当前权限检查。用户同意某次提权不是同意后续任意命令。禁止将低信任调用映射为任意 shell、任意目标文件写入或任意模块加载的特权代理；合法管理工具本身需要命令执行时，必须按明确产品安全合同限定调用主体、用途及交互，不伪装成普通 helper。

**检查与失败：** 参数选项注入、目标换成系统/他人对象、权限对话框拒绝、队列等待后账号已切换；不得产生未授权副作用。拒绝时旧状态保留，不能自动扩大 ACL 或关闭系统保护。完成应回读目标状态，不能凭 helper 退出 0 宣称系统修改成功。

**输入、输出与权威补充：** 特权代理输入最小动作/调用者/目标，输出回读结果；当前 OS 与对象权限为权威。

**正例：** 确需机器级的受限安装动作可完成。

**具体目标入口与完成判据：** 普通账号调用 helper，参数注入/换目标/拒绝提权；核目标无越权变化。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM10](../../../sources/desktop-mobile-claims.md#dm10)、[DM12](../../../sources/desktop-mobile-claims.md#dm12)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I08 异步、重入、取消和副作用未知
**适用：** 请求排队、并发、长操作或重连。请求及回复应关联连接代际和请求标识，关键有副作用动作定义去重范围与保存期限；消息重传不得无条件重复执行。授权检查与产生副作用之间存在等待或重入时，应在提交边界重新确认仍有效的权限/目标，不能让一次旧检查无限生效。

**检查与失败：** 提交后回包前断线、重复请求、取消与提交交错、接收端重启；区分未执行、已完成与未知。未知时先查询受权结果，不能自动重做不可逆操作。取消已经提交的动作不承诺回滚；无副作用读取可按契约重试。去重令牌不是对未经认证请求的授权。

**输入、输出与权威补充：** 请求控制者输入连接/账号/操作代际，输出已确认/未知；真实目标效果非传输 ACK 为权威。

**正例：** 同 ID 同参数在可靠防重窗内返回原结果。

**具体目标入口与完成判据：** 提交后断连、重启、取消交错，核权威查询与副作用次数。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM13](../../../sources/desktop-mobile-claims.md#dm13)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I09 沙箱与有效权限的叠加
**适用：** 启用平台沙箱或资源权限。应分别记录 OS 用户权限、沙箱清单/entitlement、用户选择的临时资源授权、应用自身策略与设备管理限制；有效动作须同时满足实际约束。已签名、公证、安装成功或程序内开关不证明获得访问权限。沙箱内代理可形成间接逃逸能力，必须将可调用宿主服务一并纳入边界。

采用 Flatpak 时，区分静态权限与 portal 的资源选择，审查实际总线/文件访问；不要用全总线或全主目录授权来掩盖一个资源请求错误。[DM14](../../../sources/desktop-mobile-claims.md#dm14) macOS 采用方必须分别声明沙箱资源界限与所选 IPC 的对端限制，逐接口核具体 SDK，不以沙箱配置代替对端授权。[DM21](../../../sources/desktop-mobile-claims.md#dm21)

**检查与失败：** 缺权限、宿主策略禁止、清单过宽或代理扩大访问；拒绝相关操作而保留无关合法功能。开发工具确需广泛资源时按其真实合同明确，不对所有 Linux 应用强套 Flatpak。

**输入、输出与权威补充：** 沙箱适配者输入清单、portal、宿主代理和账号策略，输出有效能力交集。

**正例：** 受控文件选择器可访问选定资源。

**具体目标入口与完成判据：** flatpak info --show-permissions 与实际 portal；macOS 核所选沙箱/IPC 接口。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM14](../../../sources/desktop-mobile-claims.md#dm14)、[DM21](../../../sources/desktop-mobile-claims.md#dm21)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I10 动态撤权、失效与剩余访问
**适用：** 可撤销资源、应用账号切换、工作区关闭或能力过期。应定义授权取得、使用、拒绝、撤销、暂不可用与恢复；在新请求和关键使用点检查当前状态，关闭或失效本应用管理的旧句柄、订阅、缓存凭证与排队任务。系统权限弹框的允许不替代应用账号授权，账号注销也不必然撤销系统永久权限。

撤权不一定能收回平台已发放的句柄、已缓存内容或已发生副作用；L5 应核实际语义，L6 对残余访问和收敛时限给出真实说明，不宣传即时追溯删除所有副本。应用至少阻止其可控制的新使用，处理正在执行操作的安全结束并如实确认结果。

**检查与失败：** 访问中撤权、撤权后再请求、休眠后恢复、重新授权与进程重启；不得静默降级全盘权限或旧账号继续访问。文件暂离线不自动等于撤销；恢复连接仍须重新确认身份和权限。

**输入、输出与权威补充：** 授权者输入撤权/关闭/过期事件，输出可控新使用失效；当前资源能力与账号权利为权威。

**正例：** 暂离线恢复后重验可继续。

**具体目标入口与完成判据：** 系统设置撤权/重启、旧句柄再用；说明平台残余语义，不伪造全面回收。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM14](../../../sources/desktop-mobile-claims.md#dm14)、[DM34](../../../sources/desktop-mobile-claims.md#dm34)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I11 WebView 桥的来源、帧与文档身份
**适用：** 网页调用原生能力。应只暴露任务级最小操作，不透出通用 IPC 对象、原生对象反射、文件系统或命令代理。每次调用验证运行时可信的发送帧/文档身份与来源及当前授权，不以消息自报 URL、字符串前缀、可混淆域名或初始加载 URL 作为证明。主帧、子帧、子窗口和销毁帧分别处理；相同 origin 仍不证明脚本未被攻击，操作范围限制必须继续有效。[DM11](../../../sources/desktop-mobile-claims.md#dm11)[DM12](../../../sources/desktop-mobile-claims.md#dm12)

不透明 origin、`about:blank`、`blob:`、本地文件及自定义 scheme 的身份规则由所选运行时确定，不用 URL 外观猜测。不能把所有 `null` origin 合并为受信站点。来源无法可靠确认的敏感桥应拒绝。

**检查与失败：** 外域 iframe、同名域、子窗口、伪造 URL、销毁帧调用；不泄露秘密不执行特权动作。受信本地 UI 调用限定任务可通过；不需要桥的静态帮助页不必提供桥。

**输入、输出与权威补充：** 桥接收者输入可信 sender frame/document/origin 及动作，输出最小能力；原生可信上下文为权威。

**正例：** 可信原文档限定调用可通过。

**具体目标入口与完成判据：** 真实 Electron/WebView2 外域 iframe、null/销毁帧/伪 URL 与原生效果检查。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM11](../../../sources/desktop-mobile-claims.md#dm11)、[DM12](../../../sources/desktop-mobile-claims.md#dm12)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I12 导航、异步回包与账号代际
**适用：** 桥调用异步执行、页面可导航或账号可切换。导航到新文档后应更新/撤销旧文档的桥能力；出站秘密和异步结果发送前也核对原请求文档、帧、账号/工作区代际，不能只校验入站请求。应避免使用“当前窗口”作为旧请求默认回复目标。平台没有可靠绑定机制时，丢弃旧回复并让仍有权的新文档重新发起。

导航、下载、新窗口和外部打开各有策略，不将允许浏览某 URL 等同允许该页面取得原生权限。受信源重定向也须重新判断；安全外部浏览替代不能隐式传出文档秘密。[DM11](../../../sources/desktop-mobile-claims.md#dm11)[DM12](../../../sources/desktop-mobile-claims.md#dm12)

**检查与失败：** 可信页面发请求后导航外域、同源新文档、账号切换、返回历史页、重开同名窗口；旧结果不得落入新上下文。原文档仍在且权利未变的正常异步回复可达，不因所有异步调用都拒绝而丢失必要功能。

**输入、输出与权威补充：** 回复者输入原请求文档/帧/账号代际，输出仅到仍有效接收者的结果。

**正例：** 原帧同账号异步完成可达。

**具体目标入口与完成判据：** 请求后导航外域/同源新文档再回包，查真实出站秘密与效果。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM11](../../../sources/desktop-mobile-claims.md#dm11)、[DM12](../../../sources/desktop-mobile-claims.md#dm12)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I13 插件及扩展能力生命周期
**适用：** 加载插件、脚本或原生扩展。应定义可信内置与第三方扩展、进程内与隔离执行的差异，按每个扩展声明及实际授予能力暴露版本化接口。来自插件的数据/动作不能借宿主身份绕过权限。插件更新、重载、停用时核对兼容性、连接代际和遗留任务/资源，不能仅卸载菜单仍留下有权后台执行。

**检查与失败：** 未声明能力、插件 B 复用插件 A 能力、更新后增加权限、停用后继续回调；拒绝越界并清理本应用可控资源。内存已加载的原生代码不能假装通过关闭开关即时安全卸载；如须进程重启才生效，应明确限制并按产品合同安全恢复。合法同权可信扩展不被误称沙箱扩展。

**输入、输出与权威补充：** 插件维护者输入扩展身份/能力/版本，输出授予/停用及资源收敛；宿主实际代理为权威。

**正例：** 可信同权内置扩展可按 TCB 合同。

**具体目标入口与完成判据：** 更新/停用后旧回调和能力串用，核实际原生模块/后台资源；需重启时明确。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM11](../../../sources/desktop-mobile-claims.md#dm11)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I14 本地秘密、账号与响应范围
**适用：** helper/后台持有令牌或敏感结果。接收端应优先代执行限定动作而不是把所有秘密返回低信任调用者；确需传递时绑定最小接收方、生命周期和用途。OS 用户相同不能证明应用账号相同，账号/工作区切换要隔离缓存、挂起回复和资源引用。日志只保留排障必需关联与拒绝原因，不记录能力凭证/完整敏感载荷。

**检查与失败：** A 账号发起后切 B、秘密库锁定/不可用、调试日志输出原消息、旧连接查询新账号；不得串号或明文降级，保留可恢复用户数据。无秘密且公开信息广播可以无需身份过滤，但须明确数据确实公开。

**输入、输出与权威补充：** 秘密持有者输入原主体/用途/接收上下文，输出最小响应；OS 用户不等于应用账号。

**正例：** 公开无秘密广播可不按账号过滤。

**具体目标入口与完成判据：** A 请求切 B、锁秘密库、查真实日志与回复，不把 full payload 用于排障。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM34](../../../sources/desktop-mobile-claims.md#dm34)、[DM12](../../../sources/desktop-mobile-claims.md#dm12)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

### I15 故障封闭、可用性与边界复验
**适用：** IPC 服务、helper 或插件故障。应限制单连接/主体占用、并发、队列与重试，释放断连资源，不让不可信客户端阻塞所有 UI 或耗尽特权服务。重启后的握手、身份及权限不得直接复用旧进程状态。错误应区分策略拒绝、协议不兼容、资源忙、不可达和结果未知，使合法用户有可行恢复而不是关安全软件。

**检查与失败：** 慢客户端、洪泛、半帧断连、服务崩溃/重启和合法用户并发；资源有界、必要合法任务可恢复，不能用无限重试掩盖权限错误。诊断权限只授予必要元数据，不增加公开调试端口。性能数值和恢复预算由 L6 固定。

**输入、输出与权威补充：** 服务者输入连接负载/协议错误，输出有界队列/重握手和错误分类。

**正例：** 预算内合法并发可正常完成。

**具体目标入口与完成判据：** 慢连接/半帧/洪泛与服务重启，查 CPU/FD/队列及合法客户端恢复。 以本条机制、失败处理及案例表的预期为通过条件；同时对照正常/直接失败/合法邻例，超时或未知不得标已确认。

**来源边界：** [DM10](../../../sources/desktop-mobile-claims.md#dm10)、[DM13](../../../sources/desktop-mobile-claims.md#dm13)；仅采用各来源所列有限事实，动作/身份栅栏、恢复和案例为组织合成契约。

## 六、实际验收入口和变更门禁

L5/L6 应在现有项目测试材料中将上述条款映射到实际端点/handler/平台工具，不要求创建额外竞争台账。每个适用边界至少有：最终运行构建身份与 OS/运行时版本；服务端及客户端真实身份；权限及消息契约；合法调用、未授权对端与失败恢复对照；原始结果、目标对象前后状态与未覆盖项。平台配置、模拟消息和真实 OS 拒绝分别记录。

运行验收分为：①静态进程/端点/清单与桥面审查；②受控协议解析与状态机检查；③目标系统不同用户/会话及同用户无关进程的真实连接拒绝；④实际导航/子帧/回包时序；⑤权限拒绝、撤销、重启和真实副作用结果回读。所声明的安全边界若无法由当前环境验证，应列待补证，不能把 Mock 或容器测试写成平台隔离已通过。无需测试未承诺的平台。

变更进程拓扑、IPC schema、helper 动作、插件能力、桥 API、origin 策略、运行时/SDK 或授权生命周期时，复验受影响边界和合法邻例。框架默认值变化不自动改变已批准义务；L5 固定实际版本及配置，例外按 L1 授权并具补偿及期限。

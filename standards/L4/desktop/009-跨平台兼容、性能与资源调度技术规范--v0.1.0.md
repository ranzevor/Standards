# L4 跨平台兼容、性能与资源调度技术规范

**文档ID：** STD-L4-DESKTOP-009　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

把支持承诺落实为目标加载能力与可重复测量的资源合同，同一源码或编译成功不证明目标兼容和交互性能。

**适用对象：** OS/CPU/ABI/依赖/显示协议/GPU，启动与 UI 调度，内存/句柄/I/O/能耗，压力与长时测试。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不强制三平台、特定框架、统一毫秒阈值或全部设备两两遍历；包安装由 P5，输入/AT 由 P4。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### DT7-01 支持画像与能力探测

**角色/前置/必要动作：** 产品维护者必须声明 OS 最低/关键版本、CPU/ABI、渠道、运行时、显示会话、硬件/驱动及核心任务差异；实际探测必要能力，不以 OS 名称或虚拟 CPU 特征替代。原生、仿真和兼容层运行分别登记，不能把一者证据覆盖全部。

**并发、超时、未知与恢复：** 能力缺失在修改关键数据前拒绝或安全降级并说明限制；探测未知保留未知，不自称兼容。支持范围变化不能由一次测试失败静默删项。

**产物、真实目标入口与判据：** 记录 Windows systeminfo/IsWow64Process2，macOS sw_vers/uname，Linux uname/会话协议及目标核心任务。判据为每项支持声明关联准确产物和证据，未声明的平台不误判失败，已承诺缺证不得改不适用。

**正例：** 仅 Windows x64 的产品完整覆盖该合同。 **直接失败反例：** ARM 仿真运行一次就声称本机驱动支持 ARM64，失败。 **合法邻例：** 已验证兼容层可以列为明确受支持模式。

**来源有限命题：** [DM23](../../../sources/desktop-mobile-claims.md#dm23)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT7-02 加载闭包、ABI 与插件边界

**角色/前置/必要动作：** 构建/运行维护者必须把主程序、原生库、helper、插件、C运行库和驱动组成加载闭包，固定 ABI、位数、架构、最低符号/系统要求。进程内模块须满足实际 ABI，跨进程协议须独立版本化；源兼容不是二进制兼容。搜索路径和动态选择不得由低信任目录抢占。

**并发、超时、未知与恢复：** 缺库、未支持指令、旧 libc/驱动和混位数应在数据迁移前可诊断拒绝；不能通过临时扩大搜索路径或载入任意同名库“修复”。可选模块缺失不应阻断无关合法功能。

**产物、真实目标入口与判据：** Windows dumpbin /headers /dependents，macOS file/lipo -info/otool -L，Linux readelf -h -d -V；再在干净目标实际加载所有必需组件。判据为静态闭包与真实 loader 一致，错架构反例失败可定位，不把 ldd 不可信程序当安全分析入口。

**正例：** 正确 ABI 插件装载，缺可选插件时核心编辑正常。 **直接失败反例：** 只验主 EXE 而 helper 为另一架构无法运行，失败。 **合法邻例：** 纯托管程序仍需验证实际运行时，但不虚构原生插件。

**来源有限命题：** [DM23](../../../sources/desktop-mobile-claims.md#dm23)、[DM25](../../../sources/desktop-mobile-claims.md#dm25)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT7-03 图形、显示协议与降级

**角色/前置/必要动作：** 渲染维护者必须记录实际 GPU/API、驱动、显示会话、字体和必要特性；功能探测与失败回退绑定具体能力。无 GPU 或远程会话模式只有在任务/正确性仍满足时才称支持，不以画面出现证明输出正确。

**并发、超时、未知与恢复：** 设备丢失、驱动重置、Wayland/X11 或远程会话变化时安全重建可丢图形资源，保留文档与任务；有界重试，软件渲染不能悄然改变安全/数值准确性。

**产物、真实目标入口与判据：** 在支持的硬件/驱动和会话运行确定渲染任务，保存截图与业务输出/命中/字体对照；触发显示器切换和可安全模拟的设备丢失路径。判据为功能正确、窗口可达及预算分别满足；容器无显示编译仅算构建。

**正例：** 无硬件加速时已验证软件路径仍可编辑导出。 **直接失败反例：** GPU 恢复清空文档或无限重启，失败。 **合法邻例：** 不使用 GPU 特性的工具无需 GPU 专项压力。

**来源有限命题：** [DM19](../../../sources/desktop-mobile-claims.md#dm19)、[DM23](../../../sources/desktop-mobile-claims.md#dm23)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT7-04 测量定义、样本与启动合同

**角色/前置/必要动作：** 性能负责人必须固定冷/热启动、可操作点、输入响应、完成点、代表数据、重复次数与统计口径；记录硬件、电源/温度、OS、构建及后台负载。采纳的预算由产品风险与需求决定，均值、尾延迟和失败分母不得互换。

**并发、超时、未知与恢复：** 缓存/网络/首次编译条件不同不得混比；超时或失败样本计入合同的失败分母，无法控制噪声应报告不确定性。优化不得靠删必要工作或改阈值抹回归。

**产物、真实目标入口与判据：** Windows WPR/WPA，macOS Instruments Time Profiler/Launch，Linux perf/选定 trace 工具，按固定用户操作标记可操作点。判据为准确构建、原始轨迹和分布可复算，冷/热及成功/失败分列，不宣称一次最快值代表预算。

**正例：** 相同机器与负载多次测量保留慢样本。 **直接失败反例：** 剔除全部启动失败后报告 100% 达标，失败。 **合法邻例：** 不承诺交互的批处理可采用不同响应预算。

**来源有限命题：** [DM45](../../../sources/desktop-mobile-claims.md#dm45)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT7-05 UI 调度、取消与背压

**角色/前置/必要动作：** 调度者必须把耗时解析、I/O 和计算与 UI 响应分离，限制并发、排队和内存；进度/取消绑定操作代际。调用取消只是请求，需区分未提交、可中断、已提交及未知；回包只更新仍有效对象，不阻塞主循环等待自身回调。

**并发、超时、未知与恢复：** 输入洪泛、窗口销毁和后台转前台时，旧任务不得反向覆盖新工作；取消后释放本地可控资源，在真实协议允许的边界结束，不能承诺已发生效果回滚。背压保留明确忙/重试路径。

**产物、真实目标入口与判据：** 用目标 trace 工具观察大文档解析中输入/滚动/取消，记录 UI 线程、队列深度和操作结果；反序释放回调并关闭窗口。判据为需求预算内响应、队列有界和文档正确，拒绝全部工作不算成功。

**正例：** 大任务忙时可取消且独立小文档仍可编辑。 **直接失败反例：** 主线程同步等待需要主线程执行的回复而死锁，失败。 **合法邻例：** 受控短任务可在主线程执行，须满足预算。

**来源有限命题：** [DM45](../../../sources/desktop-mobile-claims.md#dm45)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT7-06 长时资源、设备与压力收敛

**角色/前置/必要动作：** 资源维护者必须将内存、句柄/FD、线程、连接、GPU、缓存/日志、磁盘峰值、后台唤醒纳入实际资源画像；每项对象有创建/使用/释放责任。可重建缓存的有界增长与泄漏要用负载/稳态说明，不能只看瞬时 RSS。

**并发、超时、未知与恢复：** 反复打开/关闭、取消、睡眠和低磁盘/设备离线时观察释放与恢复；日志/诊断不应耗尽文档空间。热/节能退让不删唯一数据、不降低访问边界；无法确认物理能耗时保留测量局限。

**产物、真实目标入口与判据：** Windows Process Explorer/WPA，macOS Activity Monitor/Instruments Leaks/Energy，Linux /proc/PID/fd、perf 及功耗工具；多轮实际用户任务和空闲观察。判据为合同预算与稳定趋势、取消/退出释放证据，单次操作快不外推长时。

**正例：** 反复开关任务后 FD 回到预期稳态，缓存有界。 **直接失败反例：** 每次取消遗留一个 helper 与凭据连接，失败。 **合法邻例：** 有界缓存保留提高性能可合法不立即归零。

**来源有限命题：** [DM45](../../../sources/desktop-mobile-claims.md#dm45)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT7-07 兼容抽样、回归与证据分层

**角色/前置/必要动作：** 验证者必须用支持矩阵选择最小系统、关键差异平台及风险代表组合，说明未覆盖与选择依据；最终渠道包、实际运行时、数据格式和用户任务固定。静态、合成、VM、真实硬件、AT/设备结果单列。

**并发、超时、未知与恢复：** OS/运行时/原生依赖/驱动/编译器或性能配置变化应映射到受影响任务；只复用仍相同前提的证据。失败修复后正常、直接失败和合法降级一起重验，不靠全局拒绝通过门禁。

**产物、真实目标入口与判据：** 运行项目既有目标平台测试/基准入口并保留原始命令、轨迹和环境清单；交叉检查 P4 AT、P5 安装、P6 混版结果。判据为每个支持承诺有相应层级证据且缺测明确。

**正例：** 已证明 VM 覆盖的文件任务可复用，硬件能耗仍分列未测。 **直接失败反例：** Linux 单测通过写成 Windows UIA/IME 全通过，失败。 **合法邻例：** 单平台合同无需无关三平台组合。

**来源有限命题：** [DM19](../../../sources/desktop-mobile-claims.md#dm19)、[DM23](../../../sources/desktop-mobile-claims.md#dm23)、[DM45](../../../sources/desktop-mobile-claims.md#dm45)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

# L4 原生交互、输入与辅助技术互操作技术规范

**文档ID：** STD-L4-DESKTOP-001　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

使原生、自绘和嵌入内容的输入与可访问语义在焦点、组合输入、显示变更及错误恢复中一致。

**适用对象：** 焦点/键盘/IME，控件语义，宿主与 WebView 桥，多屏 DPI，主题/字体，真实辅助技术任务。 按产品真实存在的能力逐条激活；单平台、离线或无账号不因本专题新增功能。

**非目标：** 不重编 WCAG/ARIA，也不把某平台 API 强制为全部平台实现；无图形界面不激活本专题。

## 二、术语、强度与角色

“必须/应/不得”表示适用条件成立时的规范要求；“建议”允许有依据替代；“例如/示例”为说明，不构成新增平台、功能或统一阈值。引用厂商指南仅在采用其机制时适用，本规范综合定义的要求在来源记录中单独标明。条款 ID 在后续版本保留。

产品维护者固定支持与任务合同；L5 适配者固定 OS/SDK/框架/工具版本与真实 API；组件实现者对输入验证、状态迁移和释放负责；验证者保存准确制品、环境、前后状态与原始观察。OS/渠道记录只对其管辖状态有权威，业务结果由相应本地持久层或受权远端确认，UI 标签和日志字段本身不认证结果。

前置输入为已声明支持画像、最终构建/组件身份、相关账号/窗口/文档或操作身份、数据格式/权限与必要预算。输出为各条产物、状态和完成/失败/未知记录。实例、账号、文档与操作代际分开；状态至少区分未接纳、已接纳/排队、执行、已确认、拒绝/失败、取消请求/确认和结果未知，仅按真实对象采用。

并发和超时预算由采用方预先固定，说明时钟与睡眠语义；超时、断连或请求取消不等于效果未发生。已知未提交/无副作用路径可按合同重试；可能已提交者先回读权威结果，无法核实时保留未知。恢复不得跨账号或把旧异步回复作用于新代际。兼容以声明矩阵及双方能力/数据合同为准，不由 latest 页面或展示版本自动改变。

## 三、稳定条款与验收契约

### DT4-01 语义提供者与用户任务

**角色/前置/必要动作：** 界面维护者必须把关键控件的名称、角色、值、状态、可操作动作和关系映射到目标平台辅助技术接口。自绘和原生/Web 混合层分别核真实可访问树；屏幕像素、DOM 或自动化 locator 不是原生语义权威。装饰元素可排除，但有意义状态/错误不得仅绘制在画布。

**并发、超时、未知与恢复：** 控件销毁、虚拟化复用与异步状态更新时不得留下过期动作或读出他人内容；树暂不可用需保留可完成任务的稳定路径。可访问名字与测试 identifier 不得互相滥用。

**产物、真实目标入口与判据：** Windows Accessibility Insights/Inspect + 选定读屏；macOS Accessibility Inspector + VoiceOver；Linux 所选 AT-SPI 检查器 + Orca。逐项完成打开、编辑、错误、保存及恢复，判据为树与可见/业务状态同步且实际任务可完成。

**正例：** 保存失败由真实状态语义播报并可修正。 **直接失败反例：** 画布按钮只有图标和测试 ID，读屏不可操作，失败。 **合法邻例：** 纯装饰背景不进入读屏顺序合法。

**来源有限命题：** [DM18](../../../sources/desktop-mobile-claims.md#dm18)、[DM43](../../../sources/desktop-mobile-claims.md#dm43)、[DM44](../../../sources/desktop-mobile-claims.md#dm44)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT4-02 焦点所有权、弹层与返回

**角色/前置/必要动作：** 交互控制者必须区分键盘焦点、辅助技术焦点、激活窗口及文本选择。打开模态层时移入合理控件，关闭/取消后返回仍存在的触发点或明确后继；非模态信息不得无端抢焦点。跨原生与嵌入层的 Tab、Esc、快捷键和系统弹框按实际平台合同传递。

**并发、超时、未知与恢复：** 异步回包到达旧窗口、控件已销毁和嵌套弹框关闭时，禁止通过全局 currentFocus 恢复到错误账号/文档。恢复失败不能永久陷住键盘，也不能用关闭辅助技术解决。

**产物、真实目标入口与判据：** 用真实键盘和读屏走 Open/Cancel、错误提示、系统选择器、WebView 返回与 Close/Back；保留焦点事件轨迹与窗口标识。判据为没有循环陷阱、关闭后焦点可达、输入不送入隐藏/错误窗口。

**正例：** 取消文件选择后焦点回编辑入口且草稿保留。 **直接失败反例：** 迟到提示使另一个窗口开始接收密码输入，失败。 **合法邻例：** 合法模态安全确认可限制其生存期内焦点。

**来源有限命题：** [DM18](../../../sources/desktop-mobile-claims.md#dm18)、[DM44](../../../sources/desktop-mobile-claims.md#dm44)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT4-03 组合输入、确认与编辑代次

**角色/前置/必要动作：** 输入适配者必须区分按键、组合中临时串、已确认文本和业务提交。使用平台文本控件/受支持输入接口；自绘控件处理或正确转交组合更新、结果、取消及候选定位。Enter 用于候选确认时不得同时提交业务；最终输入以文本事件而非简单 keydown 拼字。

**并发、超时、未知与恢复：** 焦点切换、窗口关闭、DPI 改变和异步校验不得清空尚未确认文本；组合取消只撤销组合层，不删除既有已确认文档。输入/保存并发仍由 P2 按编辑代次确认，旧验证不得覆盖新输入。

**产物、真实目标入口与判据：** 在实际支持的中文/日文等 IME 中输入、换候选、确认、取消，结合 Tab/Enter 和弹层；Windows 可记录 WM_IME_COMPOSITION/GCS 状态或所选框架等价事件。判据为字符/选择正确、一次确认不产生额外提交、候选窗随光标。

**正例：** 选候选 Enter 只确认文本，第二次明确提交才发请求。 **直接失败反例：** composition 中 Enter 直接付款或发送，失败。 **合法邻例：** 无 IME 的明确命令快捷键按上下文保留。

**来源有限命题：** [DM17](../../../sources/desktop-mobile-claims.md#dm17)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT4-04 键盘、指针与可达操作

**角色/前置/必要动作：** 界面必须为关键动作保留所选平台适当的键盘/非精细指针路径；快捷键作用域、菜单可见性和 OS 保留组合应明确。拖放/双击/右键不是默认唯一途径，输入设备切换不应改变业务对象。全局热键仅在真实功能需要且用户可管理时注册。

**并发、超时、未知与恢复：** 重复键、长按、键盘布局变化和拖放取消不得产生重复不可逆提交；动作忙时反馈真实状态，并保留取消/返回。不得用禁用全部快捷键掩盖与文本输入冲突。

**产物、真实目标入口与判据：** 真实键盘完成核心任务和拒绝/取消路径；切换项目支持布局，检菜单和系统冲突；触发重复按键时核后端/本地效果次数。判据为与菜单动作同一授权/结果合同，取消无幽灵操作。

**正例：** 不用拖放也可从 Open 打开同一合法资源。 **直接失败反例：** Ctrl 快捷键在输入框中偷偷作用于别的文档，失败。 **合法邻例：** 面向专业输入设备的附加手势可保留。

**来源有限命题：** [DM18](../../../sources/desktop-mobile-claims.md#dm18)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT4-05 DPI、坐标空间和显示拓扑

**角色/前置/必要动作：** 显示适配者必须明确逻辑单位、物理像素、窗口/屏幕坐标及 DPI awareness。接收动态缩放或显示变化后重算布局、命中区、光标候选位置和缓存资源；窗口恢复位置须使必要控件可达。不得把不同坐标空间直接相加或仅放大截图。

**并发、超时、未知与恢复：** 拖窗跨 DPI、拔屏、旋转、远程会话重连可交错；重排不得反复触发无界缩放循环、丢编辑或把弹框留在不可达屏。按框架能力使用建议矩形/等效策略，混合 awareness 必须单独验证。

**产物、真实目标入口与判据：** 真实混合 DPI 双屏移动窗口、运行时改缩放并拔主屏；Windows 记录 GetDpiForWindow/WM_DPICHANGED 与实际点击区域，其他平台用其官方窗口工具。判据为文本/命中/候选位置对齐、关键控件可达，不把关闭缩放作为通过。

**正例：** 移到另一 DPI 屏后输入候选和命中区同步。 **直接失败反例：** 按钮图像放大但点击区域仍旧坐标，失败。 **合法邻例：** 产品仅承诺单屏也应处理已有屏幕的支持缩放。

**来源有限命题：** [DM19](../../../sources/desktop-mobile-claims.md#dm19)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT4-06 主题、字体、语言与受限呈现

**角色/前置/必要动作：** 界面必须在已声明的系统主题、对比度、字体/文本缩放、语言方向和减少动态效果设置下保持核心信息与动作。数值阈值由采用标准和项目合同确定；不得只以颜色区分错误/成功。文本溢出要保留可辨识内容和操作，不改变安全确认含义。

**并发、超时、未知与恢复：** 运行中设置变化、缺字体和长本地化串时重排/回退可解释；回退字体或图形模式不得删除文本。无法满足已采纳要求时记录准确失败/例外，不把正常截图替代受限设置。

**产物、真实目标入口与判据：** 系统设置中切换高对比度/大字体/减少动态效果，用长合成文案走确认、错误和恢复；记录所选 OS/语言和真实任务。判据为文本不挡必要操作、状态可感知且焦点次序合理。

**正例：** 大字体时错误可读，确认和取消均可达。 **直接失败反例：** 高对比度下白色错误图标消失但报告通过，失败。 **合法邻例：** 没有动效的产品无需新增动画开关。

**来源有限命题：** [DM43](../../../sources/desktop-mobile-claims.md#dm43)、[DM44](../../../sources/desktop-mobile-claims.md#dm44)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

### DT4-07 联合 AT 验收与回归边界

**角色/前置/必要动作：** 验证者必须把平台/OS build、框架/嵌入运行时、AT 版本、输入法和最终制品关联；原生控件、Web 内容及系统弹层作为一条任务链验收。工具审计、可访问树和真实 AT 结果分别记录；不以通过扫描或标签数量声明整应用符合。

**并发、超时、未知与恢复：** 发现自动绿灯而实际任务失败时保持真实失败，修复后重跑受影响成功与错误恢复。框架、IME、渲染器和系统版本变化按接口风险复验，不要求未经承诺的所有 AT 组合。

**产物、真实目标入口与判据：** Windows 选定 Narrator/NVDA 等目标 AT、macOS VoiceOver 或 Linux Orca 完成核心任务的正常/拒绝/返回；用 Inspector/audit 对照。判据为原始步骤、AT 输出和业务状态一致。

**正例：** 自动树检查和真实读屏均通过同一保存错误恢复任务。 **直接失败反例：** DOM 扫描通过就声称原生权限弹框可访问，失败。 **合法邻例：** 无嵌入内容产品可只验原生链路。

**来源有限命题：** [DM18](../../../sources/desktop-mobile-claims.md#dm18)、[DM43](../../../sources/desktop-mobile-claims.md#dm43)、[DM44](../../../sources/desktop-mobile-claims.md#dm44)；来源仅支持其记录的事实，组合状态机、身份栅栏与验收结果为本规范组织合成要求。

## 四、采用与证据边界

目标验收入口中的产品名/包标识、文件和设备由 L6 替换为其准确对象，不把示例工具命令的退出 0 单独当作核心任务完成。仅在获准隔离目标使用故障/篡改样本；正常输入、直接失败和合法邻例必须成对观察。静态、合成、目标 OS、真实硬件/辅助技术/自然调度各层分别留证。

离线合成示例若另有运行记录，仅证明其显式有限假设，不替代这些入口。

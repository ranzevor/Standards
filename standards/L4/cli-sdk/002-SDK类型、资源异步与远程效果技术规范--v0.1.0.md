# SDK类型、资源异步与远程效果技术规范

**文档ID：** STD-L4-CLI-SDK-002　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 1 目标、适用与非目标

让库的公开数据、资源所有权和远端结果在宿主中保真，尤其保留取消/超时后的未知状态。

**适用：** 可导入库、同步/异步SDK、分页/流式远程客户端。

**非目标：** 不强迫同步库增加异步层、使用特定认证/异常类型或实现服务器事务。

本文的“必须/不得”为采用相应条款时的必要条件，“应”为需说明偏离理由的建议，“可”为允许选项。外部标准的 MUST/SHOULD 依其原有强度与适用 profile 执行，项目参数不得降低其强制要求。能力不存在可据事实不适用；已承诺但未验的能力仍适用。

## 2 术语、主体与权威状态

公开API包括文档化行为；拥有资源与借用资源不同；逻辑操作键跨尝试不变，attempt_id标单次尝试。查询缺失、已知未应用和操作级最终未应用不同。

**主体与所有权：** SDK向调用者保留状态与原因链；宿主拥有事件循环/全局设置；服务端拥有认证/对象授权/操作事实；凭据提供器只按选定作用域提供身份。

**前置输入：** 公开类型、单位/精度/枚举策略、线程/事件循环模型、端点/身份、期限/重试预算、分页与目标幂等合同。

**输出与权威观察：** 宿主可接管的值/异常、资源关闭事实、身份隔离请求、已交付页/流、操作及未知尝试集合和权威查询回执。

**状态与终点：** 客户端构造/就绪/关闭与请求待发送/在途/已完成/明确失败/未知分开；取消本地等待不能令目标已提交变未应用。

条款 ID 在本文内稳定；全局身份为文档路径、版本与条款 ID 的组合。各条的前置输入、主体和状态继承本节，再叠加本条触发条件。诊断缺失不证明效果未发生；并发、超时、取消请求与真实业务终态分别记录。

## 3 机制、不变量及逐条验收

### SDK-API-01 类型、编码与错误保真

- **触发/前置：** 公开API接收或返回数据/错误。
- **必要机制：** 必须声明缺失/null、整数/定点精度、单位、时区、未知枚举及可变对象所有权；序列化不静默截断身份。错误用可判别类别与原因链交宿主，库不得擅自终止进程或把未知业务状态映射成功。
- **不变量：** 必要语义往返不变；错误信息不泄密。
- **并发、超时、未知与恢复：** 坏编码、超范围或未知必要字段按合同拒绝/保留，部分批次逐项报告。开放schema不等于忽略权限字段。
- **产物与观察点：** 独立边界值语料、往返值、宿主错误处理和秘密扫描。
- **正例：** 大于2^53的标识用无损合同保持；未知枚举原值保留。
- **直接失败：** 将unknown枚举默认成paid或把64位ID转成不精确double。
- **合法邻例：** 动态语言通过运行契约实现，无需强制静态类型。
- **可观察验收：** 独立服务夹具返回大整数、空值/缺失、时区和未知枚举；核调用者值及回传不变。
- **来源与限制：** RP13。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### SDK-API-02 初始化、所有权与宿主隔离

- **触发/前置：** import、构造、关闭或失败。
- **必要机制：** 必须标出取得凭据、建连、后台线程、遥测等副作用时点，默认不改宿主日志/代理/事件循环。自建资源有可重复调用关闭路径；借用资源仅按约定释放。失败构造也清理已获取部分。
- **不变量：** 未调用能力不造成未声明业务动作；关闭不夺取宿主资源。
- **并发、超时、未知与恢复：** 关闭与请求并发定义准入屏障/排空；重复close有明确语义。连接创建超时不遗留无主线程，需关闭的迟到资源仍归原所有者。
- **产物与观察点：** 全局状态差异、线程/句柄、外发与关闭回执。
- **正例：** 构造失败后自建线程收敛，借用连接由宿主继续使用。
- **直接失败：** import时联网计费或改全局日志，close关闭宿主事件循环。
- **合法邻例：** 纯计算库没有Client对象，也不必新增关闭API。
- **可观察验收：** 空网/受控凭据下反复导入、构造失败、关闭和并发close；核宿主活性及资源基线。
- **来源与限制：** RP11。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### SDK-API-03 并发、异步与取消

- **触发/前置：** 入口可并发或异步。
- **必要机制：** 必须声明线程安全/重入、回调上下文、阻塞点和共享限制；请求身份/头部不可因共享可变状态串租户。异步取消经清理后保真传播，不私自接管宿主事件循环；提供有界流/背压及消费者停止后的关闭契约。
- **不变量：** 承诺模型下无身份串扰、死锁和无限缓存；不把取消请求等同终态。
- **并发、超时、未知与恢复：** Task.cancel可能被协程延迟/处理，必须等待可观察结束或报告未停止；外部副作用按独立操作账核对，不能由CancelledError推断未发生。
- **产物与观察点：** 双租户交错轨迹、资源峰值、取消与回调时序。
- **正例：** 已有事件循环中await客户端，取消后自有流关闭且宿主继续。
- **直接失败：** 同步包装阻塞当前事件循环，或全局请求头被另一租户覆盖。
- **合法邻例：** 明确非线程安全且每线程独立客户端合法，不强制全部库并发安全。
- **可观察验收：** 控制交错不同身份、慢消费者与取消点；断言请求身份、峰值和关闭后活动，超时必须报告卡住而非PASS。
- **来源与限制：** RP11。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### SDK-API-04 鉴权、端点与凭据生命周期

- **触发/前置：** 访问受保护远端。
- **必要机制：** 必须绑定issuer/受众或提供方身份合同、租户、目标和动作；刷新按身份作用域隔离并协调并发刷新，失败不得回退高权默认。TLS/代理/重定向不扩大令牌目标，诊断屏蔽秘密；对象授权仍由目标执行边界确认。
- **不变量：** 认证成功不是任意对象许可；端点错配不靠关闭证书验证修复。
- **并发、超时、未知与恢复：** 撤销后旧缓存/排队请求需重验，迟到刷新回包不得恢复旧账号；重新认证是显式状态而非无界重试。
- **产物与观察点：** 实际目标/身份、刷新代际、授权拒绝与脱敏日志。
- **正例：** 两个租户并发各用正确令牌；错目标重定向不带秘密。
- **直接失败：** 刷新失败改用全局管理员，或换账号后旧刷新覆盖新令牌。
- **合法邻例：** 公开离线功能无需凭据；本地隔离无TLS协议不成为生产默认。
- **可观察验收：** 隔离服务核错名证书、跨目标跳转、刷新竞争/撤权/账号切换和真实对象拒绝。
- **来源与限制：** RP32；RP33。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### SDK-API-05 根期限、未知尝试与有限去重

- **触发/前置：** 远端动作有重试、超时或可能重复效果。
- **必要机制：** 必须区分连接/读写和根总期限，传递剩余预算并协调上层/SDK尝试数。相同意图保留目标作用域操作键及参数指纹；未应用新尝试不能消解旧未知。只有操作级权威终局覆盖全部相关尝试/在途窗口，或有效目标幂等合同，才允许安全续接。
- **不变量：** 查无记录不等于未发生；本地派发在去重窗内不等于目标迟到接受仍安全。
- **并发、超时、未知与恢复：** 有限窗须目标强制接受截止、已证处理覆盖或等价机制；过窗且无核对能力保持unknown。取消不回滚提交；补偿另是授权操作。
- **产物与观察点：** 根预算、各attempt、目标接受时间/去重期限、操作级查询范围和最终对象数。
- **正例：** 丢响应后同键同参在目标覆盖窗内受控重试，结果回原对象。
- **直接失败：** 以新键重试查无记录旧请求；旧请求迟到成第二对象。
- **合法邻例：** 纯函数/真实幂等GET可按合同重试，不要求副作用操作账。
- **可观察验收：** 延迟旧请求跨去重窗、同键换参、最终一致查询缺失、多层重试；核最终副作用和未知保留，而非只断言调用次数。
- **来源与限制：** RP02；RP31。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### SDK-API-06 分页、迭代与缓存新鲜度

- **触发/前置：** SDK暴露页/懒流或离线缓存。
- **必要机制：** 必须绑定游标的租户、查询、排序和服务快照语义，空页带next仍继续；只有合同允许参数可改，page_size例外不扩大其他范围。游标失效不静默重头伪称同一完整遍历；缓存绑定输入/规则/身份及新鲜度，离线不声称远端已同步。
- **不变量：** 已交付部分与完整集不同；游标不是访问授权。
- **并发、超时、未知与恢复：** 循环token有诊断终点；消费者停止后不持续预取，显式重启为新遍历并保留旧部分身份。损坏缓存可重建但不扩权。
- **产物与观察点：** 请求页序、token上下文、已交付/未完成、预取峰值和缓存时间。
- **正例：** 空页加next继续，合法更改page_size按服务合同接受。
- **直接失败：** 空页就终止，或换租户重用token而拿到旧数据。
- **合法邻例：** 变化集允许可解释重复时SDK不承诺不存在的快照。
- **可观察验收：** 提供空页、循环/过期token、换租户过滤、合法大小变化和慢消费，核结果身份/请求数/关闭后活动。
- **来源与限制：** RP06。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

## 4 兼容、迁移与退役

公开类型、默认值、错误、协议/行为、ABI分别评估兼容。未知枚举保留或拒绝按约定；旧消费者不自动理解新值。服务协议变化不由SDK生成类型证明兼容。

## 5 跨域消费接口

消费基线M12–M18、M27、M30–M35；后端/数据库提供查询一致性、事务及去重，安全提供身份/撤权，网络提供分层连接状态；SDK必须暴露这些保证的实际边界而非默认加强。

接口只定位技术职责，不自动作出规范采用决定。通用状态、测试和制品义务消费 [L3 通用工程 v0.1.0](../../L3/001-通用工程规范--v0.1.0.md)；提供方版本与摘要、应用条款、实现入口和验收责任在项目契约中绑定。提供方保证须由相应实现证据支持，消费方按该保证的实际范围验收。

## 6 真实目标验收合同

每种支持运行时提供发行包消费工程：Python画像 `python -m unittest discover -s consumer_tests -v`，其中以实际SDK调用隔离服务，在请求提交前后设置故障闸并观测目标对象；异步测试在已有宿主事件循环运行，双租户并发和关闭借用连接。服务端记录目标接受时间及幂等截止，客户端记录根deadline/attempt，不能只Mock返回字符串。

**判据：** 数据往返无精度/身份损失；import/构造不出现未声明外发或全局更改；取消释放自有资源而宿主存活；所有重试受根预算且不能重复未知副作用，分页中断与完整结果区别明确。

每次执行保存：正文/条款版本与摘要、目标制品/实现和工具版本、OS/设备/运行时/配置、输入及故障时间线、预期和实际、stdout/stderr/退出码或等价运行证据、权威状态回读、未覆盖范围。`not-run`、模型通过和真实目标通过是不同结果；实际无环境时保留命令和判据而不填写虚构回执。

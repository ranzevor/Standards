# 背压、拥塞与断线恢复技术规范

**文档ID：** STD-L4-NETWORK-004　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 1 目标、适用与非目标

在慢消费者、拥塞、断线和升级下保持资源有界、控制信令前进及应用状态可核对。

**适用：** 共享连接/队列、流式HTTP、WebSocket/SSE、重连/迁移/订阅恢复。

**非目标：** 不规定统一窗口/重试间隔，不将重连等同续传，不把抓包缺失当业务未发生。

本文的“必须/不得”为采用相应条款时的必要条件，“应”为需说明偏离理由的建议，“可”为允许选项。外部标准的 MUST/SHOULD 依其原有强度与适用 profile 执行，项目参数不得降低其强制要求。能力不存在可据事实不适用；已承诺但未验的能力仍适用。

## 2 术语、主体与权威状态

流控约束接收方可接收量，拥塞控制约束路径负载，背压约束应用生产和队列；逐跳预算不自动组成端到端预算。连接、身份、订阅、游标、快照和持久处理确认各自恢复。

**主体与所有权：** 各跳维护者报告队列/窗口；协议实现持续处理必需控制帧；应用生产者响应背压；恢复协调者核当前身份与历史窗口；业务目标提供最终状态。

**前置输入：** 路径/代理清单、协议约束、逐跳和整体数量/字节/等待预算、可丢对象、根期限、恢复游标与历史保留、支持旧客户端。

**输出与权威观察：** 队列/窗口与公平性轨迹、重试预算、游标缺口/快照、会话世代及应用最终事实。

**状态与终点：** 正常/高水位/拒绝或降级/恢复；链路恢复与状态恢复分别完成；游标为有效/过期/上下文错配，未知结果不会因队列空被消除。

条款 ID 在本文内稳定；全局身份为文档路径、版本与条款 ID 的组合。各条的前置输入、主体和状态继承本节，再叠加本条触发条件。诊断缺失不证明效果未发生；并发、超时、取消请求与真实业务终态分别记录。

## 3 机制、不变量及逐条验收

### NET-FLOW-01 分层背压与控制前进

- **触发/前置：** 接收方变慢或队列接近预算。
- **必要机制：** 必须分别设置连接/租户/全局应用队列和SDK/代理缓冲的数量、字节与等待预算；生产者能暂停/拒绝/合并。HTTP/2只有DATA消耗该版流控窗口，读取与必要控制帧处理仍持续，不能以全停socket实现全部背压。
- **不变量：** 队列有界且WINDOW_UPDATE等不被应用慢消费饿死；合法最大对象仍可通过。
- **并发、超时、未知与恢复：** 恢复按高低水位/配额唤醒，避免忙等抖动；超限断流保留已处理/未处理，不假装全量成功。
- **产物与观察点：** 各跳队列峰值/等待、DATA/控制轨迹、拒绝与丢弃账。
- **正例：** 慢流暂停DATA生产但连接控制处理仍前进。
- **直接失败：** 停止所有读取导致窗口更新不处理，自致死锁和代理积压。
- **合法邻例：** 可合并坐标只留最新样本合法；不可丢命令不能同样丢弃。
- **可观察验收：** 真实HTTP/2慢消费者与其他租户并发，核控制持续、预算、恢复和公平性而不只测源站。
- **来源与限制：** RP39。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### NET-FLOW-02 拥塞、MTU与实时退化

- **触发/前置：** 路径容量下降、丢包/MTU变化。
- **必要机制：** 必须使用所选传输适当拥塞机制并在并发连接/UDP聚合层核负载；流控不是拥塞控制。路径大包采用实现支持探测/尺寸限制，QUIC DATAGRAM受协商与MTU，无任意大消息保证。实时样本按明确迟到/可丢策略降级。
- **不变量：** 不能为低延迟绕过拥塞或无限重传；丢失诊断不是业务失败率。
- **并发、超时、未知与恢复：** 带宽恢复按协议控制，不重置根预算；合法不可靠样本可丢但保持关键确认路径。
- **产物与观察点：** RTT/PTO/拥塞窗口、尺寸/丢包、各类型丢弃与尾延迟。
- **正例：** 路径变小后调整样本或走声明可靠分块。
- **直接失败：** 局域网大报文换蜂窝后无限原尺寸重发。
- **合法邻例：** 低数据量UDP按适用指南有区别机制，不强制所有流套同算法。
- **可观察验收：** 受控带宽/抖动/丢包/MTU组合测真实协议行为，解释PTO与业务状态区别并核合法边界。
- **来源与限制：** RP34；RP37；RP40。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### NET-FLOW-03 期限、重试与存活分层

- **触发/前置：** RPC等待、群体断线或心跳。
- **必要机制：** 必须区分连接/握手/空闲/操作/整体期限，传播剩余预算；重连退避/抖动与Retry-After类信号协调，认证永久拒绝不持续风暴。PING、NAT保持、服务就绪、授权和应用同步分别观察，浏览器不能假造原生Ping API。
- **不变量：** 多层重试不各得完整预算；保活成功不掩盖业务失效。
- **并发、超时、未知与恢复：** 根期限到达返回真实已提交/未知；重新认证等外部条件不被自动扩权替代。后台节流后重核状态。
- **产物与观察点：** 根预算与各层时间线、尝试分布、保活和业务状态。
- **正例：** PING可达但订阅失败时分别报告并按合同恢复。
- **直接失败：** 全部客户端固定短间隔重连，认证拒绝仍循环。
- **合法邻例：** 普通短HTTP请求无需长连接心跳。
- **可观察验收：** 群体故障与身份拒绝、限流、后台节流测试；核尝试总数/分散、根耗时和业务回读。
- **来源与限制：** RP41；RP43。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### NET-FLOW-04 恢复窗口、游标与世代

- **触发/前置：** WS/SSE或其他应用承诺续传。
- **必要机制：** 必须分开连接建立、当前身份、订阅授权、历史游标、快照与持久消费确认。SSE Last-Event-ID只携带ID而非持久日志保证；空id重置按规范，未空行结束尾事件不派发。游标作用域含租户/订阅/版本及保留窗口。
- **不变量：** 重连成功不等于无丢失；旧世代/旧权限事件不覆盖新状态。
- **并发、超时、未知与恢复：** 窗口内去重重放，窗口外明确缺口、快照重建或不能恢复；双连接重叠按事件身份处理。最终一致快照须固定水位衔接，不丢快照与增量间隙。
- **产物与观察点：** 游标起点/水位、缺口、当前授权、旧新会话消息和最终快照。
- **正例：** 过期游标触发已声明快照并告知恢复边界。
- **直接失败：** 历史已清仍从新事件继续而报告无丢失。
- **合法邻例：** 无需无损历史承诺的实时仪表可显示缺口并继续新鲜样本。
- **可观察验收：** 真实EventSource和服务端在窗口内外、空id、截断尾部及双连接/撤权下测试，核最终状态。
- **来源与限制：** RP42。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

### NET-FLOW-05 迁移、排空与诊断

- **触发/前置：** 网络换址、服务升级或排障。
- **必要机制：** 必须区分NAT重绑定/QUIC路径验证、连接迁移、重握手及应用恢复；服务丢状态不能靠换IP恢复会话。升级处理旧新端点/代理、在途和排空，连接关闭不等于业务取消。诊断关联连接/流/会话/操作但不记录秘密原媒体。
- **不变量：** 传输路径可达不新增权限；未知业务不因断链改成已回滚。
- **并发、超时、未知与恢复：** 重启失态走新连接和应用核对；错误码只表达其层，WS1006为本地异常不可发送且不证明对端业务拒绝。证据不全标未知根因。
- **产物与观察点：** 路径/协商/世代、排空在途、脱敏指标/抓包及权威操作结果。
- **正例：** 保留QUIC状态的合法迁移和服务失态重连分开验证。
- **直接失败：** 服务重启后宣称QUIC迁移已经恢复订阅，或把1006记成对端付款拒绝。
- **合法邻例：** 无状态轮询无需持久订阅恢复，但仍核公开承诺。
- **可观察验收：** 旧新客户端和代理组合、路径变化/重启/排空测试，核恢复与未决效果；抓包权限/最小化单列。
- **来源与限制：** RP38；RP41；RP42。来源只支持[逐命题表](../../../sources/runtime-protocol/SOURCE-CLAIMS.md)所列命题；其余必要机制是为保持本条不变量而提出的组织综合设计，不声称由单一外部标准规定。

## 4 兼容、迁移与退役

窗口/压缩/代理/客户端升级固定旧新组合；保留窗口缩短须处理仍受支持游标。支持的旧客户端排空/迁移期间保留业务查询，不能断连接就宣告回滚。

## 5 跨域消费接口

消费基线M08–M16、M27–M33；后端提供消息/游标和业务终点，云提供入口与容量/拓扑，安全提供动态撤权；网络给可观察的背压/拥塞/连接与恢复证据。

接口只定位技术职责，不自动作出规范采用决定。通用状态、测试和制品义务消费 [L3 通用工程 v0.1.0](../../L3/001-通用工程规范--v0.1.0.md)；提供方版本与摘要、应用条款、实现入口和验收责任在项目契约中绑定。提供方保证须由相应实现证据支持，消费方按该保证的实际范围验收。

## 6 真实目标验收合同

隔离目标运行真实客户端/代理/服务，`curl -N --no-buffer "$SSE_URL"` 从最终入口观察事件时间，浏览器EventSource另测；`tshark -r trace.pcapng` 分析获准的脱敏抓包。拥塞/丢包/延迟由已批准测试代理或隔离网络故障工具注入，不改变生产；具体工具版本、路由、参数和队列采样脚本绑定项目合同。HTTP/2使用真实端点输出DATA/WINDOW_UPDATE和各层队列。

**判据：** 慢消费者不饿死必要控制帧或其他租户；各跳和总缓冲满足预算，恢复后能继续；重连风暴受根预算；窗口外游标触发明确缺口/快照并重新授权；响应丢失正确保留未知。

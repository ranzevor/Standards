## 一、范围、依赖与权责

本文属于第06模型训练与AI科研领域既有路线的独立专项，深化学习材料造成的研究有效性、机密泄漏和加载执行风险。适用于参数及非参数学习模型、数据/标签贡献、教师生成材料、检查点、适配器、Tokenizer/特征处理器、架构配置、研究脚本及其组合；纯理论研究无此材料时可登记相关条款不适用，不强迫训练或购买安全平台。

继承 L3《通用工程规范》§九、§十三的身份、供应链、隔离与真实证据义务；数据库《数据安全、访问控制、保留与导出技术规范》的来源权利、敏感分类及处置权；05《AI应用与Agent系统领域通用基线》§03/06 和《AI应用评测、回归与对抗验收技术规范》§09/21—29的应用出口、裁判及残余风险边界。这里不重写身份体系、通用漏洞管理或生产工具权限。应用部署仍须05独立验收；本研究检查不能授权应用调用工具。

“必须/不得”是适用范围内的组织义务，“应”的偏离须有技术理由及有权主体接受，“可”不是操作授权。规范采用不授予抓取或购买数据、真实目标攻击、恶意材料执行、付费计算、外发或公开发布的操作权限；实际法律、合同、伦理条件由L6有权主体核定，本文不宣称法律认证。

## 二、证据对象与一手来源

**材料清单**是带内容指纹及依赖关系的实际消费组合，不是模型商品名。**可疑投毒/后门**是待核异常，不等于已查明恶意意图；**污染**还包括无恶意的切分泄漏、错标签或版本错配。**隐私经验评估**测量具体访问能力及协议下的可观察泄漏；**形式隐私保证**需要明确数学定义、假设、证明及实现对应，不能由测试阴性替代。**安全准入**只覆盖准确版本/用途/环境；**研究执行许可**和**发布许可**分别核实。

### §01 威胁合同与权限闭包
**机制：** 开始研究前固定保护资产、危害、攻击者可控面（样本/标签/权重/加载代码）、知识、查询/修改能力、预算、接收方和允许环境。研究者能下载不代表能执行，能读取不代表能向外部评分器发送。对未知权利单列缺口，不以公开可见或已有论文代替授权。

**验收：** 比对操作计划与真实许可范围；只获文本筛查时加载实验标未授权且不执行。已获同范围许可不重复请求；新增对象、共享或费用须先取得依据。

**合同补充：** 安全负责人接收资产、攻击者能力、预算、环境及许可。测试计划与具体读取/执行/外发权闭包对应。

**失效与恢复：** 缺权隔离依赖步骤；公开可见不代执行许可。

**核验三例：** 正例：文本筛查许可仅做文本准入。直接失败：能下载就执行模型代码。合法邻例：已有同范围许可有效则可复用依据，不造重复审批。

**追溯与目标：** `MR-AML-P1`；目标入口 `MR-RECORDS`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为未建模；由原机制与专用验收合同审阅，不得将记录字段或单次算例升级为未测实现的证明。

### §02 联合材料清单与可信来源
**机制：** 每次准入绑定数据快照、基座、分片、适配器、Tokenizer/特征变换、配置、加载实现及依赖的版本/指纹、来源与实际路径；可重建对象记重建方法。不以单一权重哈希替代组合，哈希一致只说明字节一致，来源身份/签名验证与行为安全分别判断。

**验收：** 修改任一实际消费组件后旧准入失效或按影响重核；清单与消费回执一致，未固定别名标不确定。非参数模型按索引/规则等实际学习状态登记。

**合同补充：** 准入维护者接收数据/基座/分片/适配/Tokenizer/加载器组合。实际消费清单与联合身份一致，字节/来源/行为分开核。

**失效与恢复：** 任组件变更旧准入按影响失效；alias不固定则标未知。

**核验三例：** 正例：权重T1配TokenizerT1有完整组合。直接失败：同权重hash但Tokenizer已替换却继承安全结论。合法邻例：非参数模型可用索引/规则身份，不虚构权重文件。

**追溯与目标：** `MR-PEFT-CKPT-P1`；目标入口 `MR-RECORDS`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为`bundle`的部分谓词，不得将记录字段或单次算例升级为未测实现的证明。

### §03 准入状态与证据保存
**机制：** 待核、限定检查可用、限定研究可用、限定发布可用、拒绝/撤回分别记录；状态不自动升级。可疑输入存放在获准受限位置，保留最小指纹、来源时点和调查记录；处理内容的读取器本身亦是解析面。不得为方便审查复制私密原文到仓库。

**验收：** 合成待核条目不能凭扫描“无发现”流入训练或发布；到期/处置按已有权利执行，不强制永久保留恶意或敏感原件。

**合同补充：** 准入责任人接收待核、限定检查、研究、发布和撤回证据。状态只在对应对象/用途/环境有效，扫描阴性不自动晋级。

**失效与恢复：** 到期按真实依据处置，证据最小化；不无限持有可疑原件。

**核验三例：** 正例：限定静态检查完成仍待研究准入。直接失败：扫描无发现就由待核升级公开。合法邻例：有限检查许可可以只开放非执行性解析。

**追溯与目标：** 组织综合要求（本条因果与边界由机制、验收及下列三例论证，无逐条外部强制出处）；目标入口 `MR-RECORDS`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为`admission`的部分谓词，不得将记录字段或单次算例升级为未测实现的证明。

### §04 投毒入口与接触证据
**机制：** 记录贡献渠道、允许影响的样本/标签范围、变换链与实际训练消费身份，区分数据投毒、检查点篡改、评测污染和运行故障。来源信誉、相似度/异常分数是线索而非恶意归因；低频合法子群不得因稀有即被删。

**验收：** 可疑样本未被训练消费时只能支持入口筛查结论，不能声称训练抵御投毒；已消费则追踪受影响run及派生模型，不凭单个异常标签认定攻击者。

**合同补充：** 调查者接收贡献渠道、变换链与实际消费接触证据。入口筛查、训练影响、污染与恶意意图区分。

**失效与恢复：** 未消费只报告入口风险；已消费追run及派生模型。

**核验三例：** 正例：异常标签作为线索再独立核验。直接失败：稀有合法子群被直接定恶意投毒。合法邻例：非恶意错标签可归质量缺陷而非攻击归因。

**追溯与目标：** `MR-AML-P1`；目标入口 `MR-RECORDS`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为未建模；由原机制与专用验收合同审阅，不得将记录字段或单次算例升级为未测实现的证明。

### §05 后门与普通退化的判别设计
**机制：** 在明确许可下，检测计划分开测目标条件行为、正常任务效用和合法相邻条件；确认预定条件到达目标处理路径，预先限定结果判据与对照。异常关联不直接证明因果或恶意；对照若同时变化模型/数据/预算须承认混杂。本文不提供投毒载荷或真实目标攻击步骤。

**验收：** 条件未触达、模型本来不会该任务、裁判无效分别标未触达/能力不足/证据不足；不能都记防御成功。正常准确率相近不能单独排除后门，异常复核须绑定材料版本。

**合同补充：** 受控评测者接收目标条件、正常效用、邻近控制和到达证据。未触达/能力不足/裁判不足与防御成功各有观察点。

**失效与恢复：** 对照混杂或条件未达标不足；修协议后重验。

**核验三例：** 正例：条件触达且正常/邻近效用都有可核结果。直接失败：条件没到模型仍记防御成功。合法邻例：普通低能力退化可按能力问题报告，不硬判后门。

**追溯与目标：** 组织综合要求（本条因果与边界由机制、验收及下列三例论证，无逐条外部强制出处）；目标入口 `MR-RECORDS`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为未建模；由原机制与专用验收合同审阅，不得将记录字段或单次算例升级为未测实现的证明。

### §06 处置与防御有效性
**机制：** 隔离、重标、筛除、重训、修补或检测规则变更均保留原失败和变更原因，验证剩余数据分布、关键子群效用与已知失效回归。清除文件不等于已消除模型影响；防御在已知集合有效不等于抵御未知或适应性攻击。

**验收：** 筛除所有目标子群换取零异常不能算可用防御；将结果限定于实际协议，未授权重训仅提出方案而不执行。

**合同补充：** 修复者接收隔离/筛除/重标方案和原失败版本。剩余分布、关键子群效用及已知失效回归一起核。

**失效与恢复：** 清文件不当消除模型影响；适应性未知保持未覆盖。

**核验三例：** 正例：已知问题修复且关键子群仍有有效覆盖。直接失败：删光目标子群换零异常称可用防御。合法邻例：仅静态修复可给静态结论，不强制无依据昂贵重训。

**追溯与目标：** 组织综合要求（本条因果与边界由机制、验收及下列三例论证，无逐条外部强制出处）；目标入口 `MR-RECORDS`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为未建模；由原机制与专用验收合同审阅，不得将记录字段或单次算例升级为未测实现的证明。

### §07 隐私暴露面与访问模式
**机制：** 分别登记训练原文、成员身份、属性、模型输出、嵌入、梯度、检查点、日志/索引可见性；区分仅API、分数可见及权重可见的受测能力。泄漏评估需满足数据目的和接收方权限，训练许可不自动包含攻击评估或公开样本。

**验收：** API受限查询结果不得外推权重公开后风险；去掉姓名但可链接的长文本/稀有组合仍进入敏感分析，不据“脱敏”名称放行。

**合同补充：** 隐私审核者接收原文/成员/属性/输出/梯度等暴露与访问能力。API、分数、权重可见场景分别绑定协议和接收方。

**失效与恢复：** 新发布面需相应评估，不能由旧弱访问阴性外推。

### §08 记忆泄漏的判据与归因
**机制：** 明确逐字/近似/语义匹配规则、背景可获信息、成员依据、误报复核及敏感性；训练记忆、检索回显、提示中已给内容和公共常识区分。不为验证泄漏而查询无授权真实个人目标。合成标记须无真实秘密且其插入本身有训练变更授权。

**验收：** 受控输出命中仅能说明该条件下匹配，结合来源才能声称训练样本提取；提示已含答案不能算训练记忆证据。合成标记阴性不能证明真实数据无泄漏。

**合同补充：** 泄漏分析者接收匹配规则、背景信息、成员依据与来源。训练记忆、检索回显、提示已给信息与公共知识分别归因。

**失效与恢复：** 阳性先核来源和误报；阴性不能证明所有真实数据无泄漏。

**核验三例：** 正例：合成标记的受控命中仅报告该条件匹配。直接失败：提示含答案的复述当训练提取。合法邻例：合法检索回显可归检索来源而非训练记忆。

### §09 隐私评估设计与分母

**合同补充：** 隐私评测者接收总体、成员/非成员抽样与查询选择机会。分母、独立单位、假阳性与无效/超时状态完整。

**失效与恢复：** 年代等混杂使归因不足；弱检测力不判安全。

**核验三例：** 正例：同抽样条件对照并列全部尝试。直接失败：成员新年代非成员旧年代却归因成员泄漏。合法邻例：自适应发现可报告发现事实，但不等自然暴露概率。

### §10 经验阴性与隐私保证
**机制：** 报告“在某版本、访问能力、预算和检测方法下未发现”，并列未覆盖风险；隐私测试未发现不等于隐私证明。测试阳性需核查是否满足声称保证的假设及统计证据，不把任意复述直接当DP数学反例；真泄漏仍按风险处置。

**验收：** 零次命中记录保留检测能力、分母和限制；不能改写成“无记忆/完全匿名/已证明DP”。形式保证与工程审计分别留证。

**合同补充：** 风险负责人接收阴性结果、访问预算及形式声明。未发现限定于准确方法/版本，DP证明与经验审计各列。

**失效与恢复：** 泄漏阳性核是否违反所声称假设，不能任意复述当DP反例。

**核验三例：** 正例：零命中报告分母检测力和未覆盖。直接失败：零命中改写完全匿名或已证DP。合法邻例：无形式保证的诚实经验报告不被强制标DP。

### §11 DP保证合同
**机制：** 声称差分隐私时必须记录机制/证明引用、隐私单位与邻接关系（增删或替换，事件/记录/用户等）、参数及变体转换、信任模型、保护对象、声明保护所针对的观察主体及其可见转录。可信处理边界须明确；“发布/观察”不是仅指公开或论文发表，内部分析员、仪表盘、裁判在该可信边界之外时，其所见候选、失败run、选择/验证信息也属于对应观察范围。只保护单条事件不得命名为用户全部历史保护；δ不解释成某个用户确切泄漏概率。参数由L6风险决策，无统一推荐值。

**验收：** 同一用户多记录的贡献边界与所宣称单位一致；两个相同ε但邻接不同的方案不得直接称等强保护。未声称DP的合法研究可使用经验风险报告，不被强迫引入DP。

**合同补充：** DP声明者接收邻接、单位、参数变体、可信边界和保护观察者。保证针对该观察者全部可见转录，单位语义不可偷换。

**失效与恢复：** 内外部观察越界或参数/单位未定则保证不足；不把δ写成个人确切泄漏率。

**核验三例：** 正例：事件级保证准确称事件级并列边界。直接失败：单事件DP包装成用户全历史DP。合法邻例：无DP声明可用经验风险报告；可信curator内部不机械当公开。

**追溯与目标：** `MR-DP-P1`、`MR-NIST-DPTRUST-P1`；目标入口 `MR-DP`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为`dp`的部分谓词，不得将记录字段或单次算例升级为未测实现的证明。

### §12 DP实现与组合账本
**机制：** 对声明机制核对敏感度/裁剪单位、抽样假设、噪声实现、数值与随机源、会计器版本及实际步骤；记录所有影响相应观察主体可见转录的训练、选择、验证、重试与恢复，按实际可见输出及依赖决定组合；只有证明中间状态未被该观察主体获得且未通过选择等影响可见结果，或已被完整机制证明覆盖时，才能论证其不单独作为一次发布计账，不能仅因未公开而排除。不得只报获胜run预算，也不机械把可信边界内状态都算新发布。后处理若重新接触私密数据不得默认继承原保证；日志等非DP出口独立处理。与06基线§13/14的种子及恢复记录衔接时，DP噪声种子/随机状态须按信任边界受限保存，不得为复现向所声明保护的观察主体披露可重建噪声的信息；避免由公开配置等推断噪声。跨新机制复用或相关随机性须有对应证明，不能默认沿用普通实验固定seed策略；受信边界内合法恢复及纯合成调试不一律禁止，但须核对随机源、恢复与会计假设。

**验收：** 恢复后隐私账本不能重置；重复发布相同既有DP输出与重新访问原数据产生新随机发布区别检查。会计假设不符实际抽样时保证证据不足；数学证明不能掩盖实现遗漏。若分析员已见失败候选输出，即使最终仅论文发布获胜者，也必须分析其完整可见转录；加噪结果与可重建噪声的种子同时交付不能继承隐藏噪声假设下的保证。受限恢复不外传状态且满足原机制证明与连续账本时，不因保存状态本身误拒绝。

**合同补充：** 实现审阅者接收机制证明、裁剪抽样、会计器及实际可见发布/恢复账。机制/组合假设与所有可见选择验证输出相符，随机状态不外泄。

**失效与恢复：** 恢复不能清零账；重接触私密数据不叫免费后处理；公开可重建噪声信息使原假设失效。

**核验三例：** 正例：两次机制发布累计预算且受限恢复账连续。直接失败：仅论文发赢家就忽略裁判已见失败候选。合法邻例：重复传同一既有DP输出且无新私密访问不机械算新机制；可信内部已证明覆盖状态可整体计账。

**追溯与目标：** `MR-DP-P1`、`MR-DP-RNG-P1`；目标入口 `MR-DP`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为`dp`的部分谓词，不得将记录字段或单次算例升级为未测实现的证明。

### §13 危险加载器及不可执行格式边界
**机制：** 在内容执行之前确定解析器、序列化格式、远程代码/插件、自定义算子及加载选项；拒绝未经批准的自动反序列化代码执行/远程导入。安全模式失败不得自动降级危险模式或批量信任类；需要兼容例外须审核具体代码、来源与隔离并由有权者批准。恶意材料筛查不等于允许执行。

**合同补充：** 加载负责人接收格式、解析器、远程代码/算子与选项。执行前确定受限加载路线，失败不能自动降级不安全模式。

**失效与恢复：** 需自定义代码则核具体来源/权限/隔离，未准不执行。

**核验三例：** 正例：相同基座词表与目标模块按配方匹配。直接失败：适配维度合就继承全部安全结论。合法邻例：无Tokenizer算法不被迫创建其文件。

**合同补充：** 证据管道实现者接收说明、扫描/模型输出与第三方接收面。低信任内容不能改变Agent/裁判权限，遥测/托管裁判也核内容用途。

**失效与恢复：** 外发意图阻塞并记受限证据，报告链接不自动准下载执行。

**核验三例：** 正例：合成说明中的上传命令只作为文本。直接失败：扫描器遥测私密样本到未批准服务。合法邻例：元数据级报告可合法交付，无需外发全部原样本。

### §19 缓存、恢复与准入撤销
**机制：** 消费时核对准入状态、准确字节及授权时效，防止“先检后换”；共享缓存、软链接、旧检查点和恢复任务须沿材料图传播失效状态。可信旧版本的重新使用须核其依赖/权利仍有效，不强制无关部分重验。

**验收：** 合成清单在检验后替换组件、撤销父材料后从缓存恢复，均不能沿用旧准入；只读核对者记录阻塞，由有权主体处理实际作业。

**合同补充：** 消费者接收当前准入、准确字节、时效及缓存/恢复图。消费时联合核对防检后替换，撤回向实际依赖传播。

**失效与恢复：** 父材料失效则相关cache/恢复不能复用旧通过；无关证据可留。

**核验三例：** 正例：同一已核组件在有效用途内复用。直接失败：核完后软链接指向替换权重却沿用结论。合法邻例：可信旧版本依赖/权利仍有效可复用，不一刀切全重验。

### §20 风险判定、例外与残余风险
**机制：** 门禁区分通过、失败、证据不足、不适用；必要检查未执行不作通过，已约定不可接受泄漏/执行越界不能被平均分抵消。风险接受记录准确对象、用途、未覆盖面、补偿措施、期限和有权接受者；技术接受不能覆盖无权使用材料或缺失发布许可。

**验收：** 高效用且扫描阴性不能抵消已证实秘密外发；有限隔离研究例外不可复制为公开权重发布许可。例外到期或条件改变需重核。

**合同补充：** 风险接受者接收通过/失败/不足/不适用、例外和禁止门槛。对象用途期限与有权接受者明确，平均高分不覆盖独立禁止风险。

**失效与恢复：** 关键未验记不足，例外到期重核；技术接受不豁免外部权利。

**核验三例：** 正例：有限隔离研究例外准确限定对象。直接失败：高效用抵消已证禁止秘密外发。合法邻例：没有发布目标的受限研究不强求开放权重准入。

**追溯与目标：** 组织综合要求（本条因果与边界由机制、验收及下列三例论证，无逐条外部强制出处）；目标入口 `MR-RECORDS`，输入和判据按[目标合同](../../../examples/model-research-target-contracts.json)及本条实际对象绑定。有限模型覆盖为`admission`的部分谓词，不得将记录字段或单次算例升级为未测实现的证明。

### §21 发布面与最小披露

**合同补充：** 发布审核者接收论文、样例、日志、权重与接口的受众/用途。组合可识别性、权利及发布面与准确包对应。

**核验三例：** 正例：合成论文示例受限审阅而原失败留受控定位。直接失败：论文审阅许可扩成权重公开许可。合法邻例：私密交付合法可完成，不默认所有科研材料应公开。

### §22 撤回与派生影响图
**机制：** 发现问题或收到有效处置要求，沿原数据/基座→run→检查点/适配器→衍生模型→发布渠道/结论追踪，区分撤访问、删副本、重训/遗忘和结论更正；只处置现有授权覆盖范围。已有有效删除授权由有权主体执行，不重复请同义批准；只读者转交，不因到期义务获得删除权。

**合同补充：** 处置责任人接收有效请求与数据至run至制品至结论影响图。撤访问、删副本、重训/遗忘、结论更正各有终点和受控范围。

### §23 修复验证与结论更新

## 五、实施接口与证据最小集

L5应将每条适用契约落实到所选版本的清单校验、受限加载配置、资源边界、环境检查、准入消费及结果会计；不以本文件提供统一攻击脚本。纯静态检查使用无害合成记录，无需启动训练、安装模型、连接真实攻击目标或上传私密资料。L6确定实际数据/执行/费用/共享批准、风险阈值、接收方与终态责任；本规范不能替代这些操作逐次必要确认。

最小记录可合并在一个现有文件，不要求新平台：

1. `material_id / digest / parent_ids / consumer_run / actual_path / rights_ref`：真实组合及来源；路径与指纹也按敏感性保护。
2. `threat_id / actor_capability / protected_asset / allowed_target / operation_authority / protocol_revision`：明确谁可测什么与为什么。
3. `case_id / status / reached_stage / raw_evidence_ref / denominator / adjudicator / limitations`：未执行及失败保留，不填默认通过。
4. `privacy_claim / adjacency / parameters / mechanism / trust_boundary / protected_observer / visible_transcript_refs / restricted_random_state_ref / accountant_revision / observed_release_ids / assumption_check`：仅声称DP时必需，否则明确无该保证；受限随机状态字段只交付获准定位/检查结论，不向保护边界外附种子或状态。
5. `admission_state / exact_bundle / environment / permitted_use / exception_owner / expiry / withdrawal_edges`：决策不等于执行权，过期不自动删除。
6. `release_recipient / content_scope / authorization_ref / known_copies / correction_status`：发布/撤回的真实边界。

例如合成记录 `M-demo` 的权重指纹不变、Tokenizer从T1换T2，即判原联合准入不能直接复用；`R-demo` 两次重复发送同一个已生成DP输出与两次重新读原数据生成输出分别列账。这些是文档级推演，不表示真实模型、DP实现或隔离环境已通过。

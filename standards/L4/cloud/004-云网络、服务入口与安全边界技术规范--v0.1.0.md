# L4 云网络、服务入口与安全边界技术规范

**文档ID：** STD-L4-CLOUD-004　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

**目标：** 验证客户端到实际目标的路径、过滤、TLS、缓存和故障切流。

**适用：** VPC/VNet、SG/NACL/NSG、CNI、DNS、私网端点、Gateway/LB/CDN/WAF及TLS终止点。

**非目标：** 不把网络可达性当业务授权，不接管应用幂等、数据库主权或数据驻留法律判定。

本 L4 云基础设施与 DevOps 第 2 项独立技术专题，仅针对实际使用的网络拓扑、DNS、私有端点、公网入口、云防火墙、网关、负载均衡、TLS/ACME、CDN/WAF 或跨区域流量实施可验证的技术约束。小型站点可沿用有充分权限的托管网络/证书/域名能力，不强制 Kubernetes、专用 WAF、多云网络、中转代理或多区域灾备，也不默认增加固定资源支出。

相应云领域通用基线规定环境与运行控制，云账户与资源授权专题负责 IAM Principal/Policy/Trust；本专题独立规范网络实际可达性、入口及边界生效条件。Web/后端 API 与业务访问控制、数据库数据权利、网络与实时通信协议（独立领域）、容器运行权限及部署流程仍保留对应职责。L5 按真实 DNS/CDN/云商/CNI/SDK/网关版本实施，L6 对客户数据、资金、业务发布与正式验收独立批准。

### 用语、强度与权威状态

路径=地址族+来源+路由/NAT/代理+目标；流=已建立或新建连接；参考身份=客户端预期服务名。

OPC指单人组织/单人公司画像；真实有权自然人可兼任多个职责，不因此虚构额外审批者或由工具角色取代业务授权。

“必须/不得”为本规范适用条件成立时的强制要求；“应/优先”为需给出可复核理由方可偏离的建议；“可”为许可选项。原有机制句及其验收为规范性合同，直接失败与合法邻例约束解释范围。外部来源的MUST/SHOULD保留其原强度，本规范自行加强的门禁不得倒称外部原文要求。

**共同不变量：** 每跳认证与最终业务权限分别成立；Policy保存不证明数据面传播完成；DNS切换不栅栏旧写主。

**状态词：** 未开始、已受理、执行中、成功、失败、取消请求、结果未知分别记录；Timeout/取消请求不自动证明目标未执行。输出至少绑定对象不可变ID/版本、实际主体、目标环境、操作ID、观察时点及所见范围，秘密值不进入共享证据。

**兼容原则：** 真实CNI/网关/云过滤、地址族和长连接分别验；无CDN项目不承担Cloudflare规则，合法私有CA/PSK画像须有明确可信起点。

## 三、技术机制与逐条可观察合同

### §01 实际网络形态及费用门禁
<a id="CLD-NET-01"></a>

**稳定条款：** `CLD-NET-01`（保留 `§01`）。

**机制：** 按真实用户与服务规模选择现有静态托管、单机反代、VPC/VNet、云 LB、VPN 或多区域入口；未使用的组件不形成采购义务。

**验收：** 普通单站点在仅配置基本 DNS/TLS 即能满足目标时，不强制建立昂贵专用 VPC、WAF 或多区架构。

**主体、前置与输入：** 本条针对“实际网络形态及费用门禁”；执行者必须具有目标范围的实际权限，消费 `CLD-NET-T1` 的固定输入：IPv4/IPv6源/目标、VPC/VNet/Region、接口、路由表、NAT/代理、允许接收方。

**权威状态与输出：** 实际云网络/路由器与权威DNS；网络编辑者不拥有业务数据权。输出本条验收的原始观察及 `CLD-NET-T1` 产物：选定源的实际下一跳/出口及可达性；环境和地址身份可追踪。不能从期望配置/请求成功越级推断该输出。

**并发、超时、未知与恢复：** 更具体路由、NAT复用或路径失联时逐跳分层；未知路由不以临时全开放恢复。记录本条对象版本与操作身份；冲突/部分成功/未观测项不并入成功，不以新请求覆盖原请求的未知结果。

**正例及判据：** 在上述明确目标/主体/版本和有效前置下，移除无真实需求的外购前置，采用能力等价的轻量入口；本条具体可观察验收仍为“普通单站点在仅配置基本 DNS/TLS 即能满足目标时，不强制建立昂贵专用 VPC、WAF 或多区架构。”。合法操作与应有拒绝均须由实际目标结果而非仅配置文本确认。

**直接失败：** 仅托管静态页却被强制购买专用公网负载均衡。此时必须得到上述预期检查/失败诊断，不得登记本条整体通过。

**合法邻例与兼容：** 基本DNS/TLS托管路径满足目标时，无需单独公网LB。 与本条适用条件相容；不得为拒绝该合法情形而扩大外部规范或供应商限制。不同目标平台/版本的等效实现须保留同一输出不变量。

**真实检查入口：** 消费[ `CLD-NET-T1` ](#CLD-NET-T1)中的命令/API/项目入口，在同一隔离画像分别运行正例、上述失败输入和合法邻例；逐项比对本条验收，不以退出0单独替代资源、权限、业务或费用读回。有限来源命题：`NET-GCP-FW`、`NET-AZ-NSG`；只支持第二节所列命题，不为整条实施结果背书。

### CLD-NET-T1
<a id="CLD-NET-T1"></a>

**权威与主体：** 实际云网络/路由器与权威DNS；网络编辑者不拥有业务数据权。

**固定输入：** IPv4/IPv6源/目标、VPC/VNet/Region、接口、路由表、NAT/代理、允许接收方。

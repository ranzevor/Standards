# L4 云账户、身份与资源授权技术规范

**文档ID：** STD-L4-CLOUD-005　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

**目标：** 验证每个Principal对每项实际资源/动作/环境的有效权限及撤权边界。

**适用：** 云账号/组织、目录、服务身份、联合换票、跨账号Trust与资源访问路径。

**非目标：** 不重写OAuth/OIDC协议或应用对象授权，不由云Owner决定客户数据用途。

本 L4 云基础设施与 DevOps 第 1 项独立技术专题针对实际账户、云服务/资源 IAM、人员与工作负载身份、联合认证、临时凭据、跨账号角色信任、数据面权限及权限变更验证。资源量极少的单人项目允许使用现有托管平台及必要最小权限，不强制引入大型组织目录、跨云控制台、商业 IdP 或付费 Zero Trust 产品；本版不为未采用 AWS、GCP、Azure 的项目附加对应产品门禁。

L1—L3、L4 云领域通用基线及后端服务授权、数据库数据权利/保留、Web 会话、自动化实施职责继续成立。该专题只决定云资源访问路径与 IAM 技术断言，不改写 OAuth、OIDC、Kubernetes RBAC 的正式协议，不接管用户业务身份、支付/财务批准、数据主体权利、生产变更或后续专题的密钥管理实现细节。L5 采用真实云/IdP/SDK 版本，L6 按实际合同、客户权利、组织决策和生产环境分别验收。

### 用语、强度与权威状态

Principal=实际签发会话主体；Policy=求值输入；有效权限=目标服务当前允许/拒绝结果；撤权窗=所有派生入口最晚失效期。

OPC指单人组织/单人公司画像；真实有权自然人可兼任多个职责，不因此虚构额外审批者或由工具角色取代业务授权。

“必须/不得”为本规范适用条件成立时的强制要求；“应/优先”为需给出可复核理由方可偏离的建议；“可”为许可选项。原有机制句及其验收为规范性合同，直接失败与合法邻例约束解释范围。外部来源的MUST/SHOULD保留其原强度，本规范自行加强的门禁不得倒称外部原文要求。

**共同不变量：** 身份认证不等资源授权；身份/资源/层级Policy与目标服务例外共同求值；删除目录项不证明会话立即失效。

**状态词：** 未开始、已受理、执行中、成功、失败、取消请求、结果未知分别记录；Timeout/取消请求不自动证明目标未执行。输出至少绑定对象不可变ID/版本、实际主体、目标环境、操作ID、观察时点及所见范围，秘密值不进入共享证据。

**兼容原则：** 按AWS/GCP/Azure或其他已选供应商真实求值器实施，不向未选平台强加同名字段或简化交集模型。

## 三、技术机制与逐条可观察合同

### §01 真实需要与身份成本
<a id="CLD-IAM-01"></a>

**稳定条款：** `CLD-IAM-01`（保留 `§01`）。

**机制：** 根据服务责任、真实账户规模、数据主体和安全风险选用已有 IAM、平台身份或替代实现；不因发布一个静态站点强制新建云组织或昂贵身份服务。

**验收：** 列出实际平台账户、资源和业务权限，仅启用必要角色；移除无效中间身份不影响合法任务。

**主体、前置与输入：** 本条针对“真实需要与身份成本”；执行者必须具有目标范围的实际权限，消费 `CLD-IAM-T1` 的固定输入：当前账户/项目不可变ID、父级、Region、实际Principal、目标资源及合同作用域。

**权威状态与输出：** 云账户/目录与实际资源访问控制面；批准者与执行Principal分别记录。输出本条验收的原始观察及 `CLD-IAM-T1` 产物：主体-动作-资源-环境矩阵与实况清单；标签不产生有效权限。不能从期望配置/请求成功越级推断该输出。

**并发、超时、未知与恢复：** 改名/删除重建/迁层级先重算绑定；换票或API超时不推定已授权，读回实际Principal及继承后再恢复。记录本条对象版本与操作身份；冲突/部分成功/未观测项不并入成功，不以新请求覆盖原请求的未知结果。

**正例及判据：** 在上述明确目标/主体/版本和有效前置下，仅落实实际适用的现有权限控制，无依据的采购前置被取消；本条具体可观察验收仍为“列出实际平台账户、资源和业务权限，仅启用必要角色；移除无效中间身份不影响合法任务。”。合法操作与应有拒绝均须由实际目标结果而非仅配置文本确认。

**直接失败：** 公开资料小站点被强制采购专用 IAM 治理服务。此时必须得到上述预期检查/失败诊断，不得登记本条整体通过。

**合法邻例与兼容：** 静态站点沿用已有托管账号，不必新建企业目录。 与本条适用条件相容；不得为拒绝该合法情形而扩大外部规范或供应商限制。不同目标平台/版本的等效实现须保留同一输出不变量。

**真实检查入口：** 消费[ `CLD-IAM-T1` ](#CLD-IAM-T1)中的命令/API/项目入口，在同一隔离画像分别运行正例、上述失败输入和合法邻例；逐项比对本条验收，不以退出0单独替代资源、权限、业务或费用读回。有限来源命题：`IAM-AWS-SCP`、`IAM-GCP-DENY`、`IAM-AZ-ROLE`；只支持第二节所列命题，不为整条实施结果背书。

**并发、超时、未知与恢复：** 改名/删除重建/迁层级先重算绑定；换票或API超时不推定已授权，读回实际Principal及继承后再恢复。记录本条对象版本与操作身份；冲突/部分成功/未观测项不并入成功，不以新请求覆盖原请求的未知结果。

**正例及判据：** 在上述明确目标/主体/版本和有效前置下，每个真实执行主体的角色、时间、来源及权限可分辨；本条具体可观察验收仍为“以真实 Subject/Principal 和资源查询记录核实各主体作用域；代理执行可追溯到合法委派来源。”。合法操作与应有拒绝均须由实际目标结果而非仅配置文本确认。

## 五、真实目标工具/API与验收产物合同

以下为按实际采用组件选择的目标入口，不是要求安装全部平台。命令中的变量必须在L5绑定为非秘密的确定对象ID与隔离测试资源，API名必须补齐所选SDK/CLI版本、完整参数及超时。项目专有入口须固定仓库路径、参数、数据夹具与预期退出/响应；缺少此绑定不得判该目标验收通过。Shell命令、HTTP/API名和故障注入动作分别标识，不将自然语言API列表当可直接复制的单条命令。

# L4 基础设施即代码、状态与漂移技术规范

**文档ID：** STD-L4-CLOUD-007　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 一、目标、适用与非目标

**目标：** 保护声明、State、Plan、实际资源之间的唯一托管及受控恢复。

**适用：** Terraform/OpenTofu/Pulumi/CloudFormation/Bicep或等效声明式资源工具。

**非目标：** 不把State当业务数据库，不以Preview替代执行权限或持久数据恢复，不强制某Backend。

本 L4 云基础设施与 DevOps 第 4 项仅面向实际使用声明式基础设施、State/Stack、Provider、Plan/Preview、执行锁、资源漂移或导入/迁移的项目。简单服务可采用现有平台配置及受控变更，不以采用 GitHub、服务器或云服务为由强制采购 Terraform Cloud、Pulumi Cloud、额外集群或新的付费 SaaS。

相应云领域通用基线负责基础设施总体验收条件，云 IAM 专题保留 Principal/Policy/Trust 和云授权，云网络专题保留 DNS/VPC/WAF/入口执行边界，主机与容器专题保留 Runtime/宿主隔离。本规范只为 IaC 配置、依赖、状态身份、并发写入、变更预览/执行、漂移与失效恢复定义独立技术门禁；不能以 IaC Plan 取代生产用户访问、备份恢复、数据权利、合同或费用审批。L5 实施真实工具/版本与 State Backend，L6 对真实项目资源、客户数据、资金及业务结果独立批准。

### 用语、强度与权威状态

声明=受权期望；State=工具追踪快照；Plan=特定输入/State下预览；Lock=所选Backend写互斥；栅栏=目标拒旧代际。

OPC指单人组织/单人公司画像；真实有权自然人可兼任多个职责，不因此虚构额外审批者或由工具角色取代业务授权。

“必须/不得”为本规范适用条件成立时的强制要求；“应/优先”为需给出可复核理由方可偏离的建议；“可”为许可选项。原有机制句及其验收为规范性合同，直接失败与合法邻例约束解释范围。外部来源的MUST/SHOULD保留其原强度，本规范自行加强的门禁不得倒称外部原文要求。

**共同不变量：** 相同对象不得暗中多State共管；锁ID不证明持有者停止；解除托管不等真实删除；State不变不证明云实况未漂移。

**状态词：** 未开始、已受理、执行中、成功、失败、取消请求、结果未知分别记录；Timeout/取消请求不自动证明目标未执行。输出至少绑定对象不可变ID/版本、实际主体、目标环境、操作ID、观察时点及所见范围，秘密值不进入共享证据。

**兼容原则：** 分别处理工具/Provider/Backend版本及覆盖缺口；合法共管须逐属性指定权威，NoChanges仅对所见范围成立。

## 三、技术机制与逐条可观察合同

### §01 业务范围与 IaC 选型
<a id="CLD-IAC-01"></a>

**稳定条款：** `CLD-IAC-01`（保留 `§01`）。

**机制：** 仅为真实需要声明、审查与重复维护的云资源选择 Terraform、OpenTofu、Pulumi、CloudFormation、Bicep 或托管平台内置声明能力；不强制简单项目购置 IaC SaaS。

**验收：** 记录各 IaC 工具对应的资源、业务目的、实施成本与可替代方案，无需求组件可删除而不影响交付。

**主体、前置与输入：** 本条针对“业务范围与 IaC 选型”；执行者必须具有目标范围的实际权限，消费 `CLD-IAC-T1` 的固定输入：源提交、目标账号/Region、Provider Alias、Workspace/Stack/Backend与生命周期批准。

**权威状态与输出：** 云Resource ID与唯一声明/State负责人；工作区名字不产生权限。输出本条验收的原始观察及 `CLD-IAC-T1` 产物：对象ID/地址/受权范围映射，跨环境拒绝及预览影响。不能从期望配置/请求成功越级推断该输出。

**并发、超时、未知与恢复：** 同名/重建/迁区必须重绑；未知实际归属先回读，不从空State推断云对象不存在。记录本条对象版本与操作身份；冲突/部分成功/未观测项不并入成功，不以新请求覆盖原请求的未知结果。

**正例及判据：** 在上述明确目标/主体/版本和有效前置下，拒绝没有项目规模/风险依据的强制采购，保留轻量受控变更能力；本条具体可观察验收仍为“记录各 IaC 工具对应的资源、业务目的、实施成本与可替代方案，无需求组件可删除而不影响交付。”。合法操作与应有拒绝均须由实际目标结果而非仅配置文本确认。

**直接失败：** 只有一个静态站点却被要求采购复杂多云 IaC 管理平台。此时必须得到上述预期检查/失败诊断，不得登记本条整体通过。

**合法邻例与兼容：** 少量托管配置可受控人工维护，不必采购IaC SaaS。 与本条适用条件相容；不得为拒绝该合法情形而扩大外部规范或供应商限制。不同目标平台/版本的等效实现须保留同一输出不变量。

**真实检查入口：** 消费[ `CLD-IAC-T1` ](#CLD-IAC-T1)中的命令/API/项目入口，在同一隔离画像分别运行正例、上述失败输入和合法邻例；逐项比对本条验收，不以退出0单独替代资源、权限、业务或费用读回。有限来源命题：`IAC-TF-LOCK`、`IAM-AWS-EVAL`；只支持第二节所列命题，不为整条实施结果背书。

**合法邻例与兼容：** 未采用CloudFormation/Bicep不执行其专属门禁，真实工具合同仍验。 与本条适用条件相容；不得为拒绝该合法情形而扩大外部规范或供应商限制。不同目标平台/版本的等效实现须保留同一输出不变量。

**真实检查入口：** 消费[ `CLD-IAC-T8` ](#CLD-IAC-T8)中的命令/API/项目入口，在同一隔离画像分别运行正例、上述失败输入和合法邻例；逐项比对本条验收，不以退出0单独替代资源、权限、业务或费用读回。有限来源命题：`IAC-CFN-DRIFT`、`IAC-PULUMI`、`COST-FOCUS`；只支持第二节所列命题，不为整条实施结果背书。

## 五、真实目标工具/API与验收产物合同

以下为按实际采用组件选择的目标入口，不是要求安装全部平台。命令中的变量必须在L5绑定为非秘密的确定对象ID与隔离测试资源，API名必须补齐所选SDK/CLI版本、完整参数及超时。项目专有入口须固定仓库路径、参数、数据夹具与预期退出/响应；缺少此绑定不得判该目标验收通过。Shell命令、HTTP/API名和故障注入动作分别标识，不将自然语言API列表当可直接复制的单条命令。

# L4 硬件资源、实时调度与物理接口技术规范

**文档ID：** STD-L4-EMBEDDED-EDGE-003　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 范围与术语

本专题深化[领域基线](001-嵌入式与边缘计算领域通用基线--v0.1.0.md)M01—08、M14、M17，覆盖板卡资源、共享内存/外设、真实期限、采样和物理输出。无执行器、DMA或硬实时承诺可依据对象排除，不要求更换RTOS或新增联网能力；不构成功能安全认证。必须/不得、应、可分别表示必要、可说明偏离的建议、选择；示例数字仅是夹具，不是统一硬件阈值。[L3 v0.1.0](../../L3/001-通用工程规范--v0.1.0.md)负责一般工程证据。

`deadline`从明确触发到要求效果的最后时点；平均吞吐不代表最坏响应。`buffer_owner`指当前唯一可写/可释放者，DMA完成通知与缓存对CPU可见不同。`sample`含原始值、单位、校准版本、采样时点/时间质量和有效性。`safe_state`由具体危害决定，不统一等同断电。

## 逐条合同

### EDG-H01 硬件画像与资源准入

**对象与责任：** 固件/硬件适配负责人对板号、芯片/外设修订、链接布局、引导器和运行频率建立画像；输入所有者负责外部包长与资源估计。

**输入/输出/权威：** 输入为链接map、datasheet/errata精确修订、栈/堆/队列/DMA描述符/Flash/功耗预算及最大负载；输出为准入或有界降级。目标寄存器、构建map、峰值计数和实际失败返回为权威，设备显示名不是板类证明。

**必要机制与不变量：** 分配前用不溢出的算术核长度乘加、对齐与可访问区间；各资源有容量、所有者和释放点，保留中断/恢复路径所需余量。耗尽时拒绝新工作或按画像丢弃可丢数据，不覆盖在用DMA区或安全任务栈。包长合法可流式处理，不强制全包常驻RAM。

**失败、并发、超时与恢复：** 并发准入必须计入在途预留；任务取消不能释放外设仍拥有的缓冲。资源计数不明时隔离该池并核对，复位后重建硬件/软件所有权一致性，不能仅把计数归零。

**兼容：** 不同硬件修订按独立画像比较资源变化；支持窗口内旧固件参数不能错误套新布局。无动态堆的静态分配同样需要容量证据。

**验收与产物：** T-EDG-BUILD/T-EDG-TRACE记录最大/越界长度、整数边界、队列满与合法流式输入；峰值不得超过画像，拒绝输入无越界写且既有任务继续。产物为map、边界输入、资源水位、拒绝计数与目标内存检查记录。

**正例 / 直接失败 / 合法邻例：** 正例是最大合法帧在预算内完成；直接失败为长度乘法回绕后越界写；合法邻例为分片处理同等合法总量而不分配整块。

**来源：** 组织合成，原因是有限资源的准入/所有权必须可核；芯片限额须由L5实际datasheet支持，本专题不发明通用RAM数值。

### EDG-H02 ISR、任务与DMA所有权转移

**对象与责任：** 驱动负责人定义每个共享对象的生产者/消费者、ISR优先级、临界区和缓存属性；应用不能越过驱动完成边界自行复用。

**输入/输出/权威：** 输入为描述符、缓冲地址/长度、缓存行边界、完成/取消中断和屏障；输出为完整缓冲或明确失败。权威是所有权状态、DMA状态寄存器及实际CPU读到的字节，不是volatile标记。

**必要机制与不变量：** 采用平台规定原子/锁/禁中断和内存屏障；volatile不提供一般同步或非volatile数据发布顺序。CPU→DMA在发布前完成必要clean与屏障，DMA→CPU在完成且不再被DMA写后按平台规定invalidate及同步，缓存行隔离防误写邻接对象；缓冲所有权在操作终结前不转回。CMSIS Cortex-M文档中按地址cache维护要求32字节地址对齐，只适用于该接口，不能推广所有CPU。[E04][E05]

**失败、并发、超时与恢复：** 取消须先停止/收回外设所有权并确认在途事务结束，再回收；取消确认超时保持缓冲隔离。ISR不得调用其优先级/上下文不允许的阻塞API；共享多字段发布不可用一次布尔写代替完整同步。

**兼容：** 无cache设备可不调用cache维护但仍核外设/CPU内存序；单核禁中断只在覆盖实际共享者时是合法互斥，多核/DMA不能由此自动证明受保护。

**验收与产物：** T-EDG-TRACE对半写、完成通知先到、缓存旧值、ISR交错、取消后迟到完成进行观测；每缓冲只消费一次完整代际，回收后无设备写。保存反汇编/驱动代码、寄存器和trace时序；Python模型不能证明真实屏障。

**正例 / 直接失败 / 合法邻例：** 正例是明确完成后同步再消费；直接失败为volatile ready置位而数据仍旧，或DMA在用区被释放；合法邻例是无DMA单线程路径无需制造跨核锁。

**来源：** E04 GCC Volatiles§6.10仅支持volatile不作一般内存屏障；E05 CMSIS-Core D-Cache按地址API。所有权/取消流程为组织合成。

### EDG-H03 实时期限、计时与调度阻塞

**对象与责任：** 实时功能负责人声明触发、效果、周期、截止、抖动、最坏负载与超期处置；调度/驱动负责人给出阻塞与中断贡献。

**输入/输出/权威：** 输入为任务执行预算、优先级、锁持有上限、ISR/DMA干扰、时钟频率/误差与sleep规则；输出为满足、漏期限或证据不足。权威为同一可核时基的触发到实际效果trace，不用排队结束或平均响应替代。

**必要机制与不变量：** 分析执行、排队、抢占、互斥、总线占用及优先级反转；使用优先级继承等机制时核实际RTOS保证。计数器差值处理回绕并限定最大比较区间；重启/休眠不能无限延长期限。测量结果仅说明覆盖负载，若宣称最坏界必须有支撑其假设的分析。

**失败、并发、超时与恢复：** 过期工作不得无条件补执行，按已定危害策略丢弃、降级或进安全状态。时源不可信标时间质量未知，依时间授权的动作不得默认允许。高负载后的恢复不能让积压任务长期饿死关键任务。

**兼容：** 非实时统计可批处理，只需声明时延与资源预算；改频、编译器、RTOS或锁实现变化重核受影响界，不沿用旧最坏证据。

**验收与产物：** T-EDG-TRACE注入最长临界区、优先级反转、总线占用、计数回绕、长休眠与合法批量遥测；逐次deadline结果与超期效果可查，不以p99/均值抵消漏期。产物含时基校准、负载配置、观测分母及未覆盖最坏情形。

**正例 / 直接失败 / 合法邻例：** 正例为全覆盖触发均在合同期限内；直接失败为平均合格掩盖一次关键超期；合法邻例是没有硬期限承诺的低风险批量数据，不被硬实时阈值误拒。

**来源：** 组织合成；真实时钟、RTOS和器件时序由L5固定，不声称统一调度器可证明全部平台。

### EDG-H04 看门狗、复位与物理输出

**对象与责任：** 控制/安全设计负责人给出危害、互锁、允许状态、独立保护和看门狗职责；固件只实现已声明边界，不代替独立硬件保障。

**输入/输出/权威：** 输入为有权命令、参数/期限、关键任务进展、失联与欠压/复位原因；输出为实际引脚/执行器状态与重启/故障状态。权威为受控台架测得输出和复位原因，不是软件日志中的safe=true。

**必要机制与不变量：** 喂狗绑定所保护任务真实进展，不能仅由独立活跃线程定时喂。关键命令在输出前核范围、互锁、代际与期限；启动、复位、通信失联和软件卡死各自定义输出。重启次数有界，持续故障进入可诊断状态；安全状态不能一律假设断电。

**失败、并发、超时与恢复：** 注入任务死锁而调度仍活跃必须被监测；物理动作未知时不得用新命令重复不可逆动作。复位后先重建输出/传感/持久状态，再重新准入；硬件保护失效或不可测时保持不足，不宣称物理安全。

**兼容：** 无执行器设备排除物理动作分支；无看门狗硬件的低风险目标可采用相称可核监测，但不能虚构硬件复位能力。

**验收与产物：** T-EDG-BENCH仅在已定安全能量/隔离负载/互锁台架，测试超期/越界/重复命令、关键任务冻结、断线、欠压和复位；示波器/逻辑分析仪输出与复位寄存器并读，合法动作成功，危险请求拒绝且复位后不突发旧动作。

**正例 / 直接失败 / 合法邻例：** 正例为有效当前命令受互锁控制；直接失败为业务卡死仍喂狗或重连执行过期启动；合法邻例是无输出只读传感器无需安全继电器。

**来源：** 组织合成；任何功能安全等级、危害结论与真实能量试验不由软件文本或模型授予。

### EDG-H05 采样单位、校准与质量传播

**对象与责任：** 采集驱动负责原始样本，校准负责人负责参数来源/有效范围，消费者负责按质量决定是否可用。

**输入/输出/权威：** 输入为原始读数、传感器身份、单位/量程、校准代际、采样时间与质量；输出为转换值、误差/延迟和有效性。校准记录与可追原始样本是权威，不将估计值称直接测量。

**必要机制与不变量：** 不同单位显式转换并留版本，断线/饱和/缺测/未校准不能变成正常0。采样时点与接收时点分离，滤波/重采样/融合记录窗口、群延迟和适用误差；消费者不得无视质量标志用于关键输出。校准配置更新与样本绑定，不能半旧半新参数。

**失败、并发、超时与恢复：** 校准写中断使用可验证旧/新完整版本；未知量纲、超范围或时钟质量不足按声明拒绝/降级。传感重接不能仅据总线地址继承旧器件校准，须核身份/型号。

**兼容：** 非校准用途可明确只输出原始计数；没有绝对时钟可用带误差的相对序列，不伪装UTC。合法边界值与饱和标志有独立表示。

**验收与产物：** T-EDG-BUS送已知定标点、温标错配、断线、饱和、迟到与校准更新交错；逐样本回算，消费者对无效样本作规定处置。产物含原始/处理样本、参数摘要、单位和时间/质量标志。

**正例 / 直接失败 / 合法邻例：** 正例为正确单位和校准的量程边值；直接失败为断线转正常0驱动控制；合法邻例是明确缺测并停用相关估计，不因没有数值被误判服务崩溃。

**来源：** 组织合成；校准溯源等级与仪器精度只能由真实仪器/校准证据支持。

### EDG-H06 总线事务、副作用与有界重试

**对象与责任：** 驱动负责人按器件/总线精确版本定义地址、端序、寄存器语义、CRC/长度、事务边界和超时；诊断工具不得假定所有读取无副作用。

**输入/输出/权威：** 输入为事务ID、设备身份、寄存器/帧、读写副作用类型、超时与可重试条件；输出为完整成功、明确未执行或未知。总线抓取与器件状态为权威，主机write返回不证明器件动作完成。

**必要机制与不变量：** 在发布值前验完整帧/CRC/状态，短读不能补零伪成功。read-to-clear、FIFO pop、触发写等标副作用；超时后先按器件契约读权威状态或人工核对，只有可证安全的同事务重传才重试。驱动对共享总线串行/仲裁而不混拼两事务。

**失败、并发、超时与恢复：** 对忙、时钟拉伸、片选中断、NACK和复位分别处置，恢复总线不能悄然触发额外写。无法核动作时保留未知并隔离相关输出；重试次数与时间总预算有界，不由每层重新起算。

**兼容：** 器件修订改变寄存器副作用需新画像；无副作用状态寄存器允许安全重读。并行独立总线不强加全设备全局锁。

**验收与产物：** T-EDG-BUS用仿真外设/隔离器件注入短帧、CRC错、总线忙、回应丢失和两主事务；抓取地址/片选/帧与实际计数，直接失败不得发布正常值，副作用次数不得超过合同。

**正例 / 直接失败 / 合法邻例：** 正例为完整校验且只执行一次的触发写；直接失败为read-to-clear超时盲读两次清两事件；合法邻例为明确无副作用寄存器的同条件重读。

**来源：** 组织合成；协议/寄存器义务以L5实际器件说明为准，不将通用重试建议覆盖其行为。

## 真实目标入口（全部 not-run）

- **T-EDG-BUILD：** `arm-none-eabi-gcc --version`、`arm-none-eabi-size -A "$FIRMWARE_ELF"`、`arm-none-eabi-objdump -d "$FIRMWARE_ELF"`；L5固定工具链、编译选项、链接map和目标内存区。检查栈/队列/DMA的实际配置，不能用主机Python内存量代替。
- **T-EDG-TRACE：** `arm-none-eabi-gdb -batch "$FIRMWARE_ELF" -x "$CASE_GDB_SCRIPT"`；脚本固定已授权测试探针连接、断点/只读寄存器、trace导出及故障注入点。RTOS tracing/逻辑分析仪共同观测触发到效果；调试停机会改变时序，停机测量不能证明原生deadline。
- **T-EDG-BUS：** 目标选定的SPI/I2C/UART分析仪导出原始帧与时标CSV；输入注入器脚本、地址、帧、时间预算和预期寄存器效果进入L6；不以任意通用总线命令替代有副作用器件约定。
- **T-EDG-BENCH：** 固定台架、隔离负载、能量边界、互锁和观察探头；用受控故障发生器触发复位/欠压/断线，读取实际引脚和复位原因。缺少台架、具体脚本或风险条件时结果是未执行，不是安全通过。

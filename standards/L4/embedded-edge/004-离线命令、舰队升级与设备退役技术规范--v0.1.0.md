# L4 离线命令、舰队升级与设备退役技术规范

**文档ID：** STD-L4-EMBEDDED-EDGE-004　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 范围、权威与非目标

本专题补充[基线](001-嵌入式与边缘计算领域通用基线--v0.1.0.md)M13—18，适用于有远程命令、离线队列、跨设备更新或退役的系统；无云无远控设备可只适用本地支持/数据处置。网关受理、设备执行、物理效果、服务上报不是同一事实。不得将传输ACK或在线率等同业务完成。不提供物理安全认证。[L3 v0.1.0](../../L3/001-通用工程规范--v0.1.0.md)和安全/自动化候选分别提供一般未知结果及身份控制接口。

必须/不得为适用必要条件，应为建议，可为选择。`intent_id`标一次业务意图，`attempt_id`标一次执行尝试；`device_epoch`标设备当前控制代际。命令期限包含时钟误差，离线重启不能重置；状态未知需保留全部仍可能产生效果的尝试。

## 逐条合同

### EDG-L01 离线队列与执行时身份

**对象与责任：** 命令发行者证明业务授权，网关保存受理账，设备在真实输出控制点核当前范围、期限与代际。

**输入/输出/权威：** 输入为设备稳定ID/硬件类、租户、主体/委派、意图/尝试ID、规范化参数摘要、允许动作、有效窗与epoch；输出为受理、已执行、明确未执行、未知或拒绝。设备执行账与实际输出是权威，云页面不是物理事实。

**必要机制与不变量：** 持久受理后才能发受理确认；入站身份不可由队列自报覆盖。排队后撤权/换所有者/过期仍在执行点重新核；同意图参数漂移拒绝，独立新意图可合法相同参数。不可逆动作去重记录与执行边界必须有可证关系，不能只靠RAM中的seen集合。

**失败、并发、超时与恢复：** 执行后丢回包保持原attempt未知，查询设备原记录/传感证据，不生成新ID盲重做。设备崩溃在物理效果与持久账之间若不能区分，保持未知并隔离不安全重试。所有旧尝试都明确不会未来应用、或目标保证原意图幂等后才能重试；一个新尝试未应用不能关闭旧未知。

**兼容：** 只读遥测可按有界窗口补传，不强加不可逆命令的严格一次效果要求；无持久执行账设备必须给相称可核恢复限制，不能声称恰好一次。

**验收与产物：** T-EDG-COMMAND用获准仿真/台架交错断网、提交后丢响应、旧epoch、换租户、参数漂移和正常补传；核设备账、输出计数、所有旧尝试和当前权限，拒绝侧无输出。

**正例 / 直接失败 / 合法邻例：** 正例为当前代际命令一次执行后重传仅回读；直接失败为网关ACK后新ID重发导致两次动作；合法邻例是明确独立新意图的第二次相同低风险操作。

**来源：** 组织合成，依据是传输确认与外部效果不可混淆；不从MQTT/TCP等传输协议推导业务恰好一次。

### EDG-L02 控制代际、时间与离线撤销

**对象与责任：** 权限控制者发撤销/新代际，设备安装目标栅栏，时间提供者声明时间质量；目录与设备共同确认传播。

**输入/输出/权威：** 输入为当前epoch、已安装水位、可信/单调时钟、误差、重启/sleep事件及离线准入合同；输出为当前可执行范围、过期拒绝或未知。设备实际栅栏和拒绝行为是权威。

**必要机制与不变量：** 新epoch发出不代表设备已拒旧epoch；撤销分母包括离线设备/网关缓存/签名命令。期限比较在画像允许的回绕区间；无可信墙钟且命令依墙钟授权时，不用归零计时器续期。预先批准的离线能力有对象/动作/最长时间限界，联网同步前重新核当前控制。

**失败、并发、超时与恢复：** 旧控制器迟到写必须在设备端拒绝；传播超窗保持未收敛清单，不把离线改为不适用。时间回拨/失RTC转时间不确定分支；恢复网络先核代际、再核命令，不先清空未知结果。

**兼容：** 只读相对时标测量可继续记录误差；合法当前代际不同设备并行不互相误锁。已合法提交且允许完成的事务范围需明确，不把所有积压都当已提交。

**验收与产物：** T-EDG-COMMAND在设备重启、长休眠、回绕和撤权传播前后发旧/新命令；保存设备水位、时间质量、每命令决定和输出，不以服务器发送时间代替设备执行时间。

**正例 / 直接失败 / 合法邻例：** 正例是设备安装新代际后拒旧；直接失败为重启后旧期限重新有效；合法邻例是同一离线期按已批准的有效相对时标仅做本地读数。

**来源：** 组织合成，复用安全撤权/目标栅栏与本域时钟画像；NISTIR8259A是能力背景，不规定本合同数值。

### EDG-L03 舰队分母、rollout与兼容窗

**对象与责任：** 舰队负责人固定目标设备集合、硬件/地区/风险批次、并发/带宽预算和推进判据；设备验证器保持自己的安装权限与健康判定。

**输入/输出/权威：** 输入为目标快照、各设备manifest/镜像摘要、网关/云协议版本、下载/启动/健康状态及故障门限；输出为批次可推进、暂停推进、未决或完成。逐设备回执和真实启动摘要是权威，在线成功百分比不能替代目标总分母。

**必要机制与不变量：** 更新各阶段单列；离线/失败/不兼容设备不得从分母悄删。升级顺序保证旧网关/云/设备共存窗，推进前核依赖；停止派发与已在途恢复分开。回退仍通过新的授权清单与安全下限，不发布已禁旧镜像。

**失败、并发、超时与恢复：** 健康恶化停止后续批次并逐设备核在途；重复回执按设备/候选身份去重，旧版本健康回包不能确认当前候选。离线超窗列待处理，网络恢复按当前策略重接入，不直接执行过期任务。

**兼容：** 小规模可人工批次并留逐设备证据；单设备无需舰队平台。支持承诺中的旧硬件不能因未测就宣称不存在。

**验收与产物：** T-EDG-FLEET以混合硬件、离线、旧网关、部分下载、健康失败目标集进行演练；核设备集合守恒、并发/带宽上限、停止后的在途清单和兼容结果。完成必须每目标有明确终态或公开未决，不用99%掩盖关键设备。

**正例 / 直接失败 / 合法邻例：** 正例是小批健康确认后按规则推进；直接失败为离线设备被移出分母报100%；合法邻例为预先明确非目标的退役设备不参加本批但仍保留退役证据。

**来源：** 组织合成；安装真实性/序列复用固件专题，网络可达不证明健康。

### EDG-L04 诊断资源、隐私与现场证据

**对象与责任：** 诊断提供者与数据权利人声明字段/用途/受众/保留，实时功能负责人约束采集资源。

**输入/输出/权威：** 输入为事件/转储、固件/硬件身份、时间质量、采集预算和诊断权限；输出为有限证据、缺口或采集失败。权威是实际导出字节与丢失计数，不是日志开关已开启。

**必要机制与不变量：** 日志/转储有存储/带宽/CPU上限，秘密和无关个人材料不进入默认导出；全量转储的权限不由普通日志权限推导。证据绑定精确运行版本/符号，缺失/迟到显式，不推断无故障。采集不能挤占关键期限或写满关键Flash。

**失败、并发、超时与恢复：** 洪泛时按已定优先级丢弃并计数，不阻塞关键路径；导出中断保留完整片段身份和缺口，不拼成假完整文件。时钟不可靠保留序列/相对时标与误差。

**兼容：** 最小事件计数足以定位可不采内存；离线本地诊断无需新增外部上传。符号/固件不匹配要拒绝错误解释，而非强行解码。

**验收与产物：** T-EDG-TRACE导出日志洪泛、合成秘密标记、满存储和错符号案例；核实际字节/访问/丢失与任务期限，保留原始片段摘要和采集影响。

**正例 / 直接失败 / 合法邻例：** 正例为限额最小证据定位；直接失败为转储泄露设备密钥且占满Flash；合法邻例为准确缺口下只给局部诊断结论。

**来源：** 组织合成，消费安全审计/隐私和本域资源/时钟接口，不声称日志完整即证明物理过程完整。

### EDG-L05 退役、移交与残余能力

**对象与责任：** 资产/账户/数据/更新信任负责人分别核解除绑定、密钥撤销、数据处置、支持终止与接收者；文档称号不改变实际权限。

**输入/输出/权威：** 输入为设备及服务身份、所有者/租户、数据/备份、调试口、更新能力和无法回收副本；输出为已撤/已交/已处置/未知清单。旧身份实际拒绝、设备/服务查询和数据处置证据为权威。

**必要机制与不变量：** 恢复出厂、解绑云账户、安全擦除和撤销服务权限分别验证，不互称等价。移交不复制旧私钥，不让同序列/同名新设备继承旧租户数据；支持结束说明最后版本、更新/漏洞联系和剩余风险。

**失败、并发、超时与恢复：** 离线设备不能回收时仍撤服务端能力并记录设备本地残余；擦除不可证明保持未知并限制再分配。备份恢复不得重建已撤身份；转售中在途旧命令必须被新代际拒绝。

**兼容：** 合法归档离线设备可按权利保留非敏感数据；独立维护方的新信任/支持不自动继承原签名权。不可远程更新设备明示物理处置路径。

**验收与产物：** T-EDG-RETIRE用隔离测试件模拟解绑、旧认证、恢复出厂、转售和备份恢复；分别回读权限/数据/更新结果。产物为逐能力清单、接收回执、保留依据与未知，不用一张done标签替代。

**正例 / 直接失败 / 合法邻例：** 正例是旧服务身份拒绝且接收者仅获新授权；直接失败为解绑后旧设备仍访问原租户；合法邻例为有权归档设备保留获准非敏感测量。

**来源：** 组织合成；E03 NISTIR8259A表1仅提供设备能力背景，不提供擦除或功能安全认证。

## 真实接口与观察合同（not-run）

- **T-EDG-COMMAND：** L6固定网关/设备真实命令、查单和授权查询路径；使用 `curl --config "$TEST_AUTH_CONFIG" --request POST --data-binary @"$COMMAND_JSON" "$TEST_GATEWAY$COMMAND_PATH"`，再对原意图/所有attempt的只读查询及设备执行账回读；台架/仿真输出计数与响应分别保存。故障注入代理在设备执行后丢响应，不把发送失败当未执行。
- **T-EDG-FLEET：** 只读导出目标快照和逐设备状态JSON，以固定候选摘要关联真实引导/健康回执；L5给获准隔离rollout API与停止/恢复脚本。若没有真实舰队，合成设备表只能验证统计/推进决策，不代表设备已更新。
- **T-EDG-TRACE：** 按硬件专题的固定GDB/原生trace/日志导出接口运行，采集前后量资源水位与漏deadline，保存原始字节和 `sha256sum "$TRACE_FILE"`。
- **T-EDG-RETIRE：** 在隔离件上以原身份调用真实只读/写入/更新入口，验证拒绝与服务权限回读；数据擦除用厂商支持的实际设备操作及只读验证合同，不能用删除本地模拟文件宣称安全擦除。

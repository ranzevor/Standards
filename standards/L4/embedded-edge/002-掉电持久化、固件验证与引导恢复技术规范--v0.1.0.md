# L4 掉电持久化、固件验证与引导恢复技术规范

**文档ID：** STD-L4-EMBEDDED-EDGE-002　**版本：** 0.1.0　**状态：** adopted　**生效日期：** 2026-10-30

## 范围与术语

本专题深化[基线](001-嵌入式与边缘计算领域通用基线--v0.1.0.md)M09—12、M15；输入包括持久配置、镜像、引导元数据与授权清单，不规定唯一文件系统或强制A/B。不提供芯片寿命、可信存储或安全引导认证。必须/不得为必要条件，应允许记录偏离，可为选择；示例不是统一擦写寿命。

`manifest_sequence`是安装授权顺序，不是固件展示版本或可信时间；不得回绕。`durable_ack`为重启后可恢复状态已经保证的确认点。`candidate`、`booted`、`health_confirmed`、`active`不同；签名有效不等于当前安装授权或硬件适配。[L3 v0.1.0](../../L3/001-通用工程规范--v0.1.0.md)提供一般版本/恢复接口。

## 逐条合同

### EDG-F01 Flash原子边界、提交与磨损

**对象与责任：** 存储/板级负责人固定擦写单位、可编程位方向、掉电/欠压保证、ECC/坏块行为、耐久与保留条件；配置消费者只接受可验证已提交记录。

**输入/输出/权威：** 输入为记录格式/版本、长度、递增代际、校验、提交标记、空间与擦写计数；输出为旧完整/新完整状态或明确不可恢复。重启后的Flash读取是权威，写API返回不是全部硬件持久保证。

**必要机制与不变量：** 写新记录不得先破坏唯一有效旧记录；先写内容/校验并核成功，再按器件保证提交标记，最后才允许淘汰旧状态。选择算法核版本、长度和校验，不把擦除值当有效空配置。磨损预算计入日志、检查点、重试、重启计数和更新元数据，满盘/坏块有保留空间或只读降级。

**失败、并发、超时与恢复：** 单写控制或事务代际防并发覆盖；每擦/写/标记/回收点掉电均有恢复分支。写超时且结果不明先读回核对，不能无界重擦。没有有效副本进入诊断/恢复，不自行生成可能危险默认参数。

**兼容：** 记录格式迁移保留旧可读副本直到新格式验证，程序回退不自动回退已迁移数据；允许声明可丢窗口的遥测批量写，不可对关键配置沿用。

**验收与产物：** T-EDG-FLASH枚举所有写阶段中断并重开镜像，再以获准硬件台架执行实际掉电点；每次只能读到有效旧/新或明确失败，无确认后丢关键配置。保存原始镜像、写轨迹、ACK点与擦写分母。

**正例 / 直接失败 / 合法邻例：** 正例为新记录提交后再确认；直接失败为擦旧后写新中断导致两份皆无效；合法邻例为未确认写中断后继续使用旧完整状态。

**来源：** 组织合成；真实Flash原子/寿命假设必须由具体datasheet、驱动和实测支撑，模型不证明物理耐久。

### EDG-F02 清单身份、权限与镜像消费绑定

**对象与责任：** 更新授权者确定可安装内容，设备验证器检查签发权/用途，安装者对消费字节与目标布局负责。

**输入/输出/权威：** 输入为受认证的vendor/class、硬件/引导前置、组件/存储位置、payload类型、精确大小与摘要、清单结构版和授权链；输出为可安装候选或拒绝原因。当前信任策略、不可变清单字节与真实消费镜像为权威。

**必要机制与不变量：** 在受清单控制的写入/解压/执行前核身份、用途和组件权限，核目标适配且大小/区间不越界；传输TLS和有效签名均不能替代安装权。差分更新绑定前镜像摘要，展开后的最终消费字节也需认证校验。验证后到写入间防替换；尾随未认证可执行数据不得被消费。[E01][E02]

**失败、并发、超时与恢复：** 长度/摘要错、错误硬件类、未知授权和下载不全须写前拒绝或隔离候选，不触碰活跃镜像；流式下载若已写非活跃区仍不可激活。清单/组件并行更新必须核同一依赖组合。

**兼容：** 设备逻辑身份与固件兼容class分别匹配；多class兼容设备可接受明确授权的任一匹配类。未知格式版本拒绝或按明确扩展规则处理，不能跳过安全字段。

**验收与产物：** T-EDG-IMAGE对错类、错摘要、大小溢出、错前镜像、签后替换和合法多class运行验证；读取实际分区摘要/目标布局与拒绝前后差异，拒绝侧无活跃区改写。

**正例 / 直接失败 / 合法邻例：** 正例为当前信任链授权的适配镜像；直接失败为另一硬件类有效签名镜像安装成功；合法邻例是不同显示型号但被清单明确认证兼容class的设备。

**来源：** E01 RFC9019架构/清单；E02 RFC9124§3.3/3.4/3.13—15与§4.3.4—10。校验后使用及布局控制为组织合成。

### EDG-F03 单调授权与合法回退

**对象与责任：** 清单发行者分配序列，设备可信状态控制者保留最高已接受序列/对应摘要及安全下限；展示版本不参与授权排序。

**输入/输出/权威：** 输入为新清单sequence、清单摘要、当前高水位、撤销/安全下限和目标镜像身份；输出为新授权、同一事务续传或拒绝。设备持久高水位/可信根与当前授权策略为权威。

**必要机制与不变量：** 序列低于当前高水位拒绝，序列空间不可回绕；同序列仅允许相同清单摘要按原状态幂等恢复，异内容拒绝。新序列可以授权旧展示版本镜像，但仍需满足安全下限/撤销；不得把版本字符串比较当反回滚。高水位写入与可恢复安装状态绑定，不能先擦掉唯一可启动路径再保序列。[E02]

**失败、并发、超时与恢复：** 并发清单以持久比较更新，掉电不得让已接受高水位回退；若高水位先持久而镜像未完成，必须能以同一清单续传/恢复，不因等号拒绝永久卡死。撤销不明时不自动安装，序列耗尽更换授权域/可信迁移而非归零。

**兼容：** 合法恢复使用更高授权序列与可验证旧镜像；恢复出厂/更换所有者不能自动清零反回滚状态。不同独立组件序列作用域须明确，不能误将无关组件互相阻塞。

**验收与产物：** 本地镜像模型及T-EDG-IMAGE测试旧序列、等序列同/异摘要、高序列授权旧版本、安全下限违例、并发和高水位写后掉电；保存序列存储/引导轨迹。模型中的trusted=True仅是假设输入，不验证签名或硬件安全存储。

**正例 / 直接失败 / 合法邻例：** 正例为sequence 12安装获准镜像；直接失败为重放sequence 8或接受同12异摘要；合法邻例为sequence 13授权旧展示版本，以及sequence12同摘要中断续传。

**来源：** E02§3.2、§4.3.1支持序列与版本分离；同序列恢复、安全下限和持久耦合为防拒绝合法恢复的组织合成。

### EDG-F04 安装阶段、候选引导与健康确认

**对象与责任：** 安装器、引导器和健康判定者分别确认下载、验证、写入、候选启动、功能健康与激活；不得由下载器代签健康完成。

**输入/输出/权威：** 输入为已验证候选、引导选择、尝试计数、健康条件/截止与恢复位置；输出为可恢复候选、活跃版本或恢复态。引导元数据、真实启动身份及所声明核心功能结果为权威。

**必要机制与不变量：** 每阶段持久可判；候选未确认前保留可用旧/恢复入口。尝试计数在进入可能故障候选前按存储保证更新，防复位无限试。健康条件覆盖关键功能与依赖，不以进入main或发一次心跳代替；确认记录与启动选择在掉电后组合一致。

**失败、并发、超时与恢复：** 各阶段掉电、确认丢失、镜像损坏或健康超时进入确定恢复/有限再试；恢复也必须满足当前授权和安全下限，不能自动启动已禁旧镜像。用户/管理端重复确认按候选身份去重，旧候选回执不能确认新版本。

**兼容：** 不强制A/B；单槽可使用外部恢复或受保护最小引导器，但需完整可恢复证据。引导/应用/配置版本组合按兼容矩阵，不假设只回退应用就恢复数据。

**验收与产物：** T-EDG-FLASH/IMAGE枚举下载到确认每一状态转移和中断；重启后核实际运行摘要、剩余尝试与健康结果。合法路径最终激活，未确认路径不得永久误激活；真实台架另外报告。

**正例 / 直接失败 / 合法邻例：** 正例为核心功能通过才提交激活；直接失败为main即成功而重启循环永久活跃；合法邻例为小容量设备使用已验证外部恢复，不因无A/B被拒。

**来源：** E01§4/4.1仅支持引导与更新架构分工；阶段/健康/尝试持久状态机为组织合成。

### EDG-F05 信任根、维修模式与密钥更替

**对象与责任：** 制造/部署/维修/退役权限所有者分别核安装签发、设备认证与调试能力；维修入口不能隐式替代生产信任策略。

**输入/输出/权威：** 输入为设备/用途/环境密钥引用、信任根/委派、维修状态和目标授权；输出为被允许的验证/调试范围及撤销完成或未决。权威是目标验证器/调试口实效与消费者版本，不是工单标题。

**必要机制与不变量：** 更新签名、设备登录和数据加密用途隔离；信任根变化从已受信起点认证，核授权接收者/组件。新根就绪、消费者切换、旧签发拒绝分别验证；旧材料不因恢复模式而重新获签发权。调试/读回暴露范围在画像固定，不以默认通用口令交接。

**失败、并发、超时与恢复：** 离线设备未收新根保持未决并重连门禁；根更新中断保留明确可恢复可信路径，不能回退到“接受所有签名”。旧数据合法解密与旧签发权限分别处理。

**兼容：** 开发板可有单独获准实验镜像和信任域，不能把其调试开放结论称生产安全；不支持远程根更替的设备明示物理维护条件。

**验收与产物：** T-EDG-IMAGE/TRACE用合成信任根或隔离测试件送错用途、旧根、新根、维修模式和更新中断；核拒绝/允许和实际调试能力，保存非秘密版本记录。

**正例 / 直接失败 / 合法邻例：** 正例为有效新委派限定组件更新；直接失败为维修模式接受任意生产镜像；合法邻例为隔离开发域实验镜像明确不获得生产签发资格。

**来源：** 组织合成，复用安全基线§19—20；E02§4.3.17/18仅为签名密钥保护/更替背景，不声称硬件可信根已验证。

## 实际执行入口（not-run）

- **T-EDG-FLASH：** L5固定块设备/Flash驱动、镜像格式、擦写粒度、故障钩子和恢复入口；对每个擦写/提交边界运行目标测试二进制并用台架受控断电，重启后只读导出Flash镜像。`sha256sum "$FLASH_IMAGE"`与记录解析器核恢复结果。随机杀主机进程不能替代真实欠压/断电。
- **T-EDG-IMAGE：** 对固定镜像运行目标真实manifest验证/安装入口；若采用MCUboot或SUIT，L5给准确版本、信任配置、验证器命令和实际执行脚本，不假设所有格式通用。`arm-none-eabi-objdump -h "$IMAGE_ELF"`核区间，目标引导日志/内存读回核真实运行字节；只算SHA-256不能证明授权。
- **T-EDG-TRACE：** `arm-none-eabi-gdb -batch "$BOOTLOADER_ELF" -x "$CASE_GDB_SCRIPT"`读取序列/尝试/选择寄存器与持久区；脚本需绑定测试探针与边界注入，不对未知硬件执行通用刷写命令。

本地入口：`python3 -m unittest discover -s tests -p 'test_sec_edge_commerce_models.py' -v`，仅验证合成字节记录与有限状态假设。[来源](../../../sources/embedded-edge.md)与[模型边界](../../../examples/security-edge-commerce/README.md)单列。

# 桌面与移动有限契约示例

`contracts.py` 演示原账号/文档/scene 代际回包、编辑代次确认、激活接纳、程序/格式/组件兼容、未知效果核对、去重/迟到边界、到期完成回报和符号/配额条件。

假设：操作是进程内顺序步；authority receipt、权限与目标栅栏是测试者预先验证的输入。`RetryContract` 的服务迟到拒绝或传输上界必须在真实服务另行验证。这里没有真实认证、耐久事务、跨进程锁、网络时钟或包签名，因此不能证明 OS/后台调度/平台安全或真实效果恰好一次。

从仓库根运行：

```sh
python -m unittest discover -s tests -p 'test_desktop_mobile_contracts.py' -v
```

期望：正例可完成、错主体/参数/旧代际/错符号/不兼容格式拒绝、未知旧尝试不被新尝试否定。普通模式检查；`-O/-OO` 明确拒绝。

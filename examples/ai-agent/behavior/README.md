# AI 行为场景

这些场景用于检查声明、执行和交付中的具体失效。输入采用合成材料，不含用户会话或业务凭据。运行状态初始为 `not-run`，执行后写入实际结果。

使用方法见[行为指南](../../../guides/AI-BEHAVIOR.md)。每个案例包含明确提示、初始文件、授权边界、完成条件、可计算文件检查、语义 rubric、正例、直接失败例和合法邻例。参考措辞不作为逐字答案。

当前共 36 个场景。规范引用通过稳定文档和条款 ID 解析；运行时还要固定准确版本与摘要。

```sh
python -m checks.behavior_cases
```

该命令检查场景格式和规范引用。文案自然度、授权状态和目标系统结果由语义审查及目标执行记录判定，不按单一关键词或回答长度评分。

## 在项目中采用

参考[采用、升级与反馈](../../../guides/ai-behavior/ADOPTION.md)固定选用范围及准确版本。报告具体偏差时使用[反馈模板](FEEDBACK.template.md)，保留原失败、实际配置及合法邻例。项目采用状态和模型运行结果分别记录。

# 行为问题反馈模板

以下字段用于现有 Issue、任务或项目记录，可按实际问题选填；空模板不是一次已发生的试验或已完成的审查。

## 准确对象

- 发行集合版本与来源提交：
- 涉及的文档 ID、版本、SHA-256 和条款 ID：
- 可观察的模型、宿主、指令配置及工具版本；无法固定的部分：
- 相关行为案例或适配项：

## 任务和现象

- 实际请求、读者或产物，以及已授权范围：
- 预期完成条件：
- 实际文件、回复、工具动作和副作用；发生时间：
- 可安全分享的最小复现输入、原始可见记录位置及摘要：
- 失败、中断、未知或未执行部分：
- 相邻合法场景，应继续允许的行为：

## 处理记录

- 根因判断及支持证据；仍缺少的事实：
- 修复或解释的准确提交与受影响范围：
- 实际复验命令、环境、结果和原始记录：
- 独立审查对象、发现、处理及结论：
- 升级、恢复或适配停用动作：

只提供当前有依据的内容；不要补造模型指纹、原始调用、已通过状态或未取得的授权。不要把密钥、私人业务材料或不可披露指令放进普通反馈。

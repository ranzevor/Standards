# AI 真实目标验收接口

`target-contract.json` 登记尚未配置的目标；`target-contract-example.json` 提供填写完整的**合成接口示例**。其中的 `.invalid` 地址、模块名、版本和账本均为合成值。检查器读取字段，但不执行命令。

```sh
python -B checks/ai_target_contract.py
python -B checks/ai_target_contract.py examples/ai-agent/target-contract-example.json
```

## 字段与连接要求

配置真实适配器时，将 `target_kind` 改为 `configured-real-target`，整体替换十三个目标字段，不得半配置。执行、查询、取消和身份验证命令均为 argv 数组，不隐式调用 shell。版本固定，不接受 latest 或范围。输入输出提供对象 schema、属性和必填集合；检查器只校验有限字段格式，完整 schema 验证由目标适配器完成。

必须给出当前身份验证权威、原子权限与 fencing 接受点、任务/尝试/epoch 映射、幂等键及保留窗口、预算预留和用量权威、取消/未知结果查询合同。未知结果不得直接释放预算、重交有副作用请求或改写为失败；取消回执不能单独证明终止、退款或删除。技术审查和目标运行负责核实字段内容及目标能力。

## 必需场景与判据

1. **成功**：固定输入、版本、身份、策略和初始 epoch；执行 run argv，保留原始输出、退出码、接受点、业务权威查询和用量收据；仅当前 epoch 且权限满足时产生一个逻辑业务结果。
2. **重复/并发**：同键同摘要同时提交，业务权威只能接受一个逻辑效果；同键不同摘要必须拒绝，不得返回旧结果冒充新请求成功。
3. **断连/超时**：已接受但未收到回执时断连；状态进入 unknown，预算继续预留；执行 query argv，只有权威终态可结算，不以客户端超时推断未执行。
4. **撤权/旧 epoch**：接受点前撤权或提升 epoch；旧执行不得获得新副作用许可，晚到结果只附加为陈旧证据，不覆盖当前状态。
5. **取消竞态**：取消与完成交错；查询最终权威状态，区分取消请求被接收、实际终止和已完成；结算与权威结果一致。
6. **相邻合法例**：同任务无副作用查询可重复，成功收据晚到可补全审计；不得因重复查询或归档陈旧证据而拒绝整个合法任务。

每个场景产物包括合同摘要、输入摘要、命令和工具版本、时间与退出码、脱敏身份与授权证据、状态迁移、业务与预算权威收据，以及成功、失败和合法邻例的逐项判定。模型行为、SDK/协议、存储与隔离、业务结果四层分别登记；本地有限状态模型结果记录在对应层。未执行的层保持 `not-run`，`implementation_acceptance` 同步记录实际状态。

字段 `adapter_module` 沿用接口名称，可登记点分模块名或显式 L5 定位符（如 `exec:/isolated/adapter`、`node:@example/adapter@1.2.3`），不要求所有项目使用 Python。`run_command` 固定真实 argv；纯本地适配器可用明确 `local:`/`stdio:` URI 表示无外部网络目标，不能为填字段创建本不需要的服务。工具只拒绝已实现的歧义格式，不凭字符串认证版本确实固定或实现存在。

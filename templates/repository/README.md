# 软件仓库模板包

本目录提供可复制的仓库协作与平台配置模板。先按[软件仓库采用指南](../../guides/SOFTWARE-REPOSITORY-ADOPTION.md)固定可见性、分发、维护和发行状态，再选择实际需要的文件。已有 Issue、PR、工单或项目记录能够承载相同事实时直接复用，不建立第二份当前状态。

| 模板 | 建议目标路径 | 用途 |
| --- | --- | --- |
| [PR 模板](PULL_REQUEST_TEMPLATE.md) | `.github/pull_request_template.md` | 固定目标、基线、候选、影响、验证、恢复和审查对象 |
| [缺陷 Issue 模板](ISSUE_TEMPLATE/defect.md) | `.github/ISSUE_TEMPLATE/defect.md` | 提供可复现缺陷、影响和修复验收输入 |
| [变更提案模板](ISSUE_TEMPLATE/proposal.md) | `.github/ISSUE_TEMPLATE/proposal.md` | 提供范围、机制、兼容和接受条件 |
| [平台控制模板](PLATFORM-CONTROLS.md) | 项目的治理或运维目录 | 记录预期平台配置及实际读回入口 |

同时复用上级目录已有的 [README 入口合同](../README-ENTRY.md)、[权属与通知记录](../RIGHTS-AND-NOTICES.md)、[发行准备模板](../RELEASE-READINESS.md)和[退役模板](../RETIREMENT.md)。这些模板不自动选择许可证、开启平台功能、批准合并或证明检查通过。

## 按状态选择

- **私有开发：** README、实际构建/测试入口、依赖锁定和内部问题入口；未选择许可证时保持不分发状态，不使用开源徽章。
- **公开源码：** 增加准确的权利状态、贡献入口、安全渠道和公开范围；仅可见源码不得写成已授予开源许可。
- **开源协作：** 增加有权主体选择的许可证、第三方通知、Issue/PR 模板、维护范围和真实平台保护。
- **正式发行：** 增加版本与兼容策略、发行清单、变更记录、恢复入口和真实下载/安装验收。
- **归档：** 保留最终身份、维护状态、既有许可、替代或迁移说明及必要历史取得入口。

复制后删除说明性占位文字，填写项目自己的真实对象。原始测试输出、审查过程和截图不放入模板或源码仓库。

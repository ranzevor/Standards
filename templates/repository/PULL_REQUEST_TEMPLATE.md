- 需求、Issue 或采用条款：
- 目标分支及基线提交：

- 本次范围与明确不改范围：

## 行为与影响

- 使用者可观察变化：
- 公共接口、数据、配置、依赖、许可及兼容影响：
- 主要风险、失败状态和恢复/回退入口：

## 验证

- 环境、命令、预期、实际和退出码：
- 失败修复后的针对性回归：
- 未执行、部分执行或不适用范围及原因：
- 原始结果位置（独立运行目录或 CI 制品，不粘贴秘密）：

## 审查与合并前置

- 作者自查绑定的候选及范围：
- 独立审查绑定的候选、范围和开放发现：
- 来源、贡献权限和第三方材料已核对象：
- 合并前需重新确认的目标 HEAD、必需检查和阻断项：

字段按实际变更简洁填写。无对应影响时写明具体不触发条件；不要用“无风险”“全部通过”替代对象、范围和实际结果。

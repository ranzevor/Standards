# README 入口合同

适用于新建或更新项目主入口；采用[README规范](../standards/project-governance/005-README品牌与徽章规范--v0.1.0.md) PGE-01—08。填写后保存为项目自己的配置记录，README 保持面向读者的 Markdown 页面，不复制规范正文。

## 字段与合法值

| 字段 | 填写规则 | 可核对象 |
| --- | --- | --- |
| `audience_tasks` | 至少一项真实读者及其首要任务，例如“中文开发者：选择技术领域与规范版本” | 定位段、最快路径及对应任务结果 |
| `maturity` | `draft` / `experimental` / `maintained` / `deprecated` / `archived`；只选当前真实状态 | 项目状态决定或维护记录；状态不能推导采用或测试通过 |
| `cover` | 相对路径、图像尺寸、内容 SHA256；有意义图片填写描述其作用的替代文字；装饰图须确为无信息装饰 | 实际图像字节与窄屏渲染；不得用文件名作替代文字 |
| `badges[]` | 使用标准Shields.io徽章，每项填写官方URL、可见文字、对象、指标/状态、来源链接及更新方式；没有真实对象则不用 | URL编码与文字一致，点击后到达准确项目/版本/检查页面；静态状态与正文一致 |
| `quick_start` | 前提、工作目录、可逐行执行的命令、独立预期结果、失败分支 | 临时环境中的命令和原始退出码；输入不可凭空可得 |
| `navigation` | 版本、领域/接口、采用、贡献、安全、权属/许可各入口；确无发行/许可时链接当前状态说明 | 全部本地目标及锚点；外链的真实目的地 |
| `languages` | 各实际语言入口、权威语言、可用全文范围、未提供的内容及回退目标 | 源译清单与对应全文，不能仅有语言切换链接 |
| `visual_checks` | 桌面与320 CSS px目标、工具/版本、实际结果；未运行填`not-run` | 实际渲染截图/观察；文本链接检查不替代布局检查 |

## 填写完成的正常实例

本仓 [中文入口](../README.md) 与 [英文入口](../README.en.md) 为配套实例：中文开发者从体系/领域目录选择规范，采用者从采用指南固定准确条款；`assets/cover.png` 提供品牌封面，Shields.io采用状态徽章对应登记中的162份已采用规范，版本徽章对应发行集合版本。最快路径为 Python 3.12 的离线检查；源译清单逐份登记实际可用内容。入口身份、本地资源与徽章URL可执行 `python checks/project_readme.py` 核对；该命令不输出视觉布局通过。

## 失败与恢复实例

将实例的 `INDEX.md` 链接误改成 `INDEX-OLD.md`：本地链接检查应失败，不能保留绿色入口验收。恢复准确目标后重新执行链接检查；若此次还改变封面裁切、表格宽度或语言布局，另运行同尺寸浏览器复验，不复用原来的视觉结论。徽章已失去来源时，删除该徽章或改成真实可维护的状态，不能改成无链接图片掩盖问题。

# 兼容、迁移与可访问性

离线工具以 Python 3.12 为基线，使用标准库；采用项目记录实际运行环境并验证目标平台兼容性。相对路径、Unicode 文件名与换行在实际目标平台复验；领域 slug 使用 ASCII，其他文件路径仍可包含 Unicode 字符。

迁移规范版本时，记录旧新ID、版本与SHA；逐项核对路径、条款义务、来源、依赖和检查差异。旧版本的验收结果不自动适用于新版本。

具体流程见[迁移指南](MIGRATION.md)，项目选择见[采用指南](ADOPTION.md)。兼容检查覆盖内容义务、工具输入输出、语言和协议版本、持久格式、实际消费者及辅助技术路径。多个版本并存时，明确每个消费者依赖的准确对象，不用共享可变文件名承诺兼容。

正文采用语义标题、文本链接、具名表头与纯文本等价内容；封面/徽章有替代文字，状态不只依赖颜色。代码块可复制，无必须使用图片识别的步骤。README的窄屏、缩放及屏幕阅读器表现须按实际渲染结果验证。

破坏性修订应提供旧→新条款与接口映射、废弃期限及兼容窗口。弃用日期未确定时记录为待决定。最终技术栈与平台的可访问性按产品适用标准验收。

具体的 UTF-8/LF、Windows 路径边界及原生消费者证据要求见[跨平台验收](CROSS-PLATFORM.md)。Linux、Windows 和其他平台分别记录实际执行结果。

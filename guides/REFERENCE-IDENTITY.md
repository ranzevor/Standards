# 按稳定身份查询与引用规范

规范的文档 ID 不随目录排序或版本变化。使用 `STD-L4-AI-AGENT-015` 查找长任务恢复规范；不要把历史编排顺序中的“第11专题”当作当前文档编号。

## 查询准确对象

```sh
python tools/skill_lookup.py --document-id STD-L4-AI-AGENT-015
python tools/skill_lookup.py --document-id STD-L4-AI-AGENT-015 --clause-id '§18'
```

离线 Skill 中对应入口是 `scripts/lookup.py`。按 ID 查询返回登记的唯一文档；未知 ID 报错，不改用相近名称。结果含文档 ID、编号、完整标题、文档版本、路径和 SHA-256；条款结果另给准确行段及摘要。顶层 `version` 是发行集合版本，结果中的 `version` 是各文档版本，二者可以不同。

工具先检查正文摘要、标题、文档 ID、版本、状态、生效日期与文件编号，再返回结果。名称模糊时先用 `--query` 列出候选，选择准确 ID 后再固定采用身份。不能仅凭标题相似推定两份规范承担相同职责。

## 正文引用

需要显示准确身份的链接使用以下标签格式，链接路径来自当前登记：

```text
[文档ID · 登记的完整标题](准确的相对路径)
```

`checks/semantic_references.py` 核对这种标签的 ID、标题与真实链接目标。只有片段的 `#条款锚点` 指向当前文档，标签中的 ID 和标题仍须与当前登记一致；标签内用行内代码显示的 ID 也会核对。

数字前缀本身不证明标签在声明文档编号。自动检查覆盖“编号 + 登记的完整标题”，以及原 AI-005 链接中的五个已核实简名：指令信任、上下文、Tool/MCP、授权及副作用、执行隔离。指向真实 `§NN` 条款锚点且编号一致的标签按条款引用处理；普通数量、页码及其他自由描述不会仅因数字前缀被推定为文档身份。已通过身份检查的链接标签不会再被当作无链接的历史序号扫描。

AI 专题正文中带有明确专题名称的历史序号仍会检查；“第10个候选”这样的普通计数保持合法。整条链接作为行内或围栏代码示例时，以及注释中的示例，均不作为可点击引用核对。这与可点击链接的标签内使用代码格式不同。

检查只能证明显式身份一致；目标正文是否支持引用句的具体命题仍需阅读相应范围和条款。路径存在、标题正确和内容摘要匹配不能代替这项判断。

## 修订及迁移

修改正式正文时为该文档生成新版本、路径和摘要，并同步当前引用。引用路径变化也会改变引用方正文，因此沿实际引用关系计算受影响集合，重复至没有新增受影响文档。未发生变化的正文保留原版本，不把发行集合版本强加给每份规范。

修订后重新生成目录、条款和来源索引，更新对应的精确依赖及翻译绑定。旧版本由准确 Git 提交或发行标签定位；采用项目继续锁定原 ID、版本和 SHA-256，按[迁移指南](MIGRATION.md)决定升级。

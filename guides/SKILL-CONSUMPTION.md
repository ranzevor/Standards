# Skill 任务选读与应用

本页属于现有 Agent Skill 的可选参考资源。任务只加载必要部分，不把检索命中、模板或行为示例自动转成新的项目采用义务。

## 选取入口

| 实际任务 | 优先搜索 | 必须核实 |
| --- | --- | --- |
| 新项目治理、职责和版本决策 | `--query "项目治理"`、`--document-id STD-L0-001` | 项目阶段、责任与既有决定 |
| 软件仓库审查、质量门禁和发布 | `--query "仓库"`、`--query "质量"` | 目标产物、版本、权限和验证环境 |
| Agent 系统、工具或评测 | `--query "Agent"`、`--document-id STD-L4-AI-AGENT-002` | 宿主限制、实际工具权限与运行观察 |
| Web、数据库、游戏等领域 | `--domain web`、`--query "数据库"`、`--query "游戏"` | 项目确实使用的领域和功能 |
| 安全、凭据和隔离 | `--query "安全"`、`--query "身份"` | 信任边界、数据来源和真实授权 |
| 具体条款或未知领域用语 | `--clause-id <准确ID>`、`--text-query "<原文片段>"` | 条款段落、适用条件、依赖和唯一身份 |

`--query` 仅检索 ID、标题、路径和领域，不检查正文；`--text-query` 是条款文本的大小写不敏感精确子串匹配，不是语义搜索。没有命中的结果不能被解释为规范不适用。避免根据猜测的文件名、编号或旧记忆直接执行。

## 连续读取检索结果

先限定领域或文档，再搜索正文。例如：

```sh
python -X utf8 -B scripts/lookup.py --document-id STD-L4-AI-AGENT-002 --text-query "授权" --limit 5
python -X utf8 -B scripts/lookup.py --document-id STD-L4-AI-AGENT-002 --text-query "授权" --limit 5 --offset 5
```

输出保持 `version`、`total`、`results` 三个字段；`total` 不受分页影响。`--offset` 是非负整数，默认 0；`--limit` 仍为 1–100。按登记顺序返回，偏移在全部过滤后应用，超过总数返回空数组。继续读取时将偏移增加实际返回条数，直到达到 `total` 或返回空数组。不要在翻页中途替换发行包或改变过滤条件；版本更新后从第一页开始。分页不会跳过所选文档的索引校验。

在项目目录工作时，用宿主实际加载的 `SKILL.md` 路径定位 Skill 根目录，并使用脚本绝对路径；返回的 `references/...` 路径相对于 Skill 根目录，不相对于项目工作目录。安装与首个任务见 [宿主使用说明](SKILL-INSTALLATION.md)。

## 执行顺序

1. 从项目已有记录与本次授权确认任务边界。没有现成采用决定时，检索只产生候选要求，按项目正常流程选择。
2. 先限定领域、标题或已知文档 ID；再按条款 ID 或原文搜索缩小候选。命中多个条款时逐个核对，不采用“第一条即正确”的规则。
3. 读取对应 `references/standards/` 下准确原文，并与检索结果中的版本、摘要和行段匹配；若无法读取，停止使用该条候选。
4. 按适用范围筛选，记录确有意义的参数、例外、必要依赖和验收判据。项目无对应能力时不强制新增无关功能。
5. 执行已授权任务，依照所选条款检查结果。可直接调用 Skill 内携带的既有有限检查器，但仅在其明确支持的输入与环境下使用。
6. 采用现有项目 PR、Issue 或记录承载问题和实际复验，不要求额外平台或循环状态服务。

## 检查与恢复

- `scripts/verify_bundle.py` 只确认本地发行包身份与文件完整性。
- `scripts/lookup.py` 核对登记的规范正文与已匹配条款摘要；结果中的行号是定位依据，不是已经执行过目标行为的证据。
- 实际任务是否完成，以真实产物、命令结果、目标环境和必要的独立审查判定；已有行为案例只提供安全试验输入。
- 找不到文档、匹配为空、摘要冲突或包遭修改时，不生成伪造的后备条款。按准确发行身份恢复文件并重试只读检索。
- 规范升级时比较发行集合、所用文档及条款的准确版本和摘要；旧项目既有有效采用不被新版 Skill 自动修改。

## 测试边界

Skill 格式校验、脚本单元测试、离线解包检查、真实宿主任务分别记录。即便全部静态检查通过，也不能由此推定某个 Agent 宿主已加载或遵循条款。实际宿主测试需保留可见工具记录与最终产物，并按原定判据评审。
